## @description

### Контекст
В каталоге «Ложки» у каждого ресторана есть карточка, а на ней — строка со статусом. Дизайнер прислала макет: если ресторан сейчас работает, под названием написано «Открыто до 23:00». Если не работает — «Закрыто. Откроется в 10:00».

Обрати внимание: на карточке всегда ровно один из двух текстов. Не «показать или промолчать», как в прошлой задаче, а «показать одно или другое».

### Новое в Swift
Условие `if` умеет выполнить блок, когда ответ «да». Чтобы сказать, что делать при ответе «нет», после блока добавляют слово `else` («иначе») и второй блок:

```swift
let freeTables = 0

if freeTables > 0 {
    print("Можно забронировать столик")
} else {
    print("Свободных столиков нет")
}
```

Swift проверяет условие один раз. Если оно истинно, выполняется первый блок, а второй пропускается. Если ложно — наоборот. Запомни главное: из двух блоков **всегда выполняется ровно один**.

Правила записи:

- у `else` нет своего условия — он означает «во всех остальных случаях»;
- `else` пишут на той же строке, что и закрывающая скобка первого блока: `} else {`;
- `else` не бывает сам по себе, он всегда продолжает какой-то `if`.

**Bool в роли условия.** Условие — это любое значение типа `Bool`. Значит, ответ можно сначала посчитать и положить в константу с понятным именем, а потом поставить её после `if`:

```swift
let guests = 6
let needsBigTable = guests > 4

if needsBigTable {
    print("Подготовим большой стол")
} else {
    print("Подойдёт обычный столик")
}
```

Такой код читается почти как обычная фраза: «если нужен большой стол…». Писать `if needsBigTable == true` не нужно: в константе уже лежит готовый ответ `true` или `false`.

> 💡 Имена для `Bool` принято начинать со слов `is`, `has`, `can`, `needs`: `isOpen`, `hasDiscount`, `canDeliver`. Тогда условие читается как вопрос.

### Задача
В редакторе есть название ресторана, текущий час `currentHour`, час открытия `openingHour` и час закрытия `closingHour`. Название уже выводится. Не переименовывай данные — проверка подставит другие значения.

1. Объяви константу `isOpen` типа `Bool`. Ресторан открыт, если текущий час **не меньше** часа открытия **и** при этом **меньше** часа закрытия. Ровно в час открытия он уже работает, ровно в час закрытия — уже нет.
2. Напиши `if` / `else` с условием `isOpen`:
   - если ресторан открыт, выведи `Открыто до 23:00` — вместо `23` подставь час закрытия;
   - иначе выведи `Закрыто. Откроется в 10:00` — вместо `10` подставь час открытия.

Двоеточие и два нуля после часа — обычный текст, он одинаков для любого ресторана.

### Пример
Для данных из редактора (сейчас 14 часов, ресторан работает с 10 до 23):

```text
Том-ям бар
Открыто до 23:00
```

А в 9 утра карточка выглядела бы так:

```text
Том-ям бар
Закрыто. Откроется в 10:00
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let restaurant = "Том-ям бар"
let currentHour = 14
let openingHour = 10
let closingHour = 23

print(restaurant)

// 1. Объяви isOpen: час не меньше часа открытия и меньше часа закрытия
let isOpen = currentHour >= openingHour && currentHour < closingHour

// 2. Выведи статус: один текст, если открыто, и другой — если закрыто
if isOpen {
    print("Открыто до \(closingHour):00")
} else {
    print("Закрыто. Откроется в \(openingHour):00")
}
```

## @rules
- must: /\belse\b/ :: На карточке всегда один из двух текстов. Запиши выбор парой `if` / `else`.

## @hint1
Задача состоит из двух шагов: сначала получить ответ «открыто или нет», потом по этому ответу выбрать текст.

Шаг первый — константа `isOpen`. В ней должен лежать результат двух сравнений сразу. Первое: текущий час не меньше часа открытия, то есть больше или равен ему. Второе: текущий час строго меньше часа закрытия. Ресторан открыт, только когда верно и то и другое, — значит, сравнения соединяются оператором «и», который ты знаешь по прошлому модулю.

Шаг второй — развилка. После слова `if` ставится просто имя `isOpen`, без сравнения с `true`. В первом блоке — `print` с текстом про «Открыто» и вставкой часа закрытия. Потом слово `else` и второй блок — `print` с текстом про «Закрыто» и вставкой часа открытия.

Подумай над знаками сравнения: ровно в час открытия ресторан уже работает, а ровно в час закрытия — уже нет.

## @hint2
Ответ на вопрос можно положить в константу, а потом выбрать по нему один из двух блоков:

```swift
let guests = 6
let needsBigTable = guests > 4

if needsBigTable {
    print("Подготовим большой стол")
} else {
    print("Подойдёт обычный столик")
}
```

В твоей константе `isOpen` будет не одно сравнение, а два, соединённые через `&&`. Час во вставке и текст `:00` после неё пишутся подряд: `"до \(closingHour):00"`.

## @hint3
Осталось заполнить пропуски:

```swift
let isOpen = currentHour >= openingHour && currentHour ___ closingHour

if isOpen {
    print("Открыто до \(closingHour):00")
} ___ {
    print("Закрыто. Откроется в \(___):00")
}
```

В первом пропуске — знак сравнения: ровно в час закрытия ресторан уже не работает. Во втором — слово, которое начинает блок «иначе». В третьем — имя константы с часом открытия.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В первой строке Swift вычисляет два сравнения. Для данных из редактора это `14 >= 10` и `14 < 23` — оба истинны, оператор `&&` даёт `true`, и это значение попадает в `isOpen`. Затем `if isOpen` смотрит на готовый ответ. Раз там `true`, выполняется первый блок, а блок после `else` пропускается. В 9 утра первое сравнение было бы ложным, в `isOpen` оказалось бы `false`, и сработал бы второй блок.

**Почему `>=` в начале и `<` в конце.** В 10:00 двери открываются — гость уже может сделать заказ, поэтому час открытия входит в рабочее время. В 23:00 кухня закрывается, поэтому час закрытия в него не входит. Если написать `currentHour <= closingHour`, приложение будет принимать заказы в закрытый ресторан. Обе границы проверяются отдельными сценариями.

**Почему `else`, а не второй `if`.** Можно было написать два отдельных условия: `if isOpen { ... }` и `if !isOpen { ... }`. Но тогда Swift проверяет условие дважды, а читателю приходится самому догадываться, что эти случаи исключают друг друга. `else` говорит об этом прямо: «во всех остальных случаях».

**Зачем отдельная константа.** Условие с двумя сравнениями можно поставить и сразу после `if`. Но имя `isOpen` объясняет, что именно проверяется, и к тому же этот ответ можно использовать снова — например, чтобы отключить кнопку заказа.

**Типичные ошибки:**

- `||` вместо `&&`: тогда ресторан «открыт» почти всегда, ведь одно из двух сравнений обычно истинно;
- после `else` дописано своё условие, например `else isOpen == false {`, — у `else` условия не бывает, сразу за ним идёт фигурная скобка;
- в тексте «Закрыто» подставлен час закрытия вместо часа открытия;
- потеряна точка после слова «Закрыто» или пробел перед «Откроется».
