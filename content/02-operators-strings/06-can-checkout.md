## @description

### Контекст
Самая важная кнопка в «Гардеробе» — «Оформить заказ». Она должна быть активной не всегда. Менеджер продукта описала правила в тикете:

«Кнопка активна, только когда выполнено всё сразу:

- товара на складе хватает;
- покупательница указала адрес доставки или выбрала самовывоз — достаточно чего-то одного;
- аккаунт не заблокирован.

На прошлой неделе заказ сумел оформить заблокированный аккаунт. Нужно починить».

Одного сравнения здесь мало: несколько ответов «да или нет» нужно соединить в один.

### Новое в Swift
Значения типа `Bool` можно комбинировать **логическими операторами**. Их три.

**`&&` — «и».** Результат `true`, только если **оба** значения `true`:

```swift
let isLoggedIn = true
let hasPushEnabled = false
let canSendPush = isLoggedIn && hasPushEnabled
print(canSendPush)     // false: вход выполнен, но уведомления выключены
```

**`||` — «или».** Результат `true`, если **хотя бы одно** значение `true`:

```swift
let isNewCustomer = false
let hasGiftCard = true
let showsGiftBanner = isNewCustomer || hasGiftCard
print(showsGiftBanner)   // true: хватило подарочной карты
```

**`!` — «не».** Ставится **перед** значением и переворачивает его: `true` становится `false`, а `false` — `true`:

```swift
let isRead = false
let isUnread = !isRead
print(isUnread)        // true
```

Соединять можно не только готовые константы, но и сравнения, и больше двух условий подряд. Например, товар получает значок «Хит», если у него высокий рейтинг, достаточно отзывов и он не снят с продажи:

```swift
let rating = 4.8
let reviewsCount = 12
let isArchived = false
let isBestseller = rating >= 4.5 && reviewsCount >= 10 && !isArchived
print(isBestseller)    // true
```

Как набрать: `&` — это Shift + 7, `|` — Shift + клавиша с обратной чертой `\`, `!` — Shift + 1. Знаки `&&` и `||` пишутся парой, без пробела внутри.

> 💡 Если в одном выражении смешать `&&` и `||`, Swift сначала выполнит все `&&` и только потом `||` — как умножение перед сложением. Чтобы не ошибиться, сложное условие раскладывают на несколько констант с понятными именами. Так мы и поступим в этой задаче.

### Задача
В редакторе есть данные заказа:

- `stockCount` — сколько штук товара на складе, `quantity` — сколько хочет купить покупательница;
- `hasAddress` — указан ли адрес доставки, `isPickup` — выбран ли самовывоз;
- `isBlocked` — заблокирован ли аккаунт.

Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `isInStock`: `true`, если на складе **не меньше** штук, чем нужно покупательнице.
2. Объяви константу `hasDeliveryMethod`: `true`, если указан адрес **или** выбран самовывоз.
3. Объяви константу `canCheckout`: `true`, если товар в наличии, **и** способ получения выбран, **и** аккаунт **не** заблокирован.
4. Выведи три строки, как в примере.

### Пример
Для данных из редактора (адреса нет, но выбран самовывоз):

```text
Товар в наличии: true
Способ получения выбран: true
Можно оформить заказ: true
```

А если аккаунт заблокирован, то при тех же остальных данных последняя строка будет `Можно оформить заказ: false`.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let stockCount = 4
let quantity = 2
let hasAddress = false
let isPickup = true
let isBlocked = false

// 1. Товар в наличии: на складе не меньше, чем нужно
let isInStock = stockCount >= quantity

// 2. Способ получения выбран: есть адрес ИЛИ самовывоз
let hasDeliveryMethod = hasAddress || isPickup

// 3. Заказ можно оформить: в наличии И способ выбран И аккаунт НЕ заблокирован
let canCheckout = isInStock && hasDeliveryMethod && !isBlocked

// 4. Выведи три строки с ответами
print("Товар в наличии: \(isInStock)")
print("Способ получения выбран: \(hasDeliveryMethod)")
print("Можно оформить заказ: \(canCheckout)")
```

## @hint1
Правила из тикета уже разложены на три шага, и каждый шаг — одна константа.

Шаг первый — обычное сравнение из прошлой задачи. Товара хватает, если `stockCount` больше или равно `quantity`. Ровно столько, сколько нужно, — тоже хватает.

Шаг второй. Покупательнице достаточно чего-то одного: адреса или самовывоза. Слова «хотя бы одно» — это оператор «или», две вертикальные черты. Слева от него `hasAddress`, справа `isPickup`.

Шаг третий. Здесь должны выполняться все условия сразу, а это оператор «и» — два знака амперсанда. Соедини им три части: `isInStock`, `hasDeliveryMethod` и третью — про блокировку. С третьей будь внимательна: в данных лежит ответ на вопрос «заблокирован ли аккаунт», а тебе нужно обратное — «не заблокирован». Перевернуть значение помогает восклицательный знак перед именем.

Потом три команды `print` со вставками: `isInStock`, `hasDeliveryMethod`, `canCheckout`.

## @hint2
Вот как выглядят все три оператора в деле:

```swift
let isNewCustomer = false
let hasGiftCard = true
let isBannerClosed = false

let hasGift = isNewCustomer || hasGiftCard          // хватит одного из двух
let showsGiftBanner = hasGift && !isBannerClosed    // подарок есть И баннер НЕ закрыт
```

Обрати внимание на `!isBannerClosed`: восклицательный знак стоит вплотную перед именем и читается как «не закрыт».

## @hint3
Первые два шага готовы. Собери третий:

```swift
let isInStock = stockCount >= quantity
let hasDeliveryMethod = hasAddress || isPickup
let canCheckout = isInStock ___ hasDeliveryMethod ___ ___isBlocked

print("Товар в наличии: \(isInStock)")
print("Способ получения выбран: \(hasDeliveryMethod)")
print("Можно оформить заказ: \(___)")
```

В первых двух пропусках — оператор «и». В третьем — один знак, который превращает «заблокирован» в «не заблокирован». В четвёртом — имя константы с итоговым ответом.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Для данных из редактора `isInStock` — это `4 >= 2`, то есть `true`. `hasDeliveryMethod` — это `false || true`: адреса нет, но самовывоз выбран, а оператору «или» достаточно одного `true`. В третьей строке сначала срабатывает `!`: `isBlocked` равно `false`, значит, `!isBlocked` — это `true`. Затем `&&` соединяет три значения: `true && true && true` даёт `true`. Стоит хотя бы одному из трёх стать `false`, и весь результат станет `false`.

**Почему условие разложено на три константы.** Всё можно записать одной строкой: `stockCount >= quantity && (hasAddress || isPickup) && !isBlocked`. Но в такой записи легко забыть скобки. Без них Swift сначала выполнит все `&&`, а `||` оставит напоследок, и смысл изменится: заблокированный аккаунт с указанным адресом смог бы оформить заказ. Именно так и появляются ошибки вроде той, что описана в тикете. Константы с понятными именами защищают от этого, а код читается почти как сами правила: «можно оформить, если в наличии, и способ получения есть, и не заблокирован».

**Зачем нужен `!`.** Данные отвечают на вопрос «заблокирован ли аккаунт?», а правило звучит как «не заблокирован». Оператор `!` переводит одно в другое. Без него заказ могли бы оформить только заблокированные аккаунты.

**Типичные ошибки:**

- один знак вместо двух: `&` или `|` — логические операторы пишутся парой;
- `!` после имени (`isBlocked!`) или через пробел — он ставится вплотную перед значением;
- `&&` вместо `||` во втором шаге — тогда пришлось бы и указать адрес, и выбрать самовывоз одновременно;
- `>` вместо `>=` в первом шаге — последнюю вещь со склада никто не смог бы купить.
