## @description

### Контекст
Внизу каждого экрана «Волны» есть мини-плеер. Он показывает, какой трек играет сейчас, сколько тот длится и что будет следующим.

Название, исполнитель и длительность трека всегда ходят вместе: одно без другого не имеет смысла. Хранить их в трёх отдельных константах неудобно — легко перепутать, что к какому треку относится. Поэтому коллега, который пишет движок воспроизведения, отдаёт данные о треке одним значением.

Его сообщение в чате: «Текущий трек лежит в `nowPlaying`, это кортеж с именами. Следующий — в `nextUp`, он из старого кода, там имён нет. Собери из них три строки для мини-плеера».

### Новое в Swift
**Кортеж** — это несколько значений, собранных в одно. Он записывается в круглых скобках через запятую, и значения могут быть разных типов:

```swift
let dish = ("Сырники", 180)   // название и вес в граммах
```

К элементам кортежа обращаются через точку и номер — счёт, как всегда, с нуля:

```swift
print(dish.0)   // Сырники
print(dish.1)   // 180
```

**Именованные элементы.** Номера плохо читаются: что такое `.1` — вес, цена, калории? Поэтому элементам обычно дают имена:

```swift
let dish = (name: "Сырники", weight: 180)
print(dish.name)     // Сырники
print(dish.weight)   // 180
```

В кортеж можно класть не только готовые значения, но и результаты вычислений:

```swift
let price = 320
let cups = 3
let order = (cups: cups, total: price * cups)
print("К оплате: \(order.total) руб.")   // К оплате: 960 руб.
```

**Разбор на части.** Кортеж можно «распаковать» в несколько отдельных констант одной строкой. Слева в скобках — имена новых констант, по порядку элементов:

```swift
let delivery = ("Казань", 40)
let (city, cost) = delivery
print(city)   // Казань
print(cost)   // 40
```

Одна строка создала сразу две константы: `city` и `cost`. Количество имён слева должно совпадать с количеством элементов кортежа.

> 💡 Чем кортеж отличается от массива? В массиве много однотипных значений, и их количество меняется: треков в плейлисте может быть сколько угодно. В кортеже значений всегда ровно столько, сколько задано, и у каждого своя роль: название, вес, цена. Добавить или убрать элемент кортежа нельзя.

### Задача
В редакторе есть два кортежа. `nowPlaying` — текущий трек с элементами `title`, `artist` и `duration` (длительность в секундах). `nextUp` — следующий трек, кортеж без имён: сначала название, потом исполнитель. Не переименовывай их — проверка подставит другие треки.

1. Выведи `Сейчас играет:`, название текущего трека, дефис и исполнителя. Вокруг дефиса — по пробелу.
2. Объяви константу `length` — кортеж с двумя именованными элементами: `minutes` — сколько целых минут длится текущий трек, и `seconds` — сколько секунд остаётся сверх целых минут. Тебе пригодятся деление нацело и остаток от деления.
3. Выведи `Длительность:`, минуты, `мин`, секунды и `сек` — значения возьми из `length`.
4. Разбери `nextUp` на две константы — `nextTitle` и `nextArtist` — одной строкой.
5. Выведи `Далее:`, название следующего трека, дефис и исполнителя.

### Пример
Для данных из редактора:

```text
Сейчас играет: Маяк - Северный ветер
Длительность: 3 мин 35 сек
Далее: Апрель - Билол
```

Трек длится 215 секунд: это 3 целые минуты и ещё 35 секунд.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let nowPlaying = (title: "Маяк", artist: "Северный ветер", duration: 215)
let nextUp = ("Апрель", "Билол")

// 1. Выведи строку "Сейчас играет: ..."
print("Сейчас играет: \(nowPlaying.title) - \(nowPlaying.artist)")

// 2. Объяви кортеж length с элементами minutes и seconds
let length = (minutes: nowPlaying.duration / 60, seconds: nowPlaying.duration % 60)

// 3. Выведи строку "Длительность: ..."
print("Длительность: \(length.minutes) мин \(length.seconds) сек")

// 4. Разбери nextUp на константы nextTitle и nextArtist
let (nextTitle, nextArtist) = nextUp

// 5. Выведи строку "Далее: ..."
print("Далее: \(nextTitle) - \(nextArtist)")
```

## @hint1
В задаче пять строк: три вывода и два объявления.

Первая строка печатает данные текущего трека. Он лежит в кортеже с именованными элементами, поэтому до названия и исполнителя добираются через точку: имя кортежа, точка, имя элемента. Оба обращения вставляются в текст через интерполяцию, между ними — пробел, дефис, пробел.

Вторая строка создаёт новый кортеж `length`. В круглых скобках два элемента, перед каждым — его имя и двоеточие. Значения нужно вычислить из длительности в секундах. Вспомни модуль про операторы: при делении целых чисел дробная часть отбрасывается, а отдельный оператор даёт остаток от деления. Здесь они нужны оба: в минуте шестьдесят секунд, целые минуты даёт деление, а «лишние» секунды — остаток.

Третья строка печатает минуты и секунды — берёт их из `length` по именам.

Четвёртая строка — разбор кортежа на части. После слова `let` в круглых скобках пишутся два новых имени через запятую, затем знак равенства и кортеж, который разбирается. Порядок имён соответствует порядку элементов: в `nextUp` сначала название, потом исполнитель.

Пятая строка печатает две получившиеся константы — так же, как первая строка печатала элементы кортежа.

## @hint2

## @hint3
Первая строка и кортеж `length` почти готовы. Заполни пропуски и допиши последний вывод:

```swift
print("Сейчас играет: \(nowPlaying.title) - \(nowPlaying.___)")

let length = (minutes: nowPlaying.duration / 60, seconds: nowPlaying.duration ___ 60)
print("Длительность: \(length.minutes) мин \(length.___) сек")

let (nextTitle, ___) = nextUp

```

В первом пропуске — имя элемента с исполнителем. Во втором — знак остатка от деления. В третьем — имя элемента с секундами. В четвёртом — имя второй константы. В последней строке собери текст из `nextTitle` и `nextArtist` по образцу первой строки.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `nowPlaying.title` и `nowPlaying.artist` достают из кортежа элементы по именам — так же, как `count` достаётся из массива. В строке с `length` создаётся новый кортеж: Swift сначала вычисляет оба выражения, а потом кладёт результаты в элементы с именами `minutes` и `seconds`. Для 215 секунд это `215 / 60 = 3` и `215 % 60 = 35`. Деление целых чисел отбрасывает дробную часть, а остаток показывает, сколько секунд не поместилось в целые минуты.

Строка `let (nextTitle, nextArtist) = nextUp` создаёт две константы сразу. Первый элемент кортежа попадает в `nextTitle`, второй — в `nextArtist`. Дальше с ними работают как с обычными константами.

**Почему кортеж, а не две отдельные константы.** Минуты и секунды — это одно значение, «длительность», просто из двух частей. Когда они лежат в одном кортеже, их нельзя случайно разлучить или перепутать с минутами другого трека. В модуле про функции ты увидишь главное применение кортежей: функция может вернуть сразу несколько значений.

**Почему имена лучше номеров.** К `nextUp` тоже можно обращаться как `nextUp.0` и `nextUp.1`, и это сработает. Но через месяц никто не вспомнит, что лежит под номером один. Запись `nowPlaying.artist` объясняет себя сама. Если имён нет, как в `nextUp`, разбор на части даёт значениям имена.

**Типичные ошибки:**

- `let length = (nowPlaying.duration / 60, nowPlaying.duration % 60)` без имён — тогда `length.minutes` не существует;
- имена перепутаны местами: `let (nextArtist, nextTitle) = nextUp` — название попадёт в константу для исполнителя;
- квадратные скобки вместо круглых — получится массив, а не кортеж;
- `nowPlaying.duration / 60` для секунд или `%` для минут — знаки перепутаны.
