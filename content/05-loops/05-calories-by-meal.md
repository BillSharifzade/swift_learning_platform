## @description

### Контекст
В «Пульсе» есть дневник питания. За день в нём набирается словарь: название приёма пищи и сколько в нём килокалорий. Экран «Питание» показывает отчёт: строка на каждый приём пищи и итог за день.

Тестировщик завёл баг: «Строки отчёта при каждом запуске идут в разном порядке. То завтрак сверху, то ужин». Тимлид отвечает: «Так и есть, словарь порядок не хранит. Выводи приёмы пищи по алфавиту — тогда отчёт всегда будет одинаковым».

### Новое в Swift
По словарю тоже можно пройти циклом. Каждый его элемент — это пара «ключ, значение», поэтому переменных цикла две, в круглых скобках:

```swift
let waterByTime = ["Утро": 500, "День": 900, "Вечер": 400]
for (time, amount) in waterByTime {
    print("\(time): \(amount) мл")
}
```

Цикл побывает в каждой паре ровно один раз. Но **в каком порядке — заранее неизвестно**. Словарь устроен так, чтобы мгновенно находить значение по ключу, и порядок записей он не запоминает. Сегодня первой окажется строка про день, а при следующем запуске — про вечер.

Если порядок не важен, это не мешает: сумма от перестановки слагаемых не меняется. Но для экрана такой цикл не годится — список у пользователя будет «прыгать».

**Как получить постоянный порядок.** Ты уже знаешь `keys.sorted()` — массив ключей, отсортированный по алфавиту. По массиву цикл идёт строго по порядку. Значит, решение такое: идём по отсортированным ключам и для каждого ключа берём значение из словаря.

```swift
for time in waterByTime.keys.sorted() {
    let amount = waterByTime[time, default: 0]
    print("\(time): \(amount) мл")
}
```

```text
Вечер: 400 мл
День: 900 мл
Утро: 500 мл
```

Теперь вывод одинаковый при каждом запуске. Порядок алфавитный: «В» идёт раньше «Д», а «Д» раньше «У».

Значение читается знакомой записью с `default:`. Ключ в словаре точно есть — мы только что взяли его из этого же словаря. Но Swift этого не знает и требует запасное значение на случай, если ключа не окажется.

> 💡 Правило на будущее: всё, что из словаря попадает на экран или сравнивается при проверке, выводи через отсортированные ключи.

### Задача
В редакторе есть словарь `calories` и вывод заголовка. Не переименовывай словарь: проверка подставит другие данные.

1. Объяви переменную `totalCalories` с начальным значением `0`.
2. Пройди циклом по ключам словаря `calories` **в алфавитном порядке**. Для каждого приёма пищи выведи строку: название, двоеточие, калории и слово `ккал`. В этом же цикле прибавляй калории к `totalCalories`.
3. После цикла выведи строку `Всего:` с суммой и словом `ккал`.

### Пример
Для данных из редактора:

```text
Калории за день:
Завтрак: 420 ккал
Обед: 650 ккал
Перекус: 180 ккал
Ужин: 540 ккал
Всего: 1790 ккал
```

Если дневник пуст, останутся только заголовок и строка `Всего: 0 ккал`.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let calories = ["Завтрак": 420, "Обед": 650, "Перекус": 180, "Ужин": 540]

print("Калории за день:")

// 1. Объяви переменную totalCalories для суммы
var totalCalories = 0

// 2. Пройди по ключам словаря в алфавитном порядке:
//    выведи строку для каждого приёма пищи и прибавь калории к сумме
for meal in calories.keys.sorted() {
    let mealCalories = calories[meal, default: 0]
    print("\(meal): \(mealCalories) ккал")
    totalCalories += mealCalories
}

// 3. Выведи итог за день
print("Всего: \(totalCalories) ккал")
```

## @rules
- must: /\.sorted\s*\(/ :: Порядок элементов в словаре случаен. Иди циклом по `calories.keys.sorted()`, чтобы строки всегда шли по алфавиту.

## @hint1
Главная мысль задачи: идти нужно не по самому словарю, а по его ключам, заранее отсортированным по алфавиту. Отсортированные ключи — это обычный массив строк, и цикл `for-in` пройдёт по нему в постоянном порядке.

На каждом повторе в переменной цикла лежит один ключ — название приёма пищи. Самих калорий в ней нет. Чтобы их получить, обратись к словарю `calories` по этому ключу. Читать значение нужно так, как ты делала в модуле про коллекции: с запасным значением `default:`. Удобно сразу положить результат в константу — он понадобится дважды.

Дальше в теле цикла два действия: вывести строку с названием и калориями и прибавить калории к `totalCalories`.

Сама переменная `totalCalories` объявляется до цикла, а строка с итогом выводится после него.

## @hint2
Цикл по словарю в алфавитном порядке ключей выглядит так:

```swift
for time in waterByTime.keys.sorted() {
    let amount = waterByTime[time, default: 0]
    print("\(time): \(amount) мл")
}
```

В твоём цикле в теле будет ещё одна строка — прибавление к сумме.

## @hint3
Заполни три пропуска:

```swift
var totalCalories = 0

for meal in calories.keys.___ {
    let mealCalories = calories[___, default: 0]
    print("\(meal): \(mealCalories) ккал")
    totalCalories += ___
}

print("Всего: \(totalCalories) ккал")
```

В первом пропуске — метод, который сортирует ключи (не забудь круглые скобки). Во втором — ключ, по которому читается значение. В третьем — калории текущего приёма пищи.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `calories.keys.sorted()` создаёт массив ключей по алфавиту: `["Завтрак", "Обед", "Перекус", "Ужин"]`. Цикл идёт по этому массиву, и в `meal` по очереди попадает каждое название. Строка `calories[meal, default: 0]` достаёт из словаря калории для этого названия. Затем строка отчёта выводится на экран, а калории прибавляются к сумме.

**Почему нельзя просто `for (meal, mealCalories) in calories`.** Такой цикл рабочий, и сумма в нём получится верной. Но порядок строк будет случайным и может меняться от запуска к запуску. Пользователь увидит, что список каждый раз перемешан. А проверка сравнивает вывод построчно — с перемешанными строками она не пройдёт.

**Зачем `default: 0`, если ключ точно есть.** Обращение к словарю по ключу может ничего не найти, и Swift заставляет об этом подумать. Мы знаем, что ключ взят из этого же словаря, но для Swift это обычная строка. Запасное значение здесь никогда не понадобится, оно просто делает запись безопасной.

**Зачем константа `mealCalories`.** Значение нужно в двух местах: в тексте и в сумме. Чтобы не обращаться к словарю дважды, результат сохранён под понятным именем.

**Типичные ошибки:**

- цикл по самому словарю или по `calories.keys` без `sorted()` — порядок строк случайный;
- `sorted` без круглых скобок — это метод, его нужно вызвать;
- `calories[meal]` без `default:` — в тексте появится слово `Optional`, а сложить такое значение с числом не получится;
- `totalCalories` объявлена внутри цикла — после цикла её не существует.
