## @description

### Контекст
Каждое утро бариста обновляет «меню дня» — короткий список того, что сегодня особенно советуют гостям. Экран для него ещё рисует дизайнер, поэтому пока меню просто выводится в консоль.

Твой коллега начал эту задачу, но не успел закончить. Тебе нужно доделать: дописать недостающие позиции. И ещё одна просьба от бариста: «Тыквенный латте сегодня закончился, уберите его из меню. Но завтра сироп привезут — так что совсем удалять не надо».

### Новое в Swift
**Команды выполняются по порядку.** Каждая команда `print` выводит свой текст с новой строки. Какой порядок команд в коде — такой порядок строк на экране:

```swift
print("Доброе утро!")
print("Кофейня открыта")
```

Сначала появится «Доброе утро!», под ним — «Кофейня открыта».

**Комментарии.** Всё, что написано в строке после двух косых черт `//`, Swift пропускает. Это заметки для людей: для коллег и для себя в будущем.

```swift
// Приветствие для утренней смены
print("Доброе утро!")
```

У комментариев есть ещё одно полезное применение. Если поставить `//` перед командой, она превратится в комментарий и **перестанет выполняться**. Разработчики говорят: «закомментировать строку».

```swift
print("Кофейня открыта")
// print("Сегодня скидка 20%")
```

Здесь выведется только «Кофейня открыта». Строка про скидку осталась в коде, но спит. Когда она снова понадобится, достаточно стереть `//`. Так временно отключают код, который жалко удалять.

### Задача
В редакторе уже есть начало меню. Доделай его:

1. Под строкой с первым блюдом добавь ещё две команды `print`, чтобы в меню появились позиции `2. Круассан с миндалём` и `3. Сырники со сметаной`.
2. Строку с тыквенным латте **не удаляй**, а закомментируй — поставь перед ней `//`.

### Пример
Вот что должна вывести программа:

```text
Меню дня:
1. Раф лавандовый
2. Круассан с миндалём
3. Сырники со сметаной
```

```swift
// Допиши здесь ещё два блюда
```


## @rules
- mustraw: /\/\/\s*print\(\s*"4\. Тыквенный латте"\s*\)/ :: Строку с тыквенным латте нужно не удалить, а закомментировать: поставь `//` в её начале.

## @hint1
В задаче два отдельных дела.

Первое — дописать две команды вывода. Каждая позиция меню — это своя команда `print` на своей строке. Строки на экране появляются в том же порядке, в каком команды стоят в коде, поэтому новые команды должны оказаться между первым блюдом и тыквенным латте. Текст в кавычках пиши вместе с номером и точкой, как в примере: номер, точка, пробел, название.

Второе — отключить строку с тыквенным латте, не стирая её. Для этого в самом начале этой строки ставятся две косые черты. Всё, что после них, Swift перестанет выполнять.

## @hint2
Новая позиция в меню добавляется точно так же, как уже написанная первая:

```swift
print("2. Круассан с миндалём")
```

А вот так выглядит «уснувшая» команда — перед ней стоят две косые черты:

```swift
// print("Сегодня скидка 20%")
```

## @hint3
Допиши третье блюдо и отключи последнюю строку:

```swift
print("Меню дня:")
print("1. Раф лавандовый")
print("2. Круассан с миндалём")
print("___")
___ print("4. Тыквенный латте")
```

В первом пропуске — третья позиция из примера. Во втором — два символа, которые превращают команду в комментарий.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Swift идёт по коду сверху вниз. Он встречает четыре работающие команды `print` и выполняет их по очереди — получается четыре строки на экране, в том же порядке. Последнюю строку он пропускает целиком, потому что она начинается с `//`: для Swift это комментарий, а не команда.

**Почему не удалить строку совсем?** В настоящей работе код часто отключают на время: фича не готова, товар закончился, идёт поиск ошибки. Закомментированную строку легко вернуть — стёр две черты, и она снова работает. К тому же коллега, который откроет файл завтра, увидит, что тыквенный латте не забыли, а отключили намеренно.

**Типичные ошибки:**

- новые команды дописаны после строки с латте — тогда порядок на экране будет другим;
- комментарий поставлен не в начале, а в середине строки — например, после слова `print`. Тогда `print` останется без скобок и текста, и Swift сообщит об ошибке;
- вместо двух косых черт `//` поставлена одна или обратные `\\`.
