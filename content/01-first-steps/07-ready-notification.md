## @description

### Контекст
Когда бариста заканчивает готовить напиток, гостю приходит уведомление: «Заказ готов». Менеджер кофейни прислала текст, который хочет видеть в уведомлении, — три строки, причём слово «Выдача» обязательно в кавычках, как на табличке над стойкой.

Система уведомлений принимает текст **одним значением**. Нельзя отправить три отдельных сообщения — нужно собрать одну строку, внутри которой есть и переносы, и кавычки.

### Новое в Swift
**Перенос строки.** Чтобы внутри текста начать новую строку, используют специальную пару символов `\n` — обратная косая черта и латинская буква n (от слова new line, «новая строка»). На экране она не видна, а текст после неё переходит на следующую строку:

```swift
let note = "Спасибо за заказ!\nЖдём вас снова"
print(note)
```

```text
Спасибо за заказ!
Ждём вас снова
```

**Кавычки внутри текста.** Кавычка обозначает конец строки. Если нужна кавычка как обычный символ, перед ней ставят обратную черту: `\"`.

```swift
let sign = "Табличка \"Открыто\" на двери"
```

В `sign` окажется: `Табличка "Открыто" на двери`.

**Многострочная строка.** Когда строк много, удобнее писать текст так, как он должен выглядеть. Для этого есть тройные кавычки `"""`:

```swift
let note = """
Спасибо за заказ!
Табличка "Открыто" уже на двери.
Ждём вас снова
"""
```

Правила у такой записи простые:

- открывающие `"""` стоят в конце строки, текст начинается **с новой строки**;
- закрывающие `"""` тоже стоят **на отдельной строке**;
- переносы получаются сами — там, где ты нажала Enter;
- обычные кавычки внутри можно писать без черты;
- интерполяция `\( )` работает как обычно.

Оба способа дают одинаковый результат. Выбирай тот, который тебе удобнее.

### Задача
В редакторе есть данные заказа: `orderNumber` и `drink`. Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `message` и положи в неё текст уведомления **из трёх строк** — одной строкой типа `String`:
   - первая строка: слово `Заказ`, номер заказа и `готов!`;
   - вторая строка: название напитка и слова `ждёт вас у стойки "Выдача".` — слово «Выдача» в двойных кавычках, в конце точка;
   - третья строка: `Приятного дня!`
2. Выведи `message` одной командой `print(message)`.

### Пример
Для данных из редактора:

```text
Заказ 47 готов!
Раф лавандовый ждёт вас у стойки "Выдача".
Приятного дня!
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let orderNumber = 47
let drink = "Раф лавандовый"

// Собери текст уведомления в константу message (три строки в одном значении)
let message = """
Заказ \(orderNumber) готов!
\(drink) ждёт вас у стойки "Выдача".
Приятного дня!
"""

// Выведи message
print(message)
```

## @hint1
Весь текст уведомления должен лежать в одной константе `message`. Есть два способа уместить три строки в одно значение — выбери любой.

Первый способ — многострочная строка. После знака равенства ставишь три двойные кавычки и сразу нажимаешь Enter. Затем пишешь три строки уведомления так, как они должны выглядеть. После последней строки снова Enter и ещё три кавычки — отдельной строкой. Слово «Выдача» в этом способе пишется в обычных кавычках, ничего добавлять не надо.

Второй способ — обычная строка в одинарных двойных кавычках, где вместо каждого перехода на новую строку стоит `\n`, а перед каждой кавычкой вокруг слова «Выдача» — обратная черта.

В обоих случаях номер заказа и название напитка не пишутся буквами и цифрами, а вставляются интерполяцией — через `orderNumber` и `drink`.

Когда `message` готова, остаётся одна команда: вывести её.

## @hint2
Многострочная строка с интерполяцией и кавычками внутри выглядит так:

```swift
let table = 5
let note = """
Столик \(table) свободен.
Табличка "Резерв" снята.
"""
```

Открывающие и закрывающие тройные кавычки стоят на своих строках, а текст — между ними.

## @hint3
Первая строка уведомления готова. Допиши вторую и третью:

```swift
let message = """
Заказ \(orderNumber) готов!
\(___) ждёт вас у стойки "Выдача".
___
"""

print(___)
```

В первом пропуске — имя константы с названием напитка. Во втором — третья строка уведомления. В третьем — имя константы, которую нужно вывести.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Тройные кавычки открывают многострочную строку. Всё, что написано между ними, попадает в `message` вместе с переносами: там, где в коде новая строка, в тексте тоже будет новая строка. Вставки `\(orderNumber)` и `\(drink)` заменяются значениями. Кавычки вокруг слова «Выдача» — обычные символы: внутри тройных кавычек одиночная кавычка строку не закрывает.

**То же самое в одну строку.** Можно было написать так: `let message = "Заказ \(orderNumber) готов!\n\(drink) ждёт вас у стойки \"Выдача\".\nПриятного дня!"`. Здесь каждый перенос обозначен как `\n`, а каждая кавычка внутри текста — как `\"`. Результат одинаковый, но читать многострочный вариант намного легче. Поэтому длинные тексты обычно пишут через `"""`.

**Почему одна константа, а не три `print`.** Системе уведомлений нужен один готовый текст. Так бывает очень часто: текст письма, сообщение в чате, содержимое файла — всё это одна строка с переносами внутри.

**Типичные ошибки:**

- текст начат сразу после открывающих `"""`, в той же строке — Swift требует перейти на новую;
- закрывающие `"""` стоят в конце последней строки текста, а не на отдельной;
- в обычной строке забыта черта перед кавычкой — Swift решает, что строка закончилась на слове «стойки»;
- `/n` вместо `\n` — черта должна быть обратной.
