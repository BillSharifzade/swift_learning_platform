## @description

### Контекст
Покупатель открывает категорию, а товары ещё едут с сервера. Экрану нужно узнать момент, когда данные пришли: тогда он уберёт значок загрузки и покажет список.

В мобильной разработке это решают так: функции загрузки передают замыкание «что сделать, когда всё готово». У такого замыкания есть устоявшееся название — completion handler, «обработчик завершения».

Тимлид ставит задачу: «Напиши `loadCatalog`. Сервера пока нет, бери товары из словаря-заглушки. Но форма должна быть как в жизни: функция не возвращает список через `return`, а отдаёт его в замыкание».

### Новое в Swift
Ты уже передавала функцию в функцию. Параметр при этом имеет тип функции:

```swift
func checkPromoCode(_ code: String, onResult: (Bool) -> Void) {
    let isValid = code == "ЯРМАРКА10"
    onResult(isValid)
}
```

Параметр `onResult` принимает действие типа `(Bool) -> Void`: «получает `Bool` и ничего не возвращает». Слово `Void` означает «пусто», его пишут на месте типа результата, когда результата нет. Внутри функции параметр вызывается как обычная функция: `onResult(isValid)`.

Раньше ты передавала в такой параметр имя готовой функции. Теперь можно обойтись без имени — написать **замыкание прямо в вызове**:

```swift
checkPromoCode("ЯРМАРКА10", onResult: { (isValid: Bool) -> Void in
    print("Промокод подошёл: \(isValid)")
})
```

Это работает, но хвост `})` выглядит тяжело. Поэтому в Swift есть особая запись — **trailing closure**, «замыкание в хвосте». Если замыкание — последний аргумент, его выносят за круглые скобки, а метку не пишут:

```swift
checkPromoCode("ЯРМАРКА10") { (isValid: Bool) -> Void in
    print("Промокод подошёл: \(isValid)")
}
```

Оба вызова делают одно и то же. Но второй читается как обычная фраза: «проверь промокод, а потом сделай вот это». В настоящих проектах почти всегда пишут именно так.

Проследи порядок событий:

1. Вызывается `checkPromoCode`, замыкание уезжает в параметр `onResult`.
2. Функция делает свою работу — сравнивает код.
3. Функция вызывает `onResult(isValid)` — и только теперь выполняется тело замыкания, а в `isValid` попадает результат.

> 💡 В настоящем приложении ответ сервера приходит не сразу, и замыкание вызывается позже — через секунду или две. У нас сервер ненастоящий, поэтому замыкание вызывается тут же. Но записывается всё точно так же.

### Задача
В редакторе есть словарь `serverCatalog` — он изображает сервер. Ключ — название категории, значение — названия товаров в ней.

1. Напиши функцию `loadCatalog` с двумя параметрами:
   - `category` типа `String` — название категории;
   - `completion` типа `([String]) -> Void` — замыкание, которое получит список товаров.

   Функция находит в `serverCatalog` товары этой категории и вызывает `completion`, передав ему список. Если такой категории нет, `completion` всё равно вызывается — с пустым массивом. Сама функция ничего не возвращает.
2. Вызови `loadCatalog` для категории `"Дом"`. Замыкание передай **в хвосте** — после круглых скобок. В замыкании выведи строку `Загружено товаров: N`, а под ней — каждое название с новой строки, начиная с `- `.

### Пример
Вывод программы:

```text
Загружено товаров: 3
- Плед вязаный
- Свеча соевая
- Кружка керамическая
```

## @solution
```swift
// "Сервер": названия товаров по категориям
let serverCatalog = [
    "Дом": ["Плед вязаный", "Свеча соевая", "Кружка керамическая"],
    "Еда": ["Мёд липовый", "Варенье малиновое"],
    "Украшения": ["Серьги из бисера"]
]

// 1. Напиши функцию loadCatalog(category:completion:)
func loadCatalog(category: String, completion: ([String]) -> Void) {
    let names = serverCatalog[category] ?? []
    completion(names)
}

// 2. Загрузи категорию "Дом": замыкание в хвосте выводит количество и названия
loadCatalog(category: "Дом") { (names: [String]) -> Void in
    print("Загружено товаров: \(names.count)")
    for name in names {
        print("- \(name)")
    }
}
```

## @rules
- must: /loadCatalog\s*\(\s*category\s*:\s*"[^"]*"\s*\)\s*\{/ :: Вызови `loadCatalog` с замыканием в хвосте — оно пишется после круглых скобок: `loadCatalog(category: "Дом") { ... }`.

## @hint1
Начни с функции. У неё два параметра. Первый — обычная строка с названием категории. Второй называется `completion`, и его тип — тип функции: в круглых скобках массив строк, потом стрелка, потом `Void`. Типа результата у самой `loadCatalog` нет — она ничего не возвращает.

В теле функции два шага. Первый: достать список из словаря `serverCatalog` по ключу `category`. Вспомни, что чтение из словаря по ключу даёт опционал — такой категории может не быть. На этот случай нужен запасной вариант: пустой массив. Тебе знакомы два способа: оператор `??` или чтение с `default:`. Второй шаг: вызвать `completion`, как обычную функцию, и передать ему список.

Теперь вызов. Пишешь `loadCatalog`, в круглых скобках — только категория. Скобки закрываются, и сразу после них открывается фигурная скобка замыкания. В заголовке замыкания — параметр, в который придёт список (назови его, например, `names`), его тип, стрелка, `Void` и слово `in`. В теле — `print` с количеством через `count` и цикл `for` по названиям.

## @hint2
Функция, которая принимает замыкание и вызывает его с результатом, выглядит так:

```swift
func checkPromoCode(_ code: String, onResult: (Bool) -> Void) {
    let isValid = code == "ЯРМАРКА10"
    onResult(isValid)
}
```

А так её вызывают с замыканием в хвосте:

```swift
checkPromoCode("ЯРМАРКА10") { (isValid: Bool) -> Void in
    print("Промокод подошёл: \(isValid)")
}
```

У тебя вместо `Bool` будет массив строк `[String]`. Список для категории можно достать так: `serverCatalog[category] ?? []`.

В первом пропуске — что вернуть, если категории нет. Во втором — что передать замыканию. В третьем — количество элементов в массиве `names`.

## @hint4
Вот готовое решение:

{{solution}}

**Как устроена функция.** `serverCatalog[category]` возвращает опционал: по такому ключу может ничего не быть. Оператор `??` подставляет пустой массив, и в `names` всегда лежит настоящий `[String]`. Затем `completion(names)` вызывает замыкание, которое передали снаружи. Что именно оно сделает со списком, функция не знает — и не должна знать. Её дело — добыть данные и отдать их.

**Как устроен вызов.** `loadCatalog(category: "Дом") { ... }` — это вызов с двумя аргументами. Первый стоит в скобках, второй — замыкание после скобок. Метку `completion:` при такой записи не пишут. Параметр `names` в заголовке замыкания — это то самое значение, которое функция передала в `completion(names)`. Имена совпадают случайно: в замыкании параметр можно назвать как угодно.

**Почему `completion` вызывается даже для пустого списка.** Экран показывает значок загрузки и ждёт ответа. Если функция промолчит, значок будет крутиться вечно. Пустой массив — тоже ответ: «загрузка закончилась, товаров нет».

**Почему не `return`.** Сейчас результат можно было бы просто вернуть. Но настоящий сервер отвечает не сразу, и к моменту ответа функция давно завершилась — возвращать уже некуда. Замыкание решает эту проблему: его можно вызвать когда угодно. Поэтому такую форму стоит освоить заранее.

**Типичные ошибки:**

- замыкание написано внутри круглых скобок без метки `completion:` — Swift не поймёт, к какому параметру оно относится;
- в функции забыт вызов `completion(...)` — список найден, но никому не отдан, и на экране пусто;
- `completion` вызывается только внутри `if let` — тогда для неизвестной категории ответа не будет вовсе;
- забыто слово `in` после заголовка замыкания.
