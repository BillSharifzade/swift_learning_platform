## @description

### Контекст
В «Волне» есть эквалайзер: ползунки, которыми пользователь подстраивает звук под себя. У каждой полосы — «Бас», «Средние», «Высокие», «Вокал» — свой уровень в децибелах.

Настройки хранятся в словаре `equalizer`: ключ — название полосы, значение — её уровень. Хранятся экономно: в словаре есть только те полосы, которые пользователь менял. Если полосы в словаре нет, её уровень равен нулю. Поэтому сбросить полосу — значит удалить её запись.

В трекере задача от дизайнера: «Обработать действия на экране эквалайзера и показать сводку — сколько полос настроено и какие именно, по алфавиту».

### Новое в Swift
Читать и записывать значения словаря ты уже умеешь. Осталось научиться удалять записи и смотреть на словарь целиком.

```swift
var unread = ["Семья": 3, "Работа": 12, "Йога": 1]
```

Это счётчики непрочитанных сообщений по чатам.

**Изменить значение** — та же запись по ключу, что и раньше. Ключ уже есть, поэтому старое значение заменяется:

```swift
unread["Семья"] = 5
```

**Удалить запись** — `removeValue(forKey:)`. Исчезает вся пара — и ключ, и значение:

```swift
unread.removeValue(forKey: "Йога")
```

Если такого ключа нет, ничего страшного не случится: словарь просто останется прежним. Этим он отличается от массива, где удаление по несуществующему индексу останавливает программу.

**Сколько записей** — знакомое `count`. Есть у словаря и `isEmpty`:

```swift
print(unread.count)   // 2
```

**Все ключи** — свойство `keys`. И здесь главная особенность словаря: **у него нет порядка**. Словарь устроен так, чтобы мгновенно находить значение по ключу, а за порядком пар он не следит. Если напечатать словарь или его ключи как есть, порядок может оказаться любым — и измениться при следующем запуске.

Поэтому ключи перед показом всегда сортируют. Команда `sorted()` возвращает обычный массив:

```swift
print(unread.keys.sorted())   // ["Работа", "Семья"]
```

> ⚠️ Никогда не рассчитывай на порядок пар в словаре. Нужен предсказуемый список — бери `keys.sorted()`. Нужно конкретное значение — читай его по ключу с `default:`.

### Задача
В редакторе есть словарь `equalizer` и данные о действиях пользователя. Не переименовывай их — проверка подставит другие данные.

Сначала три действия:

1. Пользователь передвинул ползунок полосы `movedBand`: запиши для неё уровень `movedLevel`.
2. Пользователь нажал «Сбросить» на полосе `resetBand`: удали её запись из словаря.
3. Пользователь нажал кнопку «Больше баса»: увеличь уровень полосы `"Бас"` на 2. Если этой полосы в словаре нет, отсчёт идёт от нуля.

Затем сводка из четырёх строк:

4. `Настроено полос:` и количество записей в словаре.
5. `Полосы:` и массив названий полос по алфавиту.
6. Название из `movedBand`, двоеточие, её уровень и `дБ`.
7. То же самое для `resetBand`. Если полосы нет в словаре, её уровень равен 0.

### Пример
Для данных из редактора:

```text
Настроено полос: 2
Полосы: ["Бас", "Средние"]
Средние: 1 дБ
Высокие: 0 дБ
```

Полосу «Средние» передвинули на 1, «Высокие» сбросили, а «Бас» вырос с 4 до 6.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
var equalizer = ["Бас": 4, "Средние": -2, "Высокие": 3]
let movedBand = "Средние"
let movedLevel = 1
let resetBand = "Высокие"

// 1. Ползунок: запиши movedLevel для полосы movedBand
equalizer[movedBand] = movedLevel

// 2. «Сбросить»: удали запись полосы resetBand
equalizer.removeValue(forKey: resetBand)

// 3. «Больше баса»: прибавь 2 к полосе "Бас"
equalizer["Бас", default: 0] += 2

// 4. Выведи, сколько полос настроено
print("Настроено полос: \(equalizer.count)")

// 5. Выведи названия полос по алфавиту
print("Полосы: \(equalizer.keys.sorted())")

// 6. Выведи уровень полосы movedBand
print("\(movedBand): \(equalizer[movedBand, default: 0]) дБ")

// 7. Выведи уровень полосы resetBand (если её нет в словаре — 0)
print("\(resetBand): \(equalizer[resetBand, default: 0]) дБ")
```

## @rules
- must: /\bsorted\s*\(/ :: Порядок ключей в словаре случаен. Перед выводом отсортируй их: `equalizer.keys.sorted()`.

## @hint1
В задаче семь строк кода: три меняют словарь, четыре печатают сводку. Иди по комментариям сверху вниз — порядок действий важен.

Первое действие — запись значения по ключу. Ты делала это в прошлой задаче: слева словарь с ключом в квадратных скобках, справа новое значение. Изменение существующего значения и добавление нового записываются одинаково.

Второе действие — удаление. Для него у словаря есть команда `removeValue`, а ключ передаётся с меткой `forKey`. Обрати внимание: записать полосе ноль — это не то же самое. Запись должна исчезнуть, чтобы количество настроенных полос уменьшилось.

Третье действие — знакомый счётчик: чтение с запасным значением ноль, соединённое с оператором «прибавить и записать». Ключ здесь — текст «Бас» в кавычках.

В сводке количество записей — это `count`. Список полос — ключи словаря, обязательно отсортированные: без сортировки порядок будет случайным, и проверка то пройдёт, то нет. Две последние строки читают уровень по ключу с запасным значением ноль — оно сработает для сброшенной полосы.

## @hint2
Вот новые команды на другом словаре:

```swift
var unread = ["Семья": 3, "Работа": 12, "Йога": 1]

unread["Семья"] = 5                   // изменить значение
unread.removeValue(forKey: "Йога")    // удалить запись

print("Чатов: \(unread.count)")           // Чатов: 2
print("Чаты: \(unread.keys.sorted())")    // Чаты: ["Работа", "Семья"]
```

В твоей задаче ключами в первых двух действиях служат константы `movedBand` и `resetBand`.

## @hint3
Действия со словарём и начало сводки почти готовы. Заполни пропуски:

```swift
equalizer[movedBand] = movedLevel
equalizer.removeValue(forKey: ___)
equalizer["Бас", default: 0] += ___

print("Настроено полос: \(equalizer.___)")
print("Полосы: \(equalizer.keys.___())")
print("\(movedBand): \(equalizer[movedBand, default: 0]) дБ")
print("\(resetBand): \(equalizer[___, default: 0]) дБ")
```

В первом пропуске — константа с полосой, которую сбросили. Во втором — на сколько растёт бас. В третьем — свойство с количеством записей. В четвёртом — команда сортировки. В пятом — ключ, по которому читается уровень сброшенной полосы.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Проследим за словарём из редактора. Сначала в нём три полосы: «Бас» 4, «Средние» -2, «Высокие» 3. Запись `equalizer[movedBand] = movedLevel` меняет «Средние» на 1. `removeValue(forKey: resetBand)` удаляет пару «Высокие» целиком — записей остаётся две. Строка с `+=` читает уровень баса (4), прибавляет 2 и записывает 6.

В сводке `equalizer.count` даёт 2. `equalizer.keys.sorted()` берёт все ключи и возвращает их массивом по алфавиту. Последняя строка читает уровень полосы «Высокие»: записи уже нет, поэтому срабатывает `default: 0`. Это и есть правило «нет в словаре — значит, ноль».

**Почему сброс — это удаление, а не запись нуля.** По смыслу уровень в обоих случаях нулевой. Но в словаре хранятся только настроенные полосы, и строка «Настроено полос» считает записи. Если записать ноль, полоса останется в словаре и попадёт в счёт и в список.

**Почему обязательно `sorted()`.** Словарь не хранит порядок. Без сортировки ключи могут прийти как `["Средние", "Бас"]`, а при следующем запуске — наоборот. Пользователь увидел бы прыгающий список, а проверка проходила бы через раз.

**Почему порядок действий важен.** В одном из сценариев пользователь сбрасывает бас, а потом жмёт «Больше баса». Если сначала прибавить, а потом удалить, баса в словаре не останется. А правильно — запись удаляется и создаётся заново: 0 + 2.

**Типичные ошибки:**

- `equalizer[resetBand] = 0` вместо удаления — полоса остаётся в словаре;
- `equalizer.removeValue(resetBand)` без метки `forKey:` — Swift не соберёт программу;
- `equalizer.keys` без `sorted()` — порядок случайный;
- `equalizer["Бас"] += 2` без `default:` — Swift не уверен, что такой ключ есть;
- `equalizer[resetBand]` без `default:` в последней строке — напечатается `nil` вместо нуля.
