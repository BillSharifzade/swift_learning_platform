## @description

### Контекст
Ты в команде «Ложки» — сервиса доставки еды из ресторанов. У каждого ресторана есть минимальная сумма заказа: везти одну порцию супа через весь город невыгодно.

Тимлид просит доработать экран корзины: «Если гость набрал меньше минимума, покажи, сколько рублей не хватает. Если набрал достаточно — ничего лишнего не показывай».

До сих пор твои программы выполняли все команды подряд. Сейчас программа впервые должна **принять решение**: выводить строку или нет.

### Новое в Swift
В прошлом модуле ты сравнивала значения и получала ответ `true` или `false`. Теперь этим ответом можно воспользоваться: выполнить часть кода только тогда, когда ответ — `true`. Для этого есть слово `if` («если»):

```swift
let cookingMinutes = 50

if cookingMinutes > 40 {
    print("Кухня загружена, готовить будут дольше обычного")
}
```

Читается так: «если время готовки больше 40, выведи предупреждение».

Запись состоит из трёх частей:

- слово `if`;
- **условие** — любое выражение, которое даёт `Bool`: сравнение, `isEmpty`, несколько проверок через `&&` или `||`. Скобки вокруг условия не нужны;
- **блок** в фигурных скобках `{ }` — команды, которые выполнятся, только если условие истинно. Команд может быть сколько угодно.

Если условие ложно, Swift перепрыгивает через блок и идёт дальше. А код **после** закрывающей скобки выполняется в любом случае:

```swift
let itemsInCart = 0

print("Корзина")
if itemsInCart == 0 {
    print("Здесь пока пусто")
}
print("Вернуться в меню")
```

При `itemsInCart = 0` на экране три строки. При `itemsInCart = 2` — только первая и последняя: условие ложно, и средняя строка пропущена.

Команды внутри блока сдвигают вправо на четыре пробела. Это называется **отступ**. Swift на него не смотрит, но человеку сразу видно, какие строки зависят от условия. Редактор обычно ставит отступ сам, когда ты нажимаешь Enter после `{`.

И ещё одна деталь, которая пригодится в задаче. Внутри `\( )` можно написать не только имя, но и целое выражение. Swift сначала посчитает его, а потом вставит результат: `"Осталось \(60 - cookingMinutes) мин."`

> ⚠️ Проверка на равенство — это два знака: `==`. Один знак `=` кладёт значение в переменную, и в условии Swift его не примет.

### Задача
В редакторе есть сумма заказа `orderTotal` и минимальная сумма ресторана `minimumOrder`. Первая строка корзины уже выводится. Не переименовывай данные — проверка подставит в них другие значения.

1. После готового `print` напиши условие: если `orderTotal` **меньше** `minimumOrder`, выведи строку `До минимального заказа не хватает N руб.` Вместо N должна стоять разница между минимальной суммой и суммой заказа — её считает программа.
2. Если сумма заказа равна минимальной или больше неё, вторая строка появляться не должна.

### Пример
Для данных из редактора (заказ на 540 руб. при минимуме 700 руб.):

```text
Сумма заказа: 540 руб.
До минимального заказа не хватает 160 руб.
```

А если бы гость набрал ровно 700 руб., на экране осталась бы одна строка:

```text
Сумма заказа: 700 руб.
```

## @starter
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let orderTotal = 540
let minimumOrder = 700

print("Сумма заказа: \(orderTotal) руб.")

// Если сумма меньше минимальной — выведи, сколько не хватает

```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let orderTotal = 540
let minimumOrder = 700

print("Сумма заказа: \(orderTotal) руб.")

// Если сумма меньше минимальной — выведи, сколько не хватает
if orderTotal < minimumOrder {
    print("До минимального заказа не хватает \(minimumOrder - orderTotal) руб.")
}
```

## @rules
- must: /\bif\b/ :: Предупреждение должно появляться не всегда, а только когда сумма меньше минимальной. Для этого нужно условие `if`.

## @hint1
Тебе нужно одно условие и одна команда `print` внутри него.

Сначала реши, какой вопрос программа задаёт: «сумма заказа меньше минимальной?». Это обычное сравнение двух констант знаком «меньше» — такие ты уже писала в прошлом модуле. Оно и станет условием после слова `if`.

Дальше идёт блок в фигурных скобках. В нём — команда `print` с текстом предупреждения. Число в этом тексте нельзя писать цифрами: оно зависит от данных. Сколько не хватает? Столько, на сколько минимальная сумма больше суммы заказа, то есть нужна разность. Посчитай её прямо во вставке `\( )` или заранее положи в отдельную константу.

Обрати внимание на знак сравнения. Если гость набрал ровно минимальную сумму, заказ уже можно оформить — предупреждение не нужно. Значит, подходит строгое «меньше», а не «меньше или равно».

## @hint2
Условие записывается так: слово `if`, сравнение, а затем блок в фигурных скобках.

```swift
let cookingMinutes = 50

if cookingMinutes > 40 {
    print("Готовка задержится на \(cookingMinutes - 40) мин.")
}
```

У тебя вместо времени готовки сравниваются `orderTotal` и `minimumOrder`, а во вставке стоит их разность. Подумай, что из чего нужно вычесть, чтобы число получилось положительным.

## @hint3
Каркас готов, осталось заполнить пропуски:

```swift
if orderTotal ___ minimumOrder {
    print("До минимального заказа не хватает \(___ - ___) руб.")
}
```

В первом пропуске — знак сравнения: предупреждение нужно, когда заказ меньше минимума. Во вставке — разность: из большего числа вычитается меньшее.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Swift доходит до строки с `if` и вычисляет условие `orderTotal < minimumOrder`. Для данных из редактора это `540 < 700`, то есть `true`. Раз условие истинно, выполняется блок в фигурных скобках: вставка `\(minimumOrder - orderTotal)` считает `700 - 540` и подставляет `160`. Если бы в корзине было 1250 руб., условие дало бы `false`, и Swift просто пропустил бы блок целиком.

**Почему именно `<`, а не `<=`.** Минимальная сумма — это порог, с которого заказ уже принимается. При заказе ровно на 700 руб. гостю ничего докупать не надо. С условием `<=` он увидел бы странную строку «не хватает 0 руб.». Граничное значение — самое частое место ошибок в условиях, поэтому проверка отдельно запускает твой код с суммой, равной минимальной.

**Почему число не написано цифрами.** Строка `print("... не хватает 160 руб.")` верна только для одного заказа. Корзина у каждого гостя своя, поэтому разность считает программа.

**Типичные ошибки:**

- перепутан порядок в разности: `orderTotal - minimumOrder` даст `-160`;
- `print` с предупреждением стоит после закрывающей скобки `}` — тогда он не зависит от условия и выполняется всегда;
- забыта закрывающая скобка блока;
- условие взято в кавычки: `if "orderTotal < minimumOrder"` — это уже не сравнение, а просто текст.
