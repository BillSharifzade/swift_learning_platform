## @description

### Контекст
Когда ресторан собрал заказ, «Ложка» находит ближайшего свободного курьера и решает, можно ли отдать заказ именно ему. Руководитель службы доставки описал правила в трекере задач:

- Курьер **на машине** возит заказы до 30 кг включительно. Погода ему не мешает.
- Курьер **на велосипеде** возит заказы до 10 кг включительно и только когда нет дождя. В дождь или с тяжёлым заказом нужен курьер на машине.

Смотри, как устроены эти правила: сначала нужно узнать, на чём едет курьер, и только потом понятно, что проверять дальше. Одно решение зависит от другого.

### Новое в Swift
Внутри блока `if` или `else` можно писать любые команды. В том числе ещё один `if`. Такое условие называется **вложенным**:

```swift
let isKitchenOpen = true
let freeCooks = 0

if isKitchenOpen {
    if freeCooks > 0 {
        print("Заказ принят, начинаем готовить")
    } else {
        print("Заказ принят, но придётся подождать")
    }
} else {
    print("Кухня закрыта, заказы не принимаются")
}
```

Сначала Swift проверяет внешнее условие — открыта ли кухня. Внутреннее условие про поваров он проверит, только если попал в первый блок. При закрытой кухне до поваров дело вообще не дойдёт.

На что обратить внимание:

- **Отступы.** Каждый уровень вложенности — ещё четыре пробела вправо. По отступам сразу видно, какой `else` к какому `if` относится.
- **Скобки.** У каждой открывающей `{` своя закрывающая `}`. Внутренний блок должен закрыться раньше внешнего. Удобный приём: сначала написать `if ... { } else { }` целиком, а потом заполнять блоки.
- **Свой набор проверок в каждой ветке.** Во внешнем `else` тоже может быть вложенное условие, причём совсем другое.

**Вкладывать или соединять?** Ты уже знаешь операторы `&&` («и») и `||` («или»). Когда несколько проверок ведут к **одному и тому же** итогу, их удобнее соединить в одном условии:

```swift
let isHoliday = false
let guests = 9

if isHoliday || guests > 8 {
    print("Столик лучше забронировать заранее")
}
```

А когда от первой проверки зависит, **что проверять дальше**, — условия вкладывают друг в друга. В этой задаче пригодятся оба способа.

> 💡 Не увлекайся глубиной. Два уровня читаются легко, три — уже с трудом. Если условия уходят всё дальше вправо, это знак, что код пора упростить.

### Задача
В редакторе есть данные: `transport` — на чём едет курьер (`"car"` — машина, любое другое значение — велосипед), `isRaining` — идёт ли дождь, `orderWeight` — вес заказа в килограммах. Первая строка уже выводится. Не переименовывай данные — проверка подставит другие значения.

Напиши внешнее условие `if` / `else`, которое проверяет транспорт, а внутри каждой ветки — своё вложенное условие:

1. Курьер на машине (`transport` равно `"car"`):
   - заказ весит 30 кг или меньше — выведи `Назначен курьер на машине`;
   - иначе — `Отказ: заказ тяжелее 30 кг`.
2. Курьер на велосипеде (всё остальное):
   - идёт дождь **или** заказ тяжелее 10 кг — выведи `Отказ: нужен курьер на машине`;
   - иначе — `Назначен курьер на велосипеде`.

### Пример
Для данных из редактора (велосипед, дождя нет, 6 кг):

```text
Вес заказа: 6 кг
Назначен курьер на велосипеде
```

Если бы тот же заказ достался велокурьеру в дождь:

```text
Вес заказа: 6 кг
Отказ: нужен курьер на машине
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let transport = "bike"
let isRaining = false
let orderWeight = 6

print("Вес заказа: \(orderWeight) кг")

// Внешнее условие: курьер на машине ("car") или на велосипеде?
// Внутри каждой ветки — своя проверка веса и погоды
if transport == "car" {
    if orderWeight <= 30 {
        print("Назначен курьер на машине")
    } else {
        print("Отказ: заказ тяжелее 30 кг")
    }
} else {
    if isRaining || orderWeight > 10 {
        print("Отказ: нужен курьер на машине")
    } else {
        print("Назначен курьер на велосипеде")
    }
}
```

## @hint1
Начни с каркаса — внешней развилки. Она отвечает на один вопрос: курьер на машине? Это сравнение `transport` со строкой `"car"` через двойной знак равенства. Напиши `if` с этим условием, блок, затем `else` и второй блок. Пока оба блока пустые, убедись, что все четыре фигурные скобки на месте.

Теперь заполни первый блок — для машины. В нём своя маленькая развилка `if` / `else`: вес заказа не больше 30 — один текст, иначе — другой. Погоду здесь проверять не нужно.

Потом второй блок — для велосипеда. В нём тоже `if` / `else`, но условие составное. Отказ получается в двух случаях: идёт дождь или заказ тяжелее 10 кг. Итог у обоих случаев один, поэтому проверки соединяются оператором «или». В `else` остаётся удачный вариант: дождя нет и вес подходит.

Следи за отступами: внутренние `if` сдвинуты на четыре пробела, их `print` — на восемь.

## @hint2
Вложенное условие — это обычный `if` / `else` внутри блока другого `if`:

```swift
let isKitchenOpen = true
let freeCooks = 0

if isKitchenOpen {
    if freeCooks > 0 {
        print("Заказ принят, начинаем готовить")
    } else {
        print("Заказ принят, но придётся подождать")
    }
} else {
    print("Кухня закрыта, заказы не принимаются")
}
```

В твоём решении вложенная развилка будет в обеих ветках: и после `if transport == "car"`, и после `else`.

## @hint3
Ветка для машины готова. Допиши ветку для велосипеда:

```swift
if transport == "car" {
    if orderWeight <= 30 {
        print("Назначен курьер на машине")
    } else {
        print("Отказ: заказ тяжелее 30 кг")
    }
} else {
    if ___ || ___ {
        print("Отказ: нужен курьер на машине")
    } else {
        print("___")
    }
}
```

В первых двух пропусках — две причины отказа: константа про дождь и сравнение веса с 10. В третьем — текст для случая, когда велокурьер может взять заказ.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Для данных из редактора `transport` равен `"bike"`, поэтому внешнее условие `transport == "car"` ложно, и Swift переходит во внешний `else`. Там его ждёт вложенное условие `isRaining || orderWeight > 10`. Дождя нет, 6 не больше 10 — обе части ложны, значит, ложно и всё условие. Срабатывает внутренний `else`, и на экране появляется «Назначен курьер на велосипеде». Вложенное условие в первой ветке — про 30 кг — Swift при этом даже не читает.

**Почему здесь вложенность.** У машины и у велосипеда разные правила: разный предел веса, и дождь важен только для велосипеда. Сначала нужно понять, какой набор правил действует, и уже внутри него принимать решение. Именно так и читается код: «если машина, то смотрим вес; иначе смотрим дождь и вес».

**Почему в велосипедной ветке `||`.** Дождь и лишний вес — две разные причины, но итог у них один: нужна машина. Когда хватает любой из причин, проверки соединяют оператором «или». С оператором `&&` отказ получался бы, только если идёт дождь и заказ тяжёлый одновременно, — а лёгкий заказ в дождь уехал бы на велосипеде.

**Почему строка сравнивается в кавычках.** `transport` — это текст, и сравнивать его можно только с текстом: `"car"`. Без кавычек Swift стал бы искать константу с именем `car`.

**Типичные ошибки:**

- потеряна закрывающая скобка внутреннего блока — чаще всего перед внешним `else`;
- `orderWeight < 30` вместо `<= 30` — заказ ровно в 30 кг получает отказ, хотя по правилам его можно везти;
- `orderWeight >= 10` в велосипедной ветке — тогда заказ ровно в 10 кг уходит на машину;
- проверка дождя добавлена и в ветку для машины, хотя машине погода не мешает.
