## @description

### Контекст
В «Волне» есть экран «Далее» — очередь воспроизведения. Это массив треков: тот, что стоит первым (индекс `0`), играет прямо сейчас, остальные ждут своей очереди.

Очередь живая: пользователь добавляет треки, переставляет их, убирает. В трекере появился тикет: «Очередь: обработать пять действий пользователя». Коллега уже расставил в коде команды `print(queue)` после каждого действия, чтобы было видно, как меняется очередь. Сами действия предстоит написать тебе.

### Новое в Swift
Массив можно менять — но только если он объявлен через `var`. С массивом в `let` ни одна из команд ниже не сработает.

```swift
var orders = ["Латте", "Раф", "Какао"]
```

Все команды пишутся через точку после имени массива. Такие команды называют **методами** — это слово встретится тебе в объяснениях ошибок.

**Добавить в конец** — `append`:

```swift
orders.append("Чай")
// ["Латте", "Раф", "Какао", "Чай"]
```

**Вставить в нужное место** — `insert`. В скобках два значения: что вставить и индекс, на котором оно должно оказаться:

```swift
orders.insert("Эспрессо", at: 0)
// ["Эспрессо", "Латте", "Раф", "Какао", "Чай"]
```

Значения в скобках называют **аргументами**. Слово `at:` перед индексом — это **метка аргумента**. У многих команд Swift аргументы снабжены метками, чтобы код читался как фраза: «вставь эспрессо на место 0». Метка — часть команды, пропускать её нельзя.

**Удалить по индексу** — `remove(at:)`:

```swift
orders.remove(at: 2)
// убрали "Раф": ["Эспрессо", "Латте", "Какао", "Чай"]
```

**Удалить последний** — `removeLast()`:

```swift
orders.removeLast()
// убрали "Чай": ["Эспрессо", "Латте", "Какао"]
```

**Заменить элемент** — присвоить новое значение по индексу. Количество элементов при этом не меняется:

```swift
orders[1] = "Капучино"
// ["Эспрессо", "Капучино", "Какао"]
```

> 💡 После вставки и удаления элементы сдвигаются, и их индексы меняются. В примере выше «Латте» сначала имел индекс `0`, а после вставки эспрессо — уже `1`. Поэтому каждый раз думай о том, как массив выглядит **в этот момент**.

> ⚠️ Правило про границы действует и здесь: `remove(at:)` и замена по индексу, которого нет, аварийно останавливают программу. То же случится, если вызвать `removeLast()` у пустого массива.

### Задача
В редакторе есть очередь `queue` и три трека: `addedTrack`, `nextTrack` и `liveVersion`. Не переименовывай их — проверка подставит другие данные. Команды `print(queue)` уже стоят на местах, не убирай их.

Напиши пять действий, каждое — одной строкой на своём месте:

1. Пользователь нажал «Добавить в очередь»: поставь `addedTrack` в конец очереди.
2. Пользователь нажал «Играть следующим»: вставь `nextTrack` сразу после играющего трека, то есть на место с индексом `1`.
3. Играющий трек закончился: убери из очереди первый элемент.
4. Пользователь нажал «Другая версия» на треке, который теперь играет: замени первый элемент очереди на `liveVersion`.
5. Пользователь нажал «Убрать последний»: удали последний трек очереди.

И в самом конце:

6. Выведи `В очереди треков:` и количество треков, которые остались.

Для данных из редактора:


## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
var queue = ["Северное сияние", "Кофе и дождь", "Последний трамвай"]
let addedTrack = "Письма на песке"
let nextTrack = "Танцуй до утра"
let liveVersion = "Танцуй до утра (концерт)"

// 1. «Добавить в очередь»: addedTrack — в конец очереди
queue.append(addedTrack)
print(queue)

// 2. «Играть следующим»: nextTrack — на место с индексом 1
queue.insert(nextTrack, at: 1)
print(queue)

// 3. Играющий трек закончился: убери первый элемент
queue.remove(at: 0)
print(queue)

// 4. «Другая версия»: замени первый элемент на liveVersion
queue[0] = liveVersion
print(queue)

// 5. «Убрать последний»: удали последний трек
queue.removeLast()
print(queue)

// 6. Выведи, сколько треков осталось в очереди
print("В очереди треков: \(queue.count)")
```

## @hint1
В этой задаче шесть коротких строк — по одной под каждым комментарием. Команды `print(queue)` трогать не нужно: они покажут очередь после каждого твоего действия, и по выводу сразу видно, какой шаг сработал не так.

Для каждого действия пользователя есть своя команда массива. Добавить в конец — `append`. Вставить на конкретное место — `insert`, у него два аргумента: что вставить и индекс с меткой `at`. Убрать элемент по индексу — `remove`, и у него индекс тоже идёт с меткой `at`. Заменить элемент — обычное присваивание, только слева стоит не просто имя массива, а имя с индексом в квадратных скобках. Убрать последний — `removeLast` с пустыми круглыми скобками.

Следи за индексами. «Сразу после играющего трека» — это индекс один, потому что играющий трек стоит на нулевом месте. «Первый элемент» в шагах три и четыре — это индекс ноль. В шаге четыре первым уже стоит другой трек: предыдущий ты только что убрала.

Последняя строка — обычный `print` с текстом и количеством элементов.

## @hint2
Все команды вызываются через точку после имени массива. Вот как они выглядят на другом примере:

```swift
var orders = ["Латте", "Раф", "Какао"]

orders.append("Чай")              // в конец
orders.insert("Эспрессо", at: 0)  // на место с индексом 0
orders.remove(at: 2)              // убрать элемент с индексом 2
orders[1] = "Капучино"            // заменить элемент с индексом 1
orders.removeLast()               // убрать последний
```

В твоей задаче те же пять команд идут в том же порядке, только массив называется `queue`, а индексы и значения — свои.

## @hint3
Первые два действия готовы. Допиши остальные:

```swift
queue.append(addedTrack)
print(queue)

queue.insert(nextTrack, at: 1)
print(queue)

queue.remove(at: ___)
print(queue)

queue[___] = ___
print(queue)

queue.___()
print(queue)

print("В очереди треков: \(queue.count)")
```

В шагах три и четыре речь о первом элементе — вспомни его индекс. Справа от знака равенства — константа с новой версией трека. В последнем пропуске — название команды, которая убирает последний элемент.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Проследим за очередью из редактора. Сначала в ней три трека. `append` ставит «Письма на песке» в конец — треков четыре. `insert(nextTrack, at: 1)` ставит «Танцуй до утра» на место с индексом `1`, а всё, что стояло начиная с этого места, сдвигается вправо — треков пять. `remove(at: 0)` убирает «Северное сияние», и остальные сдвигаются влево: теперь индекс `0` у трека «Танцуй до утра». Поэтому `queue[0] = liveVersion` заменяет именно его. Наконец, `removeLast()` убирает «Письма на песке».

**Почему важен порядок.** Каждая команда работает с массивом в его текущем состоянии. Индекс `0` в шаге три и индекс `0` в шаге четыре — это разные треки, потому что между ними массив изменился. Если поменять шаги местами, результат будет другим.

**Почему `queue` объявлена через `var`.** Все пять команд меняют массив. Массив в константе `let` менять нельзя — Swift не соберёт программу. А вот `addedTrack`, `nextTrack` и `liveVersion` не меняются, поэтому они константы.

**Типичные ошибки:**

- `queue.insert(nextTrack, 1)` или `queue.remove(0)` без метки `at:` — Swift не узнает команду и скажет, что аргументы не подходят;
- `queue.insert(nextTrack, at: 0)` — так новый трек встанет перед играющим, а не после него;
- `queue.remove(at: 1)` в третьем шаге — первый элемент имеет индекс `0`;
- `queue.append(liveVersion)` в четвёртом шаге — это добавление, а нужна замена: количество треков при замене не меняется;
- `queue = [...]` с готовым списком — на данных из редактора это пройдёт, а на других очередях нет.
