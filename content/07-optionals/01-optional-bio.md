## @description

### Контекст
Ты в команде соцсети «Рядом» и делаешь экран профиля. У профиля есть обязательные поля — например, имя: без него нельзя зарегистрироваться. А есть необязательные: «О себе», город, сайт. Многие оставляют их пустыми.

Тимлид пишет в трекере: «Если человек ничего не рассказал о себе, покажем ему подсказку с просьбой заполнить поле. Для начала нужно научиться хранить поле, которого может не быть, и проверять, заполнено ли оно».

### Новое в Swift
До сих пор у каждой константы и переменной значение было всегда. Но как записать «значения нет»? Пустой строкой `""`? А если это возраст — нулём? Такие «особые значения» легко перепутать с настоящими: кто-нибудь забудет про договорённость и покажет на экране «Возраст: 0».

В Swift для этого есть честный способ — **опционал**. Это тип, который умеет хранить либо значение, либо «ничего». Записывается он как обычный тип с вопросительным знаком:

```swift
var website: String? = nil
```

- `String?` читается «строка или ничего».
- `nil` — специальное слово, которое означает «значения нет».

Удобно представлять опционал как **коробочку**. На ней написано, что в ней может лежать (`String`), а внутри — либо значение, либо пусто:

```swift
var website: String? = nil      // коробочка пуста
website = "bilol.example.ru"    // в коробочке появился текст
website = nil                   // снова пусто
```

Обычный тип так не умеет. В `String` значение есть всегда, и положить туда `nil` Swift не разрешит:

```swift
var name: String = nil          // ошибка
```

**Как узнать, есть ли значение.** Опционал можно сравнить с `nil` — получится `true` или `false`:

```swift
website == nil    // true, если коробочка пуста
website != nil    // true, если в ней что-то лежит
```

**Опционал в параметре функции.** Тип с вопросительным знаком можно указать и у параметра. Тогда в функцию можно передать и значение, и `nil`:

```swift
func hasWebsite(_ site: String?) -> Bool {
    return site != nil
}

hasWebsite("bilol.example.ru")  // true
hasWebsite(nil)                 // false
```

**Почему `print` показывает `Optional(...)`.** Если напечатать опционал как есть, получится неожиданное:

```swift
let website: String? = "bilol.example.ru"
print(website)
```

```text
Optional("bilol.example.ru")
```

Это не поломка. Swift напечатал коробочку целиком и честно показал: перед тобой не строка, а коробочка со строкой. Как доставать значение из коробочки, ты узнаешь в следующей задаче. А пока достаточно уметь проверять, пуста она или нет.

> 💡 Короткая запись `var website: String?` без `= nil` означает то же самое: переменная-опционал без начального значения сама получает `nil`.

### Задача
1. Объяви **переменную** `bio` типа `String?` со значением `nil` — пользователь пока ничего о себе не написал.
2. Напиши функцию `isFilled(_:)`. У неё один параметр типа `String?` без метки. Она возвращает `Bool`: `true`, если значение есть, и `false`, если передан `nil`.
3. Выведи строку `О себе заполнено: ` и результат вызова `isFilled(bio)`.
4. Пользователь рассказал о себе: положи в `bio` текст `Люблю горы и кофе`.
5. Ещё раз выведи ту же строку — теперь результат будет другим.

### Пример
Первую строку печатает готовый код из редактора, две другие — твой:

```text
Профиль: Билол
О себе заполнено: false
О себе заполнено: true
```

Вызовы функции:

```swift
isFilled(nil)                 // false
isFilled("Гуляю с собакой")   // true
```

## @solution
```swift
// Обязательное поле: имя есть у каждого пользователя
let userName: String = "Билол"
print("Профиль: \(userName)")

// 1. Объяви переменную bio типа String? — пока в ней ничего нет
var bio: String? = nil

// 2. Напиши функцию isFilled(_:) — заполнено ли необязательное поле
func isFilled(_ field: String?) -> Bool {
    return field != nil
}

// 3. Выведи "О себе заполнено: ..." с результатом isFilled(bio)
print("О себе заполнено: \(isFilled(bio))")

// 4. Пользователь рассказал о себе: положи в bio текст
bio = "Люблю горы и кофе"

// 5. Выведи ту же строку ещё раз
print("О себе заполнено: \(isFilled(bio))")
```

## @rules
- must: /\bvar\s+bio\s*:\s*String\s*\?/ :: Объяви `bio` как переменную опционального типа: `var bio: String? = nil`.

## @hint1
Иди по шагам из комментариев в редакторе.

Шаг первый. Поле «О себе» может быть пустым, поэтому обычный `String` не подойдёт — нужен тип с вопросительным знаком. Значение будет меняться, значит, это переменная, а не константа. Начальное значение — специальное слово, которое означает «значения нет».

Шаг второй. Функция принимает один параметр без метки, его тип — тоже строка с вопросительным знаком. Возвращает она `Bool`. Внутри достаточно одного сравнения: параметр «не равен» слову `nil`. Результат сравнения — это уже готовые `true` или `false`, их и нужно вернуть.

Шаги три и пять одинаковые: `print` со строкой, в которую через интерполяцию вставлен вызов `isFilled(bio)`.

Шаг четвёртый — обычное присваивание. Слово `var` второй раз не пишется, а текст кладётся в `bio` так же, как в любую строковую переменную.

## @hint2
Вот как выглядят опциональная переменная и функция с опциональным параметром на другом примере:

```swift
var website: String? = nil

func hasWebsite(_ site: String?) -> Bool {
    return site != nil
}

print("Сайт указан: \(hasWebsite(website))")
```

У тебя всё то же самое, только переменная называется `bio`, а функция — `isFilled`. Потом в `bio` кладётся текст, и строка выводится второй раз.

## @hint3
Почти готово, осталось заполнить пропуски:

```swift
var bio: ___ = nil

func isFilled(_ field: String?) -> Bool {
    return field ___ nil
}

print("О себе заполнено: \(isFilled(bio))")

bio = ___

print("О себе заполнено: \(isFilled(bio))")
```

В первом пропуске — тип «строка или ничего». Во втором — оператор «не равно». В третьем — текст о себе в кавычках.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `var bio: String? = nil` создаёт коробочку для строки, и сначала она пуста. Функция `isFilled` получает такую же коробочку в параметре `field` и сравнивает её с `nil`. Выражение `field != nil` само даёт `true` или `false`, поэтому `if` здесь не нужен — результат сравнения сразу возвращается. В первый раз `bio` пуста, и функция возвращает `false`. Потом в `bio` кладётся текст, и тот же самый вызов возвращает `true`.

**Почему опционал, а не пустая строка.** Можно было бы договориться, что `""` означает «не заполнено». Но о такой договорённости знаешь только ты. Тип `String?` говорит об этом прямо, и его видит компилятор: он не даст использовать такое значение, не проверив, есть ли оно. Кроме того, способ один для всех типов: `Int?`, `Double?`, `Bool?` устроены точно так же.

**Почему в функцию можно передать просто текст.** Параметр ждёт `String?`, а в тесте вызывается `isFilled("Гуляю с собакой")` — с обычной строкой. Swift сам кладёт обычное значение в коробочку, когда это нужно. В обратную сторону так не работает: достать значение из коробочки нужно явно.

**Типичные ошибки:**

- `var bio: String = nil` — без вопросительного знака тип обычный, и `nil` в него положить нельзя;
- `var bio = nil` — тип не указан, и Swift не понимает, коробочка для чего это;
- `Nil` или `null` вместо `nil` — слово пишется маленькими буквами и только так;
- `field == nil` вместо `field != nil` — функция начнёт отвечать наоборот.
