## @description

### Контекст
На экране оформления заказа есть три текстовых поля: промокод, почта для чека и отзыв о покупке. Тестировщица завела по ним три замечания:

1. «Промокод VESNA25 не срабатывает, если набрать его маленькими буквами. Сервер знает промокоды только заглавными».
2. «Почту Bilol.Style@Mail.Ru и bilol.style@mail.ru система считает разными адресами. Нужно хранить почту строчными буквами».
3. «Под полем отзыва нужен счётчик символов, например 37/500. А ещё приложение должно знать, пустой ли отзыв, — пустой отправлять нельзя».

Люди вводят текст так, как им удобно. Приводить его к единому виду — обычная работа приложения.

### Новое в Swift
Строку можно не только выводить на экран. У неё есть **свойства** и **методы** — к ним обращаются через точку после имени.

**Свойство** — это характеристика значения. Пишется без скобок.

- `count` — количество символов, тип `Int`. Пробелы и знаки препинания тоже считаются.
- `isEmpty` — пустая ли строка, тип `Bool`.

```swift
let comment = "Позвоните за час"
print(comment.count)      // 16
print(comment.isEmpty)    // false

let note = ""
print(note.isEmpty)       // true
```

**Метод** — это действие. Пишется с круглыми скобками.

- `uppercased()` — та же строка заглавными буквами.
- `lowercased()` — та же строка строчными буквами.

```swift
let sizeInput = "xl"
let size = sizeInput.uppercased()
print(size)           // XL
print(sizeInput)      // xl
```

Метод не меняет исходную строку, а создаёт новую — поэтому в `sizeInput` по-прежнему `xl`. Цифры и знаки остаются как были.

**Склейка строк.** Оператор `+` соединяет две строки в одну:

```swift
let firstName = "Билол"
let city = "Казань"
let signature = firstName + ", " + city
print(signature)      // Билол, Казань
```

Склеивать можно только строку со строкой. Если поставить `+` между числом и текстом, программа не соберётся: Swift не станет гадать, сложение это или склейка. Число сначала превращают в текст преобразованием `String(...)` — оно работает так же, как знакомые тебе `Double(...)` и `Int(...)`:

```swift
let itemsInCart = 3
let badge = "В корзине: " + String(itemsInCart)
print(badge)          // В корзине: 3
```

К строке-переменной текст дописывают оператором `+=`:

```swift
var greeting = "Здравствуйте"
greeting += ", " + firstName
print(greeting)       // Здравствуйте, Билол
```

> 💡 Интерполяция `\( )` и склейка через `+` часто дают одинаковый результат. Интерполяция удобнее для фраз со вставками, а `+` — когда нужно соединить готовые кусочки. В чужом коде встречаются оба способа, поэтому важно знать оба.

### Задача
В редакторе есть данные формы: `promoInput` — промокод в том виде, как его ввела покупательница, `emailInput` — почта, как её ввели, `review` — текст отзыва, `maxReviewLength` — максимальная длина отзыва. Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `promoCode` — промокод заглавными буквами.
2. Объяви константу `email` — почту строчными буквами.
3. Объяви константу `reviewLength` — количество символов в отзыве.
4. Объяви константу `isReviewEmpty` — пустой ли отзыв. Используй свойство `isEmpty`.
5. Объяви константу `counter` — текст счётчика: длина отзыва, знак `/` и максимальная длина, без пробелов. Собери его склейкой через `+`, а числа преврати в строки через `String(...)`.
6. Выведи четыре строки, как в примере.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let promoInput = "vesna25"
let emailInput = "Bilol.Style@Mail.Ru"
let review = "Платье село идеально, ткань приятная."
let maxReviewLength = 500

// 1. Промокод заглавными буквами
let promoCode = promoInput.uppercased()

// 2. Почта строчными буквами
let email = emailInput.lowercased()

// 3. Количество символов в отзыве
let reviewLength = review.count

// 4. Пустой ли отзыв
let isReviewEmpty = review.isEmpty

// 5. Текст счётчика: длина, знак / и максимум (склей через +)
let counter = String(reviewLength) + "/" + String(maxReviewLength)

// 6. Выведи четыре строки
print("Промокод: \(promoCode)")
print("Почта: \(email)")
print("Отзыв пустой: \(isReviewEmpty)")
print("Счётчик: \(counter)")
```

## @rules
- must: /\.isEmpty\b/ :: Проверь, пустой ли отзыв, свойством `isEmpty`: так принято в Swift, и это понятнее, чем сравнивать длину с нулём.
- must: /\bString\s*\(/ :: Числа для счётчика преврати в текст преобразованием `String(...)`.
- must: /\+/ :: Счётчик собери склейкой строк через оператор `+`.

## @hint1
Пять констант — пять коротких строк кода. В каждой ты обращаешься к строке через точку или склеиваешь кусочки.

Промокод: возьми `promoInput`, поставь точку и вызови метод, который делает все буквы заглавными. Это метод, значит, после названия нужны круглые скобки.

Почта: то же самое с `emailInput`, только метод другой — он делает буквы строчными.

Длина отзыва: у `review` через точку возьми свойство с количеством символов. Это свойство, скобки не нужны.

Пустой ли отзыв: ещё одно свойство `review` — оно сразу отвечает `true` или `false`.

Счётчик: это три кусочка, соединённые плюсами. Первый — длина отзыва, превращённая в текст. Второй — строка из одного символа, косой черты, в кавычках. Третий — максимальная длина, тоже превращённая в текст. Число превращается в текст словом `String` с круглыми скобками.

В конце четыре команды `print` со вставками: `promoCode`, `email`, `isReviewEmpty` и `counter`.

## @hint2
Свойства пишутся без скобок, методы — со скобками, а число перед склейкой превращается в текст:

```swift
let sizeInput = "xl"
let size = sizeInput.uppercased()        // XL
let sizeLength = sizeInput.count         // 2

let itemsInCart = 3
let badge = "В корзине: " + String(itemsInCart)
```

В твоём счётчике плюсов два: число, потом косая черта в кавычках, потом ещё одно число.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `promoInput.uppercased()` создаёт новую строку, где каждая буква заглавная: из `vesna25` получается `VESNA25`. Цифры остаются на месте. `emailInput.lowercased()` делает обратное. `review.count` считает символы — в отзыве из редактора их 37, вместе с пробелами, запятой и точкой. `review.isEmpty` отвечает `false`, потому что в отзыве есть хотя бы один символ. Счётчик собирается из трёх строк: `"37"`, `"/"` и `"500"`.

**Почему у одних слов есть скобки, а у других нет.** `count` и `isEmpty` — свойства: строка просто сообщает свою характеристику. `uppercased()` и `lowercased()` — методы: строка выполняет действие и возвращает результат. Если забыть скобки у метода или поставить лишние у свойства, программа не соберётся.

**Зачем `String(...)`.** Оператор `+` для чисел означает сложение, а для строк — склейку. Смешивать их нельзя: Swift не знает, чего ты хочешь от выражения «число плюс текст». `String(reviewLength)` превращает число `37` в текст `"37"`, и дальше склеиваются уже три строки. Интерполяцией вышло бы короче: `"\(reviewLength)/\(maxReviewLength)"`. В работе чаще выбирают её, но `+` и `String(...)` постоянно встречаются в чужом коде.

**Почему исходные данные не тронуты.** `promoInput` и `emailInput` остались такими, как их ввели. Приведённые к единому виду значения лежат в новых константах. Это удобно: всегда можно посмотреть, что на самом деле набрала покупательница.

**Типичные ошибки:**

- `promoInput.uppercased` без скобок или `review.count()` со скобками;
- `"/"` без кавычек — тогда Swift примет черту за деление;
- `String(reviewLength) + / + ...` или пробелы внутри кавычек `" / "` — в счётчике пробелов быть не должно;
- `review.count == 0` вместо `isEmpty` — работает, но `isEmpty` короче и сразу говорит, что имеется в виду.
