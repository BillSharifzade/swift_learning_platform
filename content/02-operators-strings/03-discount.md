## @description

### Контекст
В «Гардеробе» началась распродажа. На карточке товара теперь нужно показывать сумму скидки и новую цену.

Менеджер по ценам объясняет правила: «Цена и процент скидки приходят с сервера целыми числами. Сумму скидки показываем точно, с копейками. А к оплате — только целые рубли: копейки отбрасываем в пользу покупателя».

Коллега уже пробовал посчитать скидку целыми числами и написал `price * (discountPercent / 100)`. Скидка всегда получалась нулевой. Ты уже знаешь почему: `25 / 100` для целых чисел — это `0`. Значит, для процентов нужны дробные числа.

### Новое в Swift
В первом модуле ты познакомилась с двумя числовыми типами: `Int` — целые числа, `Double` — дробные. У чисел типа `Double` деление обычное, дробная часть не теряется.

Но есть правило: Swift **не смешивает** `Int` и `Double` в одном действии. Нельзя умножить значение типа `Int` на значение типа `Double` — программа не соберётся. Сначала числа нужно привести к одному типу. Это называется **преобразованием типа**.

**Из целого в дробное: `Double(...)`.** В скобках — значение, которое нужно превратить:

```swift
let starsSum = 23        // сумма всех оценок товара, Int
let reviewsCount = 5     // сколько было оценок, Int

print(starsSum / reviewsCount)     // 4 — дробная часть потеряна

let rating = Double(starsSum) / Double(reviewsCount)
print(rating)                      // 4.6
```

Сами `starsSum` и `reviewsCount` остались целыми. `Double(starsSum)` создаёт новое, дробное значение `23.0`, и делятся уже дробные числа.

**Из дробного в целое: `Int(...)`.** Дробная часть при этом **отбрасывается**, округления нет:

```swift
let filledStars = Int(rating)
print(filledStars)                 // 4
```

Даже `Int(4.99)` — это `4`.

Ещё две детали:

- Число, написанное цифрами прямо в выражении, Swift подстраивает сам. В `rating * 2` двойка станет дробной, преобразовывать её не нужно. А вот значение из константы типа `Int` само не подстроится — для него нужен `Double(...)`.
- `Double` всегда выводится с дробной частью. Если в константе типа `Double` лежит ровно восемь, `print` покажет `8.0`.

> 💡 Тип константы Swift определяет по результату выражения. Если справа от `=` получилось дробное число, константа будет `Double`, если целое — `Int`.

### Задача
В редакторе есть данные товара: `price` — цена в рублях и `discountPercent` — процент скидки. Обе константы типа `Int`. Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `discountAmount` типа `Double` — сумму скидки в рублях: цена, умноженная на процент и делённая на 100. Цену и процент перед вычислением преобразуй в `Double`.
2. Объяви константу `discountedPrice` типа `Double` — цену со скидкой: из цены, преобразованной в `Double`, вычти `discountAmount`.
3. Объяви константу `finalPrice` типа `Int` — сумму к оплате: преобразуй `discountedPrice` в целое число, копейки отбросятся.
4. Выведи четыре строки, как в примере. Знак `%` в тексте — обычный символ.

### Пример
Для данных из редактора:

```text
Цена: 2990 руб.
Скидка 25%: 747.5 руб.
Цена со скидкой: 2242.5 руб.
К оплате: 2242 руб.
```

Если скидка получается без копеек, дробное число всё равно выводится с точкой. Для цены 4000 рублей и скидки 50% вторая строка будет такой: `Скидка 50%: 2000.0 руб.`

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let price = 2990
let discountPercent = 25

// 1. Сумма скидки в рублях (Double): цена * процент / 100
let discountAmount = Double(price) * Double(discountPercent) / 100

// 2. Цена со скидкой (Double): цена минус сумма скидки
let discountedPrice = Double(price) - discountAmount

// 3. К оплате (Int): цена со скидкой без копеек
let finalPrice = Int(discountedPrice)

// 4. Выведи четыре строки для карточки товара
print("Цена: \(price) руб.")
print("Скидка \(discountPercent)%: \(discountAmount) руб.")
print("Цена со скидкой: \(discountedPrice) руб.")
print("К оплате: \(finalPrice) руб.")
```

## @hint1
Иди по шагам из задания. Главная мысль: пока идут вычисления с копейками, все числа должны быть дробными, и только в самом конце результат превращается в целое.

Шаг первый. Сумма скидки — это цена, умноженная на процент и делённая на сто. `price` и `discountPercent` — целые, поэтому каждую из них оберни в `Double` с круглыми скобками. Число сто можно написать просто цифрами: Swift сам сделает его дробным. Результат положи в `discountAmount`.

Шаг второй. Из цены нужно вычесть `discountAmount`. Но `price` — целое, а `discountAmount` — дробное, и вычесть одно из другого напрямую нельзя. Поэтому цену снова оберни в `Double`. Результат положи в `discountedPrice`.

Шаг третий. Теперь наоборот: дробное число нужно сделать целым. Оберни `discountedPrice` в `Int` с круглыми скобками — дробная часть отбросится. Результат положи в `finalPrice`.

Шаг четвёртый. Четыре команды `print`. Во второй строке две вставки: процент и сумма скидки. Знак процента пишется сразу после первой вставки как обычный символ.

## @hint2
Преобразование в обе стороны выглядит так:

```swift
let starsSum = 23

```

В твоём первом шаге тоже два `Double(...)`, только между ними умножение, а потом идёт деление на 100.

Вывод готов, в вычислениях осталось заполнить пропуски:

```swift
let discountAmount = Double(price) * Double(___) / 100
let discountedPrice = ___(price) - discountAmount
let finalPrice = ___(discountedPrice)

print("Цена: \(price) руб.")
print("Скидка \(discountPercent)%: \(discountAmount) руб.")
print("Цена со скидкой: \(discountedPrice) руб.")

```

В первом пропуске — имя константы с процентом. Во втором — название типа, в который нужно превратить цену, чтобы вычесть из неё дробное число. В третьем — название типа, который отбрасывает дробную часть.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `Double(price)` превращает `2990` в `2990.0`, а `Double(discountPercent)` — `25` в `25.0`. Дальше идут действия с дробными числами: `2990.0 * 25.0` — это `74750.0`, а после деления на 100 получается `747.5`. Копейки сохранились. Во второй строке из `2990.0` вычитается `747.5` — выходит `2242.5`. В третьей строке `Int(2242.5)` отбрасывает дробную часть, остаётся `2242`.

**Почему нельзя посчитать всё в целых числах.** `price * discountPercent / 100` для целых — это `74750 / 100`, то есть `747`: пятьдесят копеек пропали. А `discountPercent / 100` — вообще ноль. Целочисленное деление подходит для коробок, но не для денег и процентов.

**Почему `Double(...)` стоит у каждой константы.** Swift не станет сам превращать `Int` в `Double`: он считает, что такие решения должен принимать разработчик. Зато это защищает от тихих ошибок, когда дробная часть теряется незаметно. Число `100` в формуле написано цифрами, поэтому Swift сам делает его дробным.

**Почему копейки отбрасываются в самом конце.** Если округлять по дороге, ошибка накапливается. Правило простое: считаем точно, округляем один раз — перед показом.

**Типичные ошибки:**

- `Double(price) * discountPercent` — одна из констант осталась целой, типы не совпали;
- `Double(price * discountPercent / 100)` — деление выполнилось в целых числах ещё до преобразования, копейки уже потеряны;
- `double(price)` или `int(...)` с маленькой буквы — названия типов пишутся с большой;
- ожидание, что `Int(2242.5)` округлит до 2243, — `Int(...)` не округляет, а отбрасывает.
