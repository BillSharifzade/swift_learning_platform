## @description

### Контекст
На главном экране «Волны» появится раздел «Под настроение»: «Бодрое», «Спокойное», «Для дороги». У каждого настроения — свой плейлист. А рядом — чарт недели: самые популярные треки с числом прослушиваний.

Раньше в твоих коллекциях лежали простые значения: строки и числа. Но настроений несколько, и у каждого целый список треков. Получается коллекция, внутри которой лежат другие коллекции.

Задача из трекера: «Добавление трека в плейлист настроения и сводка для главного экрана: список настроений, размер и первый трек выбранного плейлиста, первое и последнее места чарта».

### Новое в Swift
Элементом коллекции может быть другая коллекция. Новых команд для этого нет — всё, что ты знаешь, просто соединяется в цепочку.

**Словарь массивов.** Ключ — строка, значение — целый массив:

```swift
var catalog = ["Обувь": ["Кеды", "Ботинки"], "Верх": ["Свитер"]]
```

Тип такого словаря — `[String: [String]]`. Чтение по ключу возвращает массив, поэтому запасное значение в `default:` — тоже массив, пустой:

```swift
catalog["Обувь", default: []]         // ["Кеды", "Ботинки"]
catalog["Обувь", default: []].count   // 2
catalog["Обувь", default: []][1]      // Ботинки
catalog["Сумки", default: []].count   // 0 — такой категории нет
```

Читай цепочку слева направо: сначала словарь отдаёт массив, потом у этого массива берут `count` или элемент по индексу.

Точно так же вложенный массив можно менять:

```swift
catalog["Верх", default: []].append("Пальто")    // добавили в готовый массив
catalog["Сумки", default: []].append("Рюкзак")   // массива не было — он создался
```

Вторая строка работает как счётчик из задачи про прослушивания: ключа нет, поэтому берётся пустой массив, в него добавляется элемент, и результат записывается в словарь.

> ⚠️ Если сначала достать массив в отдельную переменную, получится **копия**. Изменения копии в словарь не попадут. Чтобы изменить массив внутри словаря, обращайся к нему через словарь, как в примере выше.

**Массив кортежей.** Каждый элемент массива — кортеж с несколькими значениями:

```swift
let reviews = [(author: "Билол", stars: 5), (author: "night_owl", stars: 4)]
```

Сначала индексом выбирают кортеж, потом через точку — его элемент:

```swift
reviews[0].author                   // Билол
reviews[1].stars                    // 4
reviews[reviews.count - 1].author   // night_owl — автор последнего отзыва
```

### Задача
В редакторе есть словарь `moodPlaylists` (настроение и его плейлист), настроение `mood`, трек `newTrack` и массив кортежей `chart` — чарт недели, от первого места к последнему. У каждого кортежа в чарте два элемента: `title` и `plays`. Не переименовывай входные данные — проверка подставит другие.

1. Добавь `newTrack` в конец плейлиста настроения `mood`. Если такого настроения в словаре ещё нет, должен появиться новый плейлист из одного трека.
2. Выведи `Настроения:` и массив названий настроений по алфавиту.
3. Выведи название из `mood`, запятую, `треков:` и количество треков в его плейлисте.
4. Выведи `Первый трек:` и первый трек этого плейлиста.
5. Выведи `Лидер чарта:`, название трека с первого места и его число прослушиваний в круглых скобках.
6. Выведи `Замыкает чарт:`, название трека с последнего места и его число прослушиваний в круглых скобках. Чарт может быть любой длины.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
var moodPlaylists = ["Бодрое": ["Комета", "Танцуй до утра"], "Спокойное": ["Маяк", "Апрель", "Белый шум"]]
let mood = "Спокойное"
let newTrack = "Океан внутри"
let chart = [(title: "Комета", plays: 5400), (title: "Маяк", plays: 4800), (title: "Апрель", plays: 3900)]

// 1. Добавь newTrack в плейлист настроения mood
moodPlaylists[mood, default: []].append(newTrack)

// 2. Выведи названия настроений по алфавиту
print("Настроения: \(moodPlaylists.keys.sorted())")

// 3. Выведи, сколько треков в плейлисте настроения mood
print("\(mood), треков: \(moodPlaylists[mood, default: []].count)")

// 4. Выведи первый трек этого плейлиста
print("Первый трек: \(moodPlaylists[mood, default: []][0])")

// 5. Выведи первое место чарта
print("Лидер чарта: \(chart[0].title) (\(chart[0].plays))")

// 6. Выведи последнее место чарта (чарт может быть любой длины)
print("Замыкает чарт: \(chart[chart.count - 1].title) (\(chart[chart.count - 1].plays))")
```

## @hint1
Новых команд в этой задаче нет: нужно только аккуратно соединить знакомые. Помогает правило «читай слева направо»: каждая следующая часть цепочки работает с тем, что вернула предыдущая.

Первый шаг — добавление трека. Чтение из словаря по ключу `mood` с запасным пустым массивом возвращает плейлист. К этому обращению сразу, через точку, приписывается команда добавления в конец. Если настроения в словаре не было, Swift возьмёт пустой массив, добавит в него трек и сохранит под новым ключом. Не доставай плейлист в отдельную переменную: это будет копия, и словарь не изменится.

Второй шаг — ключи словаря, обязательно отсортированные.

Третий и четвёртый шаги снова начинаются с чтения плейлиста из словаря. Дальше к нему приписывается либо свойство с количеством элементов, либо индекс первого элемента в квадратных скобках. Получается две пары квадратных скобок подряд: первая — обращение к словарю, вторая — индекс в массиве.

Пятый и шестой шаги — про чарт. Это массив, поэтому сначала идёт индекс в квадратных скобках, а потом, через точку, имя элемента кортежа. Первое место — индекс ноль. Последнее место — индекс «количество минус один», как в самой первой задаче модуля. Число прослушиваний стоит в обычных круглых скобках — они часть текста.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Разберём первую строку по частям. `moodPlaylists[mood, default: []]` — это плейлист нужного настроения: массив строк. `.append(newTrack)` добавляет трек в конец этого массива. Так как обращение идёт через словарь, изменённый массив сразу сохраняется в нём. Для настроения «Спокойное» в массиве было три трека, стало четыре. Для настроения, которого в словаре не было, Swift берёт пустой массив `[]`, добавляет трек и записывает массив из одного элемента под новым ключом.

Строки три и четыре читают тот же плейлист и продолжают цепочку: `.count` даёт количество, `[0]` — первый трек. После первого шага в плейлисте есть хотя бы один трек, поэтому индекс `0` безопасен.

В строках про чарт порядок обратный: снаружи массив, внутри кортежи. `chart[0]` — это кортеж с первого места, `chart[0].title` — его название. `chart[chart.count - 1]` — кортеж с последнего места, какой бы длины чарт ни был.

**Почему нельзя сначала достать плейлист в переменную.** Массивы в Swift копируются при присваивании. Если написать `var playlist = moodPlaylists[mood, default: []]` и потом `playlist.append(newTrack)`, изменится только `playlist`. В словаре останется старый массив. Такой способ тоже возможен, но тогда копию нужно записать обратно: `moodPlaylists[mood] = playlist`.

**Почему `default: []`, а не `default: 0`.** Запасное значение должно быть того же типа, что и значения словаря. Здесь значения — массивы строк, значит, запасное значение — пустой массив.

**Типичные ошибки:**

- `moodPlaylists[mood].append(newTrack)` без `default:` — Swift не уверен, что такой ключ есть, и не соберёт программу;
- `moodPlaylists[mood] = [newTrack]` — так старые треки плейлиста пропадут, останется один новый;
- `chart.title[0]` — порядок перепутан: сначала индекс, потом имя элемента;
- `chart[2]` для последнего места — в чарте из одного трека такого индекса нет, программа остановится;
- `moodPlaylists.keys` без `sorted()` — настроения напечатаются в случайном порядке.
