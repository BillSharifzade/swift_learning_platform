## @description

### Контекст
Финальная задача спринта — экран «Отчёт за месяц». Аналитик прислала макет: заголовок, доходы, расходы, разбивка расходов по категориям и итог — остаток или перерасход.

Доходы приходят с сервера списком сумм, а расходы — словарём «категория: сумма». Тимлид даёт два совета: «Сумму нам нужно считать и по списку, и по словарю. Назови обе функции одинаково — `total(of:)`, Swift сам выберет нужную. А строку с названием и суммой собирай маленькой функцией прямо внутри отчёта: больше она нигде не нужна».

### Новое в Swift
Два небольших приёма, которые часто встречаются в настоящем коде.

**Перегрузка.** У нескольких функций может быть одно имя, если у них разные параметры — например, разные типы. Swift смотрит на аргумент и выбирает подходящую функцию:

```swift
func describe(_ amount: Int) -> String {
    return "\(amount) руб."
}

func describe(_ amounts: [Int]) -> String {
    return "Операций: \(amounts.count)"
}

describe(450)           // "450 руб."        — вызвана первая
describe([450, 1200])   // "Операций: 2"     — вызвана вторая
```

Так устроена и `print`: одно имя, а принимает строки, числа, массивы. Перегрузка уместна, когда функции делают одно и то же по смыслу, только с разными данными.

**Вложенная функция.** Функцию можно объявить внутри другой функции. У такой функции две особенности: снаружи она не видна, зато сама видит параметры и переменные «большой» функции.

```swift
func subscriptionsList(prices: [Int], discount: Int) -> [String] {
    // Вложенная функция: пользуется параметром discount
    func finalPrice(_ price: Int) -> Int {
        return price - price * discount / 100
    }

    var result: [String] = []
    for price in prices {
        result.append("К оплате: \(finalPrice(price)) руб.")
    }
    return result
}
```

`finalPrice` — помощник, который нужен только здесь. Ему не пришлось передавать `discount`: он берёт его у внешней функции.

### Что пригодится
Всё остальное ты уже умеешь:

- **типы коллекций в параметрах**: `[Int]` — массив целых чисел, `[String]` — массив строк, `[String: Int]` — словарь со строковыми ключами и целыми значениями;
- **метки и значения по умолчанию**: `of amounts: [Int]`, `currency: String = "руб."`;
- **`guard`** для раннего выхода, когда продолжать нет смысла;
- **цикл по словарю** — через отсортированные ключи: `for name in expenses.keys.sorted()`, а значение читается как `expenses[name, default: 0]`;
- **массив строк**: начать с первой строки и добавлять остальные через `append`.

### Задача
В редакторе есть данные за март и готовая функция `total(of:)` для массива.

1. Добавь **перегрузку** `total(of:)` для расходов: параметр с меткой `of` типа `[String: Int]`, результат `Int` — сумма всех значений словаря.
2. Объяви функцию `monthlyReport`, которая возвращает `[String]` — строки отчёта. Параметры: `month: String`, `incomes: [Int]`, `expenses: [String: Int]` и `currency: String` со значением по умолчанию `"руб."`.
3. Внутри `monthlyReport` объяви **вложенную** функцию `line` с двумя параметрами без меток: `title: String` и `amount: Int`. Она возвращает строку: название, двоеточие, пробел, сумма, пробел и `currency`. Например, `Доходы: 98000 руб.` Все строки с суммами собирай через неё.
4. Строки отчёта идут в таком порядке:
   - `Отчёт за` и название месяца;
   - если нет ни доходов, ни расходов (оба набора пустые) — ещё одна строка `Операций нет`, и на этом отчёт заканчивается. Сделай это через `guard`;
   - `Доходы` — сумма доходов;
   - `Расходы` — сумма расходов;
   - по одной строке на категорию, в алфавитном порядке; название — дефис, пробел и имя категории: `- Жильё: 35000 руб.`;
   - если расходы больше доходов — `Перерасход` с разницей, иначе — `Остаток` с разницей.
5. Выведи отчёт: вызови `monthlyReport` для `reportMonth`, `marchIncomes` и `marchExpenses` и напечатай каждую строку результата.

### Пример
Вывод программы:

```text
Отчёт за март
Доходы: 98000 руб.
Расходы: 61500 руб.
- Жильё: 35000 руб.
- Продукты: 18500 руб.
- Транспорт: 8000 руб.
Остаток: 36500 руб.
```

Проверка вызовет функцию и для других месяцев:

## @solution
```swift
// Данные за март
let reportMonth = "март"
let marchIncomes = [85000, 13000]
let marchExpenses = ["Жильё": 35000, "Продукты": 18500, "Транспорт": 8000]

// Сумма списка: эта функция уже готова
func total(of amounts: [Int]) -> Int {
    var sum = 0
    for amount in amounts {
        sum += amount
    }
    return sum
}

// 1. Добавь перегрузку total(of:) для словаря с расходами по категориям
func total(of categories: [String: Int]) -> Int {
    var sum = 0
    for name in categories.keys.sorted() {
        sum += categories[name, default: 0]
    }
    return sum
}

// 2. Объяви функцию monthlyReport(month:incomes:expenses:currency:)
//    Внутри неё: вложенная функция line, проверка через guard и сборка строк
func monthlyReport(month: String, incomes: [Int], expenses: [String: Int], currency: String = "руб.") -> [String] {
    func line(_ title: String, _ amount: Int) -> String {
        return "\(title): \(amount) \(currency)"
    }

    var lines = ["Отчёт за \(month)"]
    guard !incomes.isEmpty || !expenses.isEmpty else {
        lines.append("Операций нет")
        return lines
    }

    let income = total(of: incomes)
    let spent = total(of: expenses)
    lines.append(line("Доходы", income))
    lines.append(line("Расходы", spent))
    for name in expenses.keys.sorted() {
        lines.append(line("- \(name)", expenses[name, default: 0]))
    }

    if spent > income {
        lines.append(line("Перерасход", spent - income))
    } else {
        lines.append(line("Остаток", income - spent))
    }
    return lines
}

// 3. Выведи отчёт за март: каждую строку результата — командой print
for row in monthlyReport(month: reportMonth, incomes: marchIncomes, expenses: marchExpenses) {
    print(row)
}
```

## @rules
- must: /func\s+monthlyReport\b[\s\S]*\bfunc\s+line\s*\(/ :: Функция `line` должна быть вложенной: объяви её внутри `monthlyReport`, между фигурными скобками.
- must: /\bguard\b/ :: Случай «операций нет» обработай через `guard` — сейчас его в коде нет.

## @hint1
Задача большая, но состоит из знакомых шагов. Делай их по очереди.

Перегрузка. Посмотри на готовую функцию `total(of:)` для массива. Вторая функция называется так же и тоже возвращает целое число, но её параметр — словарь из строк в целые числа. Внутри заведи переменную для суммы, пройди по отсортированным ключам словаря и прибавляй значение каждого ключа, читая его с `default`.

Объявление отчёта. Четыре параметра, у последнего — значение по умолчанию. Результат — массив строк.

Вложенная функция. Сразу после открывающей фигурной скобки `monthlyReport` объяви `line`: два параметра без меток, результат — строка. Она собирает текст из названия, суммы и `currency`. Параметр `currency` ей передавать не нужно: вложенная функция видит параметры внешней.

Сборка строк. Заведи массив с первой строкой — заголовком. Затем `guard`: требование — хотя бы один из наборов не пуст. Если оно не выполнено, добавь строку `Операций нет` и верни массив. Дальше посчитай доходы и расходы двумя вызовами `total(of:)`, добавь две строки через `line`, потом циклом по отсортированным ключам — строки категорий. В конце сравни расходы с доходами и добавь либо перерасход, либо остаток. Верни массив.

Вывод. Пройди циклом `for` по результату вызова `monthlyReport` и напечатай каждую строку.

## @hint4
Вот готовое решение:

{{solution}}

**Перегрузка.** В коде две функции `total(of:)`. Когда ты пишешь `total(of: incomes)`, аргумент — массив, и Swift вызывает первую. В `total(of: expenses)` аргумент — словарь, и вызывается вторая. Читающему код не нужно помнить два разных имени: `total(of:)` всегда означает «сложи всё».

**Вложенная функция.** `line` объявлена внутри `monthlyReport` и собирает строку из названия и суммы. Обрати внимание: `currency` не входит в её параметры, но она им пользуется — вложенная функция видит всё, что видит внешняя. Поэтому вызовы получаются короткими: `line("Доходы", income)`. А снаружи `monthlyReport` функции `line` не существует, и она никому не мешает.

**Почему формат строки вынесен в функцию.** Строк с суммами в отчёте много: доходы, расходы, каждая категория, итог. Если завтра дизайнер попросит писать валюту перед числом, ты поправишь одну строчку внутри `line`, а не шесть мест.

**Ранний выход.** Массив `lines` начинается с заголовка. `guard` требует, чтобы хотя бы один набор был не пуст. Если пусты оба, добавляется строка `Операций нет`, и функция сразу возвращает результат. Весь остальной код работает уже с настоящими данными и не думает о пустом случае.

**Категории.** Порядок элементов в словаре случайный, поэтому цикл идёт по `expenses.keys.sorted()` — так строки всегда выходят по алфавиту. Название для `line` собирается на месте: `"- \(name)"`.

**Итог.** Условие `spent > income` строгое: при равенстве это не перерасход, а остаток в ноль.

**Типичные ошибки:**

- `line` объявлена снаружи `monthlyReport` — тогда она не видит `currency`;
- в `line` написано готовое `руб.` вместо `currency` — отчёт в другой валюте получится неверным;
- условие в `guard` перевёрнуто: `guard incomes.isEmpty && expenses.isEmpty` — так `Операций нет` получат все обычные отчёты;
- цикл идёт по `expenses.keys` без `sorted()` — порядок категорий будет меняться от запуска к запуску;
- в последней строке всегда `income - spent` — при перерасходе получится отрицательное число.
