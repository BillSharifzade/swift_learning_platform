## @description

### Контекст
В «Копилке» можно переводить деньги между своими счетами. Перед кнопкой «Перевести» приложение показывает строку подтверждения: откуда, куда и сколько.

Первую версию функции написал стажёр, и на код-ревью тимлид оставил комментарий: «Вызов `describeTransfer(source: "Основной", destination: "Отпуск", amount: 1500)` читается тяжело. В Swift принято, чтобы вызов звучал как фраза: перевод *из* одного счёта *в* другой — `from:` и `to:`. А помощнику `rubles` имя параметра при вызове только мешает, пусть вызывается просто: `rubles(1500)`».

### Новое в Swift
В прошлой задаче имя параметра работало сразу в двух местах: в теле функции и при вызове. На самом деле у параметра может быть **два имени**:

- **метка аргумента** — внешнее имя, его пишут при вызове;
- **имя параметра** — внутреннее имя, им пользуются в теле функции.

В объявлении они идут подряд через пробел: сначала метка, потом имя параметра.

```swift
func remind(about bill: String, after days: Int) -> String {
    return "Напомним про \(bill) через \(days) дн."
}

print(remind(about: "интернет", after: 3))
// Напомним про интернет через 3 дн.
```

Вызов читается почти как фраза: «напомни про интернет через 3». А внутри функции удобнее имена-существительные `bill` и `days`. Метки `about` и `after` в теле не видны — они существуют только для вызова.

**Вызов без метки.** Иногда метка ничего не добавляет: по имени функции и так понятно, что ей передают. Тогда на месте метки ставят подчёркивание `_` — оно означает «метки нет»:

```swift
func percentText(_ value: Int) -> String {
    return "\(value)%"
}

print(percentText(15))                  // 15%
print("Скидка: \(percentText(20))")     // Скидка: 20%
```

Так вызывается и знакомая тебе `print("Привет")`. А вторая строка примера показывает ещё одно: вызов функции можно поставить прямо внутрь интерполяции.

Итого у параметра бывает три вида записи:

- `amount: Int` — одно имя на оба случая: при вызове `amount: 100`, в теле `amount`;
- `after days: Int` — при вызове `after: 3`, в теле `days`;
- `_ value: Int` — при вызове просто `15`, в теле `value`.

Свои функции можно вызывать и из других своих функций — точно так же, как ты вызываешь `print`.

> 💡 Если всё тело функции — одно выражение, слово `return` можно не писать: `func percentText(_ value: Int) -> String { "\(value)%" }`. Оба варианта правильные — выбирай тот, который тебе понятнее.

### Задача
В редакторе есть данные перевода: `sourceAccount`, `destinationAccount`, `transferAmount` и `transferFee`.

1. Объяви функцию `rubles`. У неё один параметр `amount` типа `Int`, при вызове метка **не пишется**. Функция возвращает `String`: число, пробел и `руб.` Например, `rubles(1500)` возвращает `1500 руб.`
2. Объяви функцию `describeTransfer`, которая возвращает `String`. У неё три параметра:
   - счёт списания: метка `from`, внутреннее имя `source`, тип `String`;
   - счёт зачисления: метка `to`, внутреннее имя `destination`, тип `String`;
   - сумма: `amount` типа `Int` (одно имя — оно и метка, и имя параметра).

   Функция возвращает текст вида `Перевод со счёта Основной на счёт Отпуск: 1500 руб.` Сумму вместе с `руб.` получи вызовом `rubles`.
3. Выведи две строки:
   - результат `describeTransfer` для данных из редактора;
   - слово `Комиссия:`, пробел и результат `rubles` для `transferFee`.

### Пример
Вывод программы:

```text
Перевод со счёта Основной на счёт Отпуск: 1500 руб.
Комиссия: 0 руб.
```

Проверка вызовет функции и с другими данными:

```swift
rubles(250)                                                // "250 руб."
describeTransfer(from: "Отпуск", to: "Основной", amount: 700)
// "Перевод со счёта Отпуск на счёт Основной: 700 руб."
```

## @solution
```swift
// Данные перевода с экрана подтверждения
let sourceAccount = "Основной"
let destinationAccount = "Отпуск"
let transferAmount = 1500
let transferFee = 0

// 1. Объяви функцию rubles: она вызывается без метки, например rubles(1500)
func rubles(_ amount: Int) -> String {
    return "\(amount) руб."
}

// 2. Объяви функцию describeTransfer: она вызывается с метками from, to и amount
func describeTransfer(from source: String, to destination: String, amount: Int) -> String {
    return "Перевод со счёта \(source) на счёт \(destination): \(rubles(amount))"
}

// 3. Выведи описание перевода и строку с комиссией
print(describeTransfer(from: sourceAccount, to: destinationAccount, amount: transferAmount))
print("Комиссия: \(rubles(transferFee))")
```

## @rules
- must: /func\s+describeTransfer\s*\(\s*from\s+[A-Za-z_]\w*\s*:/ :: У первого параметра `describeTransfer` должно быть два имени через пробел: метка `from` и внутреннее имя `source`.
- must: /,\s*to\s+[A-Za-z_]\w*\s*:\s*String/ :: У второго параметра `describeTransfer` должно быть два имени через пробел: метка `to` и внутреннее имя `destination`.

## @hint1
Обе функции возвращают строку, и в обеих хватит одной команды `return`. Вся новизна — в круглых скобках объявления.

Начни с `rubles`. Её параметр называется `amount`, но при вызове имя писать не нужно. Чтобы убрать метку, перед именем параметра ставят подчёркивание и пробел. Тело — строка из значения `amount`, пробела и `руб.`

Теперь `describeTransfer`. У первых двух параметров по два имени через пробел: сначала метка для вызова, потом имя для тела функции. У первого это `from` и `source`, у второго — `to` и `destination`. Третий параметр записан как в прошлой задаче: одно имя `amount`. Между параметрами — запятые, у каждого после двоеточия свой тип.

В теле `describeTransfer` пользуйся внутренними именами: `source` и `destination`. Метки `from` и `to` там не работают. Чтобы получить сумму со словом `руб.`, вызови свою же функцию `rubles` — прямо внутри интерполяции.

При вызове всё наоборот: пишутся метки `from:`, `to:`, `amount:`, а про внутренние имена вызывающий код ничего не знает.

## @hint2
Вот как объявляются и вызываются параметры с меткой, с двумя именами и без метки:

```swift
func remind(about bill: String, after days: Int) -> String {
    return "Напомним про \(bill) через \(days) дн."
}

func percentText(_ value: Int) -> String {
    return "\(value)%"
}

print(remind(about: "интернет", after: 3))
print("Скидка: \(percentText(20))")
```

`rubles` устроена как `percentText`, а первые два параметра `describeTransfer` — как параметры `remind`.

## @hint3
Функция `rubles` готова. Допиши объявление и тело `describeTransfer`, а потом вторую строку вывода:

```swift
func rubles(_ amount: Int) -> String {
    return "\(amount) руб."
}

func describeTransfer(from source: String, ___ destination: String, amount: Int) -> String {
    return "Перевод со счёта \(source) на счёт \(___): \(rubles(amount))"
}

print(describeTransfer(from: sourceAccount, to: destinationAccount, amount: transferAmount))
print("Комиссия: \(___)")
```

В первом пропуске — метка второго параметра. Во втором — внутреннее имя счёта зачисления. В третьем — вызов `rubles` для `transferFee`, без метки.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В объявлении `rubles(_ amount: Int)` подчёркивание стоит на месте метки и говорит: «при вызове метку не писать». Поэтому вызов выглядит как `rubles(1500)`. В теле при этом используется обычное имя `amount`.

У `describeTransfer` первые два параметра записаны двумя словами. `from source: String` означает: снаружи этот параметр называется `from`, внутри — `source`. Вызов `describeTransfer(from: "Основной", to: "Отпуск", amount: 1500)` читается как фраза, а в теле функции стоят понятные существительные `source` и `destination`. У третьего параметра одно имя, `amount`, — оно работает и как метка, и как имя в теле.

Внутри `describeTransfer` вызывается `rubles(amount)`. Так правило «как записать сумму» живёт в одном месте: если завтра решат писать `₽` вместо `руб.`, достаточно поправить одну функцию.

**Почему не оставить одно имя.** Можно было объявить `describeTransfer(from: String, to: String, amount: Int)` — вызов выглядел бы так же. Но тогда в теле пришлось бы писать `"со счёта \(from) на счёт \(to)"`. Предлоги в роли имён данных читаются плохо. Два имени позволяют сделать удобно и снаружи, и внутри.

**Когда убирать метку.** Подчёркивание уместно, когда имя функции уже объясняет аргумент: `rubles(1500)`, `print("Привет")`. Если аргументов несколько и их легко перепутать — например, два счёта — метки обязательно нужны.

**Типичные ошибки:**

- в теле функции использована метка вместо имени параметра: `\(from)` — Swift не знает такого имени, внутри есть только `source`;
- при вызове написано внутреннее имя: `describeTransfer(source: ...)` — снаружи видны только метки;
- забыто подчёркивание у `rubles` — тогда вызов `rubles(1500)` не соберётся, Swift попросит метку `amount:`;
- счета перепутаны местами в тексте — проверка специально делает перевод в обратную сторону.
