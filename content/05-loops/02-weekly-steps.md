## @description

### Контекст
На главном экране «Пульса» есть карточка «Шаги за неделю». Браслет присылает массив чисел: сколько шагов пройдено в каждый из дней. На карточке нужно показать два итога: сколько шагов всего и сколько в среднем за день.

Тестировщик добавляет к задаче замечание: «У нового пользователя данных ещё нет, массив пустой. Проверьте, что приложение в этот момент не падает».

### Новое в Swift
В прошлой задаче цикл шёл по диапазону чисел. Точно так же можно пройти **по массиву**: переменная цикла по очереди получит каждый его элемент, от первого до последнего.

```swift
let workouts = ["Йога", "Бег", "Плавание"]
for workout in workouts {
    print("Тренировка: \(workout)")
}
```

```text
Тренировка: Йога
Тренировка: Бег
Тренировка: Плавание
```

Заметь: в `workout` попадает сам элемент, а не его номер. Индексы и квадратные скобки здесь не нужны, и выйти за границы массива невозможно. Имя переменной цикла обычно выбирают так, чтобы было понятно, что в ней лежит: массив `workouts` — элемент `workout`.

**Накопление результата.** Часто нужно не просто показать элементы, а что-то из них собрать — например, сумму. Для этого перед циклом заводят переменную, а в теле цикла понемногу её увеличивают:

```swift
let sessions = [30, 45, 20]

var totalMinutes = 0
for minutes in sessions {
    totalMinutes += minutes
}
print("Всего: \(totalMinutes) мин")
```

Проследим по шагам. Сначала в `totalMinutes` лежит 0. После первого повтора — 30, после второго — 75, после третьего — 95. Цикл закончился, и в переменной осталась сумма всех элементов.

Здесь важны две вещи:

- переменная объявлена **до цикла**. Если объявить её внутри фигурных скобок, она будет создаваться заново на каждом повторе, а после цикла исчезнет;
- это именно `var`, а не `let`: значение меняется.

> 💡 Если массив пуст, тело цикла не выполнится ни разу. Это не ошибка: программа просто пойдёт дальше, а в `totalMinutes` останется 0.

### Задача
В редакторе есть массив `steps` — шаги по дням — и вывод количества дней. Не переименовывай массив: проверка подставит другие данные.

1. Объяви переменную `totalSteps` с начальным значением `0`.
2. Циклом `for-in` пройди по массиву `steps` и прибавь шаги каждого дня к `totalSteps`.
3. Выведи строку `Всего шагов:` и сумму.
4. Объяви `averageSteps` — среднее число шагов за день. Это `totalSteps`, делённое на количество дней `steps.count`. Оба числа целые, поэтому дробная часть отбросится — для карточки это подходит. Если массив пуст, в `averageSteps` должен лежать `0`.
5. Выведи строку `В среднем за день:` и среднее.

> ⚠️ Делить на ноль нельзя: программа аварийно остановится. У пустого массива `count` равен нулю, поэтому перед делением нужна проверка через `if`.

Для данных из редактора:


Для нового пользователя, у которого массив пуст:

```text

Всего шагов: 0
В среднем за день: 0
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let steps = [8200, 10450, 6300, 12100, 9800, 4050, 7600]

print("Дней в отчёте: \(steps.count)")

// 1. Объяви переменную totalSteps — в ней будет копиться сумма
var totalSteps = 0

// 2. Пройди циклом по массиву steps и прибавь шаги каждого дня к totalSteps
for daySteps in steps {
    totalSteps += daySteps
}

// 3. Выведи общее количество шагов
print("Всего шагов: \(totalSteps)")

// 4. Посчитай среднее за день в averageSteps. Если дней нет, среднее равно 0
var averageSteps = 0
if !steps.isEmpty {
    averageSteps = totalSteps / steps.count
}

// 5. Выведи среднее
print("В среднем за день: \(averageSteps)")
```

## @rules
- must: /\bfor\s+\w+\s+in\b/ :: Сумму шагов нужно накопить циклом `for-in` по массиву `steps`.

## @hint1
Задача состоит из двух частей: сначала сумма, потом среднее.

Для суммы нужна переменная-накопитель `totalSteps`. Объяви её до цикла и положи в неё ноль: пока мы не посмотрели ни одного дня, шагов ноль. Затем напиши цикл `for-in` по массиву `steps`. Переменная цикла на каждом повторе получит шаги очередного дня. В теле цикла одна строка: прибавь это значение к `totalSteps` оператором `+=`. После закрывающей скобки цикла выведи результат.

Среднее — это сумма, делённая на количество дней. Количество дней — `steps.count`. Но у пустого массива оно равно нулю, а делить на ноль нельзя. Поэтому сначала положи в `averageSteps` ноль, а деление выполняй внутри `if` — только когда массив не пуст. Проверить это можно через `isEmpty` или сравнив `count` с нулём.

Числа `7`, `58500` и `8357` в коде не пиши: проверка запустит программу на других массивах.

## @hint2
Так накапливается сумма элементов массива:

```swift
let sessions = [30, 45, 20]

var totalMinutes = 0
for minutes in sessions {
    totalMinutes += minutes
}
```

А так выглядит защита от деления на ноль: значение по умолчанию и деление только при непустом массиве.

```swift
var averageMinutes = 0
if !sessions.isEmpty {
    averageMinutes = totalMinutes / sessions.count
}
```

## @hint4
Вот готовое решение:

{{solution}}

**Как работает накопление.** Перед циклом в `totalSteps` лежит 0. Цикл по очереди кладёт в `daySteps` шаги каждого дня: 8200, потом 10450, потом 6300 и так далее. Строка `totalSteps += daySteps` каждый раз увеличивает сумму: 8200, затем 18650, затем 24950... После седьмого повтора элементы заканчиваются, и в `totalSteps` остаётся 58500.

**Почему `totalSteps` объявлена до цикла.** Всё, что объявлено внутри фигурных скобок цикла, создаётся заново на каждом повторе и не видно снаружи. Накопитель должен жить дольше цикла: помнить значение между повторами и быть доступным после него.

**Почему перед делением стоит `if`.** У нового пользователя массив пуст. Цикл по пустому массиву не выполнится ни разу — это безопасно. А вот `totalSteps / steps.count` превратится в `0 / 0`, и программа аварийно остановится. Поэтому в `averageSteps` заранее лежит 0, а деление выполняется, только если дни есть. Запись `!steps.isEmpty` читается как «массив не пуст». Условие `steps.count > 0` означает то же самое.

**Почему получилось 8357, а не 8357.14.** Оба числа имеют тип `Int`, а деление целых отбрасывает дробную часть. На карточке дробные шаги не нужны.

**Типичные ошибки:**

- `var totalSteps = 0` написано внутри цикла — сумма каждый раз начинается с нуля;
- `totalSteps = daySteps` вместо `+=` — в переменной окажется только последний день;
- деление на `7` вместо `steps.count` — неделя бывает неполной;
- деление без проверки — программа падает на пустом массиве.
