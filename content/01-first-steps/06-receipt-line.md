## @description

### Контекст
После оплаты гость видит на экране чек. Пока дизайнер рисует красивую версию, нужно собрать текст чека из данных заказа: название напитка, цена и количество.

Данные каждый раз разные: сегодня это раф за 320 рублей, завтра — капучино за 270. Поэтому текст нельзя написать «намертво» — его нужно **собирать из значений**.

### Новое в Swift
До сих пор ты выводила либо готовый текст, либо одно значение. Но в настоящих приложениях почти всегда нужно смешать текст и данные: «Привет, Билол!», «В корзине 3 товара», «Доставим за 25 минут».

Для этого в Swift есть **интерполяция строк**. Внутри кавычек пишут обратную косую черту и круглые скобки `\( )`, а в скобках — имя константы или переменной. Swift подставит на это место её значение:

```swift
let guest = "Билол"
print("Привет, \(guest)!")
```

На экране появится: `Привет, Билол!`

В одной строке может быть сколько угодно вставок, и вставлять можно значения любых типов — текст, числа, `true` и `false`:

```swift
let table = 5
let guests = 2
print("Столик \(table), гостей: \(guests)")
```

Получится: `Столик 5, гостей: 2`

Обрати внимание на три вещи:

- Черта именно **обратная** — `\`, наклонена влево. На клавиатуре она обычно рядом с Enter.
- Скобки с именем стоят **внутри кавычек**. Всё, что вне `\( )`, остаётся обычным текстом.
- Имя внутри скобок пишется без кавычек.

> ⚠️ Без черты и скобок вставка не сработает. `print("Привет, guest!")` выведет именно `Привет, guest!` — для Swift это просто буквы.

### Задача
В редакторе уже есть данные заказа: `drink`, `price` и `cups`. Не меняй и не переименовывай их — при проверке в них подставятся другие значения.

Выведи две строки чека, собрав их с помощью интерполяции:

1. Название, двоеточие, цена и слова `руб. за чашку`.
2. Слово `Количество:`, число чашек и `шт.`

Текст должен совпасть с примером до последнего пробела и точки.

### Пример
Для данных из редактора:

```text
Раф лавандовый: 320 руб. за чашку
Количество: 2 шт.
```

А если бы в данных были капучино за 270 рублей и одна чашка, получилось бы:

```text
Капучино: 270 руб. за чашку
Количество: 1 шт.
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let drink = "Раф лавандовый"
let price = 320
let cups = 2

// Выведи две строки чека, вставляя значения через \( )
print("\(drink): \(price) руб. за чашку")
print("Количество: \(cups) шт.")
```

## @hint1
Тебе нужны две команды `print` — по одной на каждую строку чека.

Посмотри на первую строку примера и мысленно раздели её на части: что в ней меняется от заказа к заказу, а что остаётся всегда? Название напитка и цена меняются — на их месте должны стоять вставки с именами `drink` и `price`. Двоеточие, пробелы и слова «руб. за чашку» одинаковы всегда — их пишешь обычным текстом.

Вставка — это обратная косая черта и круглые скобки с именем внутри. Вся строка целиком, вместе со вставками, находится в одних кавычках.

Вторая строка устроена так же: постоянный текст, в середине — вставка с именем `cups`.

Главное — не пиши `320` и `Раф лавандовый` прямо в тексте. Проверка запустит твой код с другим заказом, и там должны оказаться другие значения.

## @hint2
Так значения вставляются в текст:

```swift
let table = 5
let guests = 2
print("Столик \(table), гостей: \(guests)")
```

В твоей первой строке тоже будет две вставки: одна в самом начале, вторая — после двоеточия и пробела.

## @hint3
Первая строка почти готова, вторую собери сама:

```swift
print("\(drink): \(___) руб. за чашку")
print("Количество: ___ шт.")
```

В первом пропуске — имя константы с ценой. Во втором — целая вставка: черта, скобки и имя константы с количеством чашек.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Когда Swift встречает внутри строки `\(drink)`, он вычисляет то, что в скобках, — то есть берёт значение константы `drink` — и ставит его на это место. Со вставкой `\(price)` происходит то же самое, причём число `320` само превращается в текст. В итоге из шаблона `"\(drink): \(price) руб. за чашку"` получается готовая строка `Раф лавандовый: 320 руб. за чашку`.

**Почему нельзя просто написать текст целиком.** Если написать `print("Раф лавандовый: 320 руб. за чашку")`, программа будет верно работать ровно для одного заказа. Настоящий чек печатается для тысяч разных заказов. Поэтому текст отделён от данных: шаблон один, а значения подставляются. Именно это и проверяют дополнительные сценарии — с капучино и какао.

**Типичные ошибки:**

- прямая косая черта `/(drink)` вместо обратной `\(drink)`;
- вставка вынесена за кавычки: `print(\(drink) ": ")` — она работает только внутри строки;
- имя в кавычках внутри вставки: `\("drink")` — подставится слово `drink`, а не значение;
- потерян пробел после двоеточия или точка после `шт` — проверка сравнивает текст символ в символ.
