## @description

### Контекст
Экран «Медиатека» показывает все треки пользователя. Они хранятся в двух списках: `savedTracks` — добавленные раньше, и `recentTracks` — добавленные на этой неделе. Внутри каждого списка треки стоят в порядке добавления, от старых к новым.

Менеджер продукта описала, что нужно на экране: общее число треков, переключатель сортировки с двумя вариантами — «По алфавиту» и «Сначала новые» — и строка поиска. А если у пользователя ещё нет ни одного трека, экран должен честно сказать, что медиатека пуста.

### Новое в Swift
В прошлой задаче ты меняла массив. Сегодня — команды, которые массив **не меняют**, а отвечают на вопрос о нём или возвращают новый массив. Часть из них ты уже встречала у строк.

**Склеить два массива** — оператор `+`. Получается новый массив: сначала элементы левого, за ними элементы правого.

```swift
let hotDrinks = ["Раф", "Латте"]
let coldDrinks = ["Лимонад", "Айс-кофе"]
let menu = hotDrinks + coldDrinks
// ["Раф", "Латте", "Лимонад", "Айс-кофе"]
```

**Пуст ли массив** — `isEmpty`. Даёт `true`, если в массиве нет ни одного элемента:

```swift
print(menu.isEmpty)   // false
```

**Есть ли в массиве значение** — `contains`. Тоже отвечает `true` или `false`:

```swift
print(menu.contains("Латте"))   // true
print(menu.contains("Чай"))     // false
```

У массива `contains` ищет **элемент целиком**: `menu.contains("Лат")` даст `false`, потому что элемента `"Лат"` в массиве нет.

**Отсортировать** — `sorted()`. Возвращает новый массив: строки в нём стоят по алфавиту, числа — по возрастанию. Исходный массив остаётся прежним.

```swift
print(menu.sorted())
// ["Айс-кофе", "Латте", "Лимонад", "Раф"]
```

**Развернуть задом наперёд** — `reversed()`. Здесь есть тонкость: эта команда возвращает не готовый массив, а особый «взгляд на массив с конца». Чтобы получить обычный массив, результат оборачивают в `Array( )` — так же, как ты превращала значения с помощью `Int( )` и `String( )`:

```swift
let fromEnd = Array(menu.reversed())
// ["Айс-кофе", "Лимонад", "Латте", "Раф"]
```

> ⚠️ Если напечатать `menu.reversed()` без `Array( )`, на экране появится что-то вроде `ReversedCollection<Array<String>>(...)`. Увидишь такое в выводе — значит, обёртка забыта.

> 💡 Пустой массив записывается как `[]`. По пустым скобкам Swift не может понять, что в нём будет лежать, поэтому тип указывают явно: `let menu: [String] = []`.

### Задача
В редакторе есть списки `savedTracks` и `recentTracks` и поисковый запрос `query`. Не переименовывай их — проверка подставит другие данные.

1. Объяви константу `library` — общий список: сначала все треки из `savedTracks`, за ними все из `recentTracks`.
2. Если `library` пуст, выведи одну строку `Медиатека пуста` — и больше ничего.
3. Иначе выведи четыре строки:
   - `Всего треков:` и количество треков в `library`;
   - `По алфавиту:` и массив треков, отсортированный по алфавиту;
   - `Сначала новые:` и массив треков в обратном порядке — от последнего добавленного к первому;
   - название из `query`, двоеточие и `есть в медиатеке`, если такой трек есть в `library`, или `нет в медиатеке`, если его нет.

### Пример
Для данных из редактора:

```text
Всего треков: 5
По алфавиту: ["Апрель", "Белый шум", "Комета", "Маяк", "Океан внутри"]
Сначала новые: ["Белый шум", "Комета", "Маяк", "Апрель", "Океан внутри"]
Маяк: есть в медиатеке
```

Если бы искали трек `Вальс`, последняя строка была бы такой:

```text
Вальс: нет в медиатеке
```

А если оба списка пусты:

```text
Медиатека пуста
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let savedTracks = ["Океан внутри", "Апрель", "Маяк"]
let recentTracks = ["Комета", "Белый шум"]
let query = "Маяк"

// 1. Собери общий список library: сначала savedTracks, потом recentTracks
let library = savedTracks + recentTracks

// 2. Если library пуст — выведи "Медиатека пуста"
// 3. Иначе выведи четыре строки: количество, по алфавиту, сначала новые, результат поиска
if library.isEmpty {
    print("Медиатека пуста")
} else {
    print("Всего треков: \(library.count)")
    print("По алфавиту: \(library.sorted())")
    print("Сначала новые: \(Array(library.reversed()))")
    if library.contains(query) {
        print("\(query): есть в медиатеке")
    } else {
        print("\(query): нет в медиатеке")
    }
}
```

## @hint1
Начни с общего списка. Два массива склеиваются тем же знаком, которым ты склеивала строки. Порядок слагаемых важен: что стоит слева, то и окажется в начале. Результат положи в константу `library` — дальше вся работа идёт только с ней.

Теперь развилка. У экрана два разных состояния: «пусто» и «есть треки». Это обычное условие с двумя ветками, а вопрос «пуст ли массив» задаётся свойством `isEmpty`.

В ветке «есть треки» четыре вывода. Количество — знакомый `count`. Список по алфавиту — команда `sorted()`, её результат можно вставить прямо в текст. Список «сначала новые» — это `library` задом наперёд: команда `reversed()`, но её результат нужно обернуть в `Array( )`, иначе напечатается не массив, а служебное описание.

Последняя строка зависит от ответа на вопрос «есть ли в `library` трек из `query`». Этот вопрос задаёт команда `contains`. Ответ — `true` или `false`, так что здесь нужно ещё одно условие внутри ветки: в одном случае печатается один текст, в другом — другой.

## @hint2
Вот как выглядят новые команды на другом массиве:

```swift
let menu = ["Раф", "Латте"] + ["Лимонад"]

print(menu.isEmpty)               // false
print(menu.contains("Латте"))     // true
print(menu.sorted())              // ["Латте", "Лимонад", "Раф"]
print(Array(menu.reversed()))     // ["Лимонад", "Латте", "Раф"]
```

`isEmpty` и `contains` дают `true` или `false`, поэтому их можно ставить прямо в условие: `if menu.isEmpty { ... } else { ... }`.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `savedTracks + recentTracks` создаёт новый массив: сначала элементы первого, потом второго. Так как внутри каждого списка треки идут от старых к новым, в `library` самый новый трек оказывается последним. Условие `library.isEmpty` делит программу на две ветки. В первой одна строка. Во второй — четыре: `count` даёт количество, `sorted()` — список по алфавиту, `Array(library.reversed())` — список от последнего к первому, а вложенное условие с `contains` выбирает текст про поиск.

**Почему нужен `Array( )`.** `reversed()` не строит новый массив, а возвращает «взгляд на массив с конца» — так быстрее, если нужно просто пройти по элементам. Но напечатать его как обычный массив не получится. `Array( )` превращает этот взгляд в настоящий массив.

**Почему `library` не меняется.** `sorted()` и `reversed()` возвращают новые значения, а исходный массив не трогают. Поэтому `library` объявлена через `let`, и строка «Сначала новые» разворачивает исходный порядок, а не отсортированный.

**Почему поиск не нашёл «Кофе».** `contains` у массива сравнивает запрос с каждым элементом целиком. Трек называется «Кофе и дождь», а элемента «Кофе» в массиве нет. Поиск по части названия ты сможешь сделать, когда изучишь циклы.

Последние строки можно записать короче, через тернарный оператор: `print(library.contains(query) ? "\(query): есть в медиатеке" : "\(query): нет в медиатеке")`. Оба варианта верные.

**Типичные ошибки:**

- `recentTracks + savedTracks` — порядок перепутан, «Сначала новые» покажет не то;
- `library.reversed()` без `Array( )` — в выводе появится `ReversedCollection...`;
- `library.sorted()` отдельной строкой в надежде, что `library` отсортируется, — результат просто пропадёт, а массив останется прежним;
- `library.count == 0` вместо `isEmpty` — работает, но `isEmpty` читается понятнее, и так принято писать.
