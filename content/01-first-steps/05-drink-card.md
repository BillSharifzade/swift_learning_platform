## @description

### Контекст
Дизайнер нарисовал карточку напитка: на ней название, цена, объём стакана и пометка, есть ли напиток сейчас в наличии.

Данные для карточки будут приходить с сервера. Серверный разработчик прислал описание полей и просит: «Заведите у себя эти поля строго с такими типами, иначе при обмене данными будут ошибки».

| Поле | Тип | Что это |
|---|---|---|
| `drinkName` | String | название напитка |
| `price` | Int | цена в рублях |
| `volume` | Double | объём в литрах |
| `isAvailable` | Bool | есть ли в наличии |

### Новое в Swift
У каждого значения в Swift есть **тип** — он говорит, что это за данные и что с ними можно делать. Четыре основных типа встречаются в любом приложении:

- **`String`** — текст. Пишется в кавычках: `"Капучино"`.
- **`Int`** — целое число: `3`, `250`, `-10`. Количество, цена в рублях, номер заказа.
- **`Double`** — дробное число. Дробная часть отделяется **точкой**: `0.5`, `36.6`, `4.25`. Вес, расстояние, рейтинг.
- **`Bool`** — «да» или «нет». Бывает только двух значений: `true` (да, правда) и `false` (нет, ложь). Пишутся маленькими буквами и без кавычек.

Раньше ты не указывала тип — Swift определял его сам по значению. Увидел кавычки — значит, `String`. Увидел целое число — `Int`.

Но тип можно указать и **явно**: после имени ставится двоеточие и название типа.

```swift
let city: String = "Казань"
let tables: Int = 12
let rating: Double = 4.8
let hasTerrace: Bool = true
```

Читается так: «пусть `tables` типа `Int` будет равно 12».

**Зачем указывать тип, если Swift и сам умеет?** Во-первых, так код понятнее читателю. Во-вторых, это страховка: если по ошибке положить в `tables` текст, Swift сразу скажет, что типы не сходятся.

> ⚠️ Тип нельзя поменять. Если константа объявлена как `Int`, в ней всегда будет целое число. Положить туда текст `"12"` или дробное `12.5` не получится. Строгость к типам — одна из главных черт Swift: она ловит множество ошибок ещё до запуска программы.

### Задача
Объяви четыре значения по таблице из описания. У каждого **явно укажи тип** через двоеточие:

1. Константа `drinkName` типа `String` со значением `"Раф лавандовый"`.
2. Константа `price` типа `Int` со значением `320`.
3. Константа `volume` типа `Double` со значением `0.35`.
4. Переменная `isAvailable` типа `Bool` со значением `true`. Это именно переменная (`var`): наличие меняется в течение дня.

Затем выведи все четыре значения по очереди, каждое своей командой `print`.

### Пример
```text
Раф лавандовый
320
0.35
true
```

## @solution
```swift
// Карточка напитка. Поля и типы — из таблицы в описании.
// Объяви drinkName, price, volume и isAvailable с явным указанием типа
let drinkName: String = "Раф лавандовый"
let price: Int = 320
let volume: Double = 0.35
var isAvailable: Bool = true

// Выведи все четыре значения по очереди
print(drinkName)
print(price)
print(volume)
print(isAvailable)
```

## @hint1
Нужно написать четыре объявления и четыре вывода.

Каждое объявление строится по одной схеме: слово `let` или `var`, имя, двоеточие, название типа, знак равенства, значение. Имена и типы возьми из таблицы в описании. Три значения не меняются — это константы. Четвёртое, наличие, по условию должно быть переменной.

Следи за тем, как записываются значения разных типов. Текст — в кавычках. Целое число — просто цифрами. Дробное — через точку, а не через запятую. Логическое значение — словом `true`, маленькими буквами и без кавычек.

Для вывода достаточно `print` с именем в скобках — он умеет выводить значения любого типа.

## @hint2

По такому же образцу объяви четыре поля карточки напитка.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В каждой строке объявления после имени стоит двоеточие и тип. Так мы прямо говорим Swift, данные какого вида здесь лежат: `String` — текст, `Int` — целое число, `Double` — дробное, `Bool` — да или нет. Справа от знака `=` стоит значение, и оно обязано подходить к заявленному типу.

**Почему у цены `Int`, а у объёма `Double`.** Цена в рублях у нас целая, копеек нет — подходит `Int`. Объём стакана — треть литра с небольшим, целым числом его не записать, нужен `Double`. Выбирать тип под смысл данных — обычная ежедневная работа разработчика.

**Почему `isAvailable` — `var`.** Напиток может закончиться в середине дня, и тогда приложение должно поменять значение на `false`. Название, цена и объём на карточке не меняются, поэтому они `let`.

**Типичные ошибки:**

- `0,35` через запятую — Swift понимает дробные числа только с точкой;
- `"320"` или `"true"` в кавычках — это уже текст, и к типам `Int` и `Bool` он не подойдёт;
- `True` с большой буквы или `string` с маленькой — названия типов пишутся с большой буквы, а `true` и `false` — с маленькой;
- двоеточие забыто или поставлено после типа.
