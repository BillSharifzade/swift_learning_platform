## @description

### Контекст
Первое устройство в «Гнезде» — умная лампа. Приложению нужна её модель: как лампа называется, включена ли она и какая у неё яркость.

Тимлид оставил в задаче комментарий: «Лампа в комнате одна, а управляют ею с разных экранов. Поэтому устройства у нас — классы, а не структуры. Почему это важно, разберём в следующей задаче. Сейчас просто опиши лампу классом. Увидишь: это почти как структура».

### Новое в Swift
Класс объявляют словом `class`. Внутри — уже знакомые тебе свойства и методы:

```swift
class SmartSocket {
    let name: String
    var isOn = false
    var powerLimit: Int

    init(name: String, powerLimit: Int) {
        self.name = name
        self.powerLimit = powerLimit
    }

    func switchState() {
        isOn = !isOn
    }

    func label() -> String {
        return "\(name), до \(powerLimit) Вт"
    }
}

let socket = SmartSocket(name: "Розетка у чайника", powerLimit: 2000)
socket.switchState()
print(socket.isOn)      // true
print(socket.label())   // Розетка у чайника, до 2000 Вт
```

То, что создано по классу, называют **объектом** (или экземпляром класса). Здесь `socket` — объект класса `SmartSocket`.

От структуры этот код отличается в двух местах.

**Инициализатор нужно написать самой.** Структура получала `init` автоматически. Класс — нет. Правило такое: к моменту, когда объект создан, у каждого свойства должно быть значение. У `isOn` оно записано прямо в объявлении, поэтому в `init` его нет. А `name` и `powerLimit` заполняет инициализатор. Запись `self.name = name` ты уже встречала в «Уюте»: слева свойство объекта, справа параметр с тем же именем.

Если свойства без значений есть, а `init` нет, Swift не соберёт код и сообщит, что у класса нет инициализатора.

**Слово `mutating` не нужно.** Метод `switchState()` меняет свойство `isOn`, но перед `func` ничего нет. Методы класса меняют свойства свободно.

> 💡 Обрати внимание: объект лежит в константе `let socket`, а его свойство всё равно меняется. Со структурой так не получилось бы. Это не ошибка, а главная особенность классов — о ней следующая задача. Пока запомни: объекты классов обычно хранят в `let`.

### Задача
Объяви класс `Lamp`. Сценарий внизу файла уже написан — он заработает, когда класс будет готов.

1. Свойства:
   - `name` — название лампы, `String`, константа;
   - `isOn` — включена ли лампа, `Bool`, переменная; новая лампа выключена (`false`);
   - `brightness` — яркость в процентах, `Int`, переменная.
2. Инициализатор `init(name:brightness:)` — заполняет название и яркость.
3. Методы `turnOn()` и `turnOff()` — включают и выключают лампу, то есть меняют `isOn`. Параметров и результата у них нет.
4. Метод `status()` возвращает `String` — строку для списка устройств:
   - если лампа включена: название, двоеточие, `включена, яркость` и число со знаком процента — `Торшер: включена, яркость 70%`;
   - если выключена: `Торшер: выключена`.

### Пример
```swift
let floorLamp = Lamp(name: "Торшер", brightness: 70)
floorLamp.status()    // "Торшер: выключена"
floorLamp.turnOn()
floorLamp.status()    // "Торшер: включена, яркость 70%"
```

Сценарий из редактора должен вывести:

```text
Торшер: выключена
Торшер: включена, яркость 70%
Торшер: включена, яркость 30%
Торшер: выключена
```

## @solution
```swift
// Умная лампа приложения «Гнездо».
// Объяви здесь класс Lamp: свойства, init, методы turnOn(), turnOff() и status()
class Lamp {
    let name: String
    var isOn = false
    var brightness: Int

    init(name: String, brightness: Int) {
        self.name = name
        self.brightness = brightness
    }

    func turnOn() {
        isOn = true
    }

    func turnOff() {
        isOn = false
    }

    func status() -> String {
        if isOn {
            return "\(name): включена, яркость \(brightness)%"
        } else {
            return "\(name): выключена"
        }
    }
}

// Сценарий для проверки: вечер в гостиной. Этот код менять не нужно
let floorLamp = Lamp(name: "Торшер", brightness: 70)
print(floorLamp.status())

floorLamp.turnOn()
print(floorLamp.status())

floorLamp.brightness = 30
print(floorLamp.status())

floorLamp.turnOff()
print(floorLamp.status())
```

## @rules
- must: /\bclass\s+Lamp\b/ :: Лампа должна быть классом: объяви её словом `class`, а не `struct`.

## @hint1
Класс записывается почти так же, как структура, только начинается со слова `class`. Внутри фигурных скобок по порядку идут свойства, инициализатор и методы.

Свойств три. Название не меняется, поэтому это константа. Состояние и яркость меняются — это переменные. Состоянию `isOn` сразу дай значение по умолчанию: новая лампа выключена.

Теперь инициализатор. У `name` и `brightness` значений по умолчанию нет, и сам класс инициализатор не создаст. Напиши `init` с двумя параметрами — названием и яркостью. Внутри запиши каждый параметр в одноимённое свойство через `self`.

Методы `turnOn()` и `turnOff()` — по одной строке: в `isOn` кладётся `true` или `false`. Слово `mutating` не нужно.

Метод `status()` возвращает строку. В нём одна развилка по `isOn`: для включённой лампы — текст с названием и яркостью, для выключенной — текст только с названием. Обе строки собери интерполяцией из свойств.

## @hint2
Так выглядит класс со свойствами, инициализатором и методом:

```swift

    var isOn = false
    var powerLimit: Int

        self.name = name
        self.powerLimit = powerLimit

        isOn = false
```

В твоём классе `Lamp` всё устроено так же: вместо `powerLimit` — яркость `brightness`, методов выключения и включения два, и ещё есть `status()` с развилкой `if isOn { ... } else { ... }`.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Слово `class` объявляет новый тип `Lamp`. У него три свойства. `isOn` получает значение `false` прямо в объявлении, поэтому каждая новая лампа выключена. `name` и `brightness` заполняет инициализатор: `self.name` — это свойство объекта, а просто `name` — параметр, который пришёл в скобках при создании. Методы `turnOn()` и `turnOff()` записывают в `isOn` новое значение. Метод `status()` смотрит на `isOn` и собирает одну из двух строк.

**Почему нужен `init`.** Структура сама создавала инициализатор по списку свойств. У класса такого подарка нет: всё, что не получило значение в объявлении, ты обязана заполнить в `init`. Зато правило простое и строгое: объект не может появиться «недозаполненным».

**Почему нет `mutating`.** Это слово нужно только структурам. Методы класса меняют свойства без особых пометок. И вызвать их можно даже у объекта, который лежит в `let`, — как `floorLamp` в сценарии. Почему так, ты узнаешь в следующей задаче.

**Типичные ошибки:**

- свойства объявлены, а `init` не написан — Swift сообщит, что у класса нет инициализатора;
- в `init` написано `name = name` без `self` — Swift не поймёт, где свойство, а где параметр;
- `mutating func turnOn()` — в классе это слово запрещено;
- `turnOn()` написан как переключатель `isOn = !isOn` — второй вызов подряд выключит лампу;
- в `status()` текст написан целиком, с «Торшером» и числом 70, — для другой лампы он окажется неверным.
