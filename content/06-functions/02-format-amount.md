## @description

### Контекст
На экране «Операции» каждая строка заканчивается суммой. Дизайнер прислала правила: пополнения показываем с плюсом, списания — с минусом, а нулевую сумму — без знака.

Такая запись нужна не только в списке операций, но и в уведомлениях, и в отчётах — всего в пяти местах приложения. Тимлид просит: «Сделай одну функцию. На вход — сумма, на выход — готовый текст. А что с этим текстом делать — напечатать, показать на экране или отправить в уведомлении — решит тот, кто функцию вызвал».

### Новое в Swift
Функция из прошлой задачи всегда делала одно и то же. Чтобы функция работала с разными данными, ей нужны вход и выход.

**Параметр — вход функции.** В круглых скобках объявления пишут имя параметра и его тип через двоеточие — так же, как в константе с явным типом:

```swift
func printBonus(points: Int) {
    print("Бонусов: \(points)")
}
```

Внутри тела `points` — обычная константа. Её значение задаётся при вызове: в скобках пишут имя параметра, двоеточие и значение. Это значение называют **аргументом**:

```swift
printBonus(points: 120)   // Бонусов: 120
printBonus(points: 45)    // Бонусов: 45
```

**Результат — выход функции.** Часто функция должна не печатать, а *отдать* значение тому, кто её вызвал. Тогда после скобок ставят стрелку `->` (минус и знак «больше») и тип результата, а в теле пишут слово `return` и само значение:

```swift
func bonusText(points: Int) -> String {
    return "Бонусов: \(points)"
}
```

Вызов такой функции сам становится значением. Его можно положить в константу или сразу передать в `print`:

```swift
let text = bonusText(points: 120)
print(text)                       // Бонусов: 120
print(bonusText(points: 45))      // Бонусов: 45
```

Два правила про `return`:

- `return` сразу **завершает** функцию. Всё, что написано в теле ниже, уже не выполнится.
- Если функция обещала результат, она обязана вернуть его при любом ходе событий — и когда условие выполнено, и когда нет:

```swift
func accountStatus(balance: Int) -> String {
    if balance < 0 {
        return "Счёт в минусе"
    }
    return "Счёт в порядке"
}
```

При отрицательном балансе сработает первый `return`, и до второго дело не дойдёт. Иначе функция пропустит блок `if`, дойдёт до конца и вернёт второй текст.

> 💡 Печатать и возвращать — разные вещи. `print` показывает текст на экране, и на этом всё. `return` отдаёт значение обратно в код, и с ним можно работать дальше.

### Задача
В редакторе уже есть суммы трёх операций: `salary`, `groceries` и `correction`.

1. Объяви функцию `formatAmount` с одним параметром `amount` типа `Int`. Функция возвращает `String`.
2. Правила текста:
   - сумма **больше нуля** — плюс, число, пробел и `руб.`, например `+1500 руб.`;
   - сумма **равна нулю или меньше нуля** — число, пробел и `руб.` без дополнительных знаков: `0 руб.`, `-300 руб.` Минус у отрицательного числа Swift поставит сам.
3. Внутри функции ничего не печатай — она только возвращает текст.
4. Ниже вызови функцию три раза — для `salary`, `groceries` и `correction` — и выведи каждый результат командой `print`.

### Пример
Вывод программы:

```text
+85000 руб.
-2350 руб.
0 руб.
```

Проверка вызовет твою функцию и с другими суммами:

```swift
formatAmount(amount: 1500)   // "+1500 руб."
formatAmount(amount: -300)   // "-300 руб."
formatAmount(amount: 0)      // "0 руб."
```

## @solution
```swift
// Суммы операций: зарплата, покупка продуктов и корректировка
let salary = 85000
let groceries = -2350
let correction = 0

// 1. Объяви функцию formatAmount(amount:), которая возвращает текст суммы
func formatAmount(amount: Int) -> String {
    if amount > 0 {
        return "+\(amount) руб."
    }
    return "\(amount) руб."
}

// 2. Вызови функцию для каждой из трёх сумм и выведи результаты
print(formatAmount(amount: salary))
print(formatAmount(amount: groceries))
print(formatAmount(amount: correction))
```

## @hint1
Начни с объявления. Функции нужен вход — сумма операции. Значит, в круглых скобках после имени `formatAmount` стоит параметр `amount` и через двоеточие его тип, целое число. Функции нужен и выход — готовый текст. Значит, после скобок идёт стрелка и тип результата, строка.

Теперь тело. Вариантов текста два: с плюсом в начале и без него. Плюс нужен только тогда, когда сумма больше нуля, — это обычное условие `if`. Внутри условия верни строку, собранную интерполяцией: плюс, значение `amount`, пробел и `руб.` После блока `if` верни строку без плюса. Отдельно проверять отрицательные числа не нужно: минус — часть самого числа, он появится в тексте сам.

Обрати внимание: внутри функции нет ни одного `print`. Функция только возвращает текст через `return`.

Вторая часть — три вызова. При вызове в скобках пишется имя параметра, двоеточие и значение. Вызов функции — это уже готовая строка, поэтому его можно поставить прямо в скобки команды `print`.

## @hint2
Функция с параметром, результатом и условием выглядит так:

```swift
func accountStatus(balance: Int) -> String {
    if balance < 0 {
        return "Счёт в минусе"
    }
    return "Счёт в порядке"
}

print(accountStatus(balance: -500))
```

У твоей функции тот же «скелет»: параметр типа `Int`, результат типа `String`, один `return` внутри `if` и один после него. Только условие другое, а возвращаемые строки собираются интерполяцией из `amount`.

## @hint3
Объявление и первый вызов готовы. Допиши условие, вторую строку и остальные вызовы:

```swift
func formatAmount(amount: Int) -> String {
    if ___ {
        return "+\(amount) руб."
    }
    return ___
}

print(formatAmount(amount: salary))
print(formatAmount(amount: ___))
print(___)
```

В первом пропуске — условие «сумма больше нуля». Во втором — строка без плюса: значение `amount`, пробел и `руб.` В третьем и четвёртом — вызовы для `groceries` и `correction`, по образцу первого.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В объявлении `func formatAmount(amount: Int) -> String` записан договор: функция получает одно целое число и обязуется вернуть строку. При вызове `formatAmount(amount: salary)` значение `85000` попадает в параметр `amount`. Условие `amount > 0` верно, поэтому срабатывает первый `return` — функция отдаёт строку `+85000 руб.` и сразу завершается.

При вызове с `-2350` условие ложно, блок `if` пропускается, и функция доходит до второго `return`. Интерполяция превращает число `-2350` в текст вместе с его минусом, получается `-2350 руб.` С нулём происходит то же самое: ноль не больше нуля, значит, плюса не будет.

**Почему после `if` нет `else`.** Можно написать и с `else` — результат будет тем же. Но `return` внутри `if` уже завершает функцию, поэтому всё, что стоит ниже, выполняется только тогда, когда условие ложно. Так код получается короче и ровнее.

**Почему функция возвращает, а не печатает.** Если бы внутри стоял `print`, функция годилась бы только для вывода на экран. А текст суммы нужен в уведомлениях, отчётах, на кнопках. Функция, которая возвращает значение, подходит для всех этих мест: вызвавший код сам решает, что делать с результатом. Здесь мы передали его в `print`, а проверка сравнивает его с ожидаемым текстом.

**Типичные ошибки:**

- забыта стрелка и тип результата (`-> String`) — тогда Swift считает, что функция ничего не возвращает, и не разрешит `return` со значением;
- `print` вместо `return` внутри функции — текст появится на экране, но функция ничего не отдаст;
- условие `amount >= 0` — тогда ноль получит плюс: `+0 руб.`;
- вызов без имени параметра: `formatAmount(salary)` — пока имя параметра при вызове обязательно;
- `return` стоит только внутри `if` — Swift сообщит, что функция не всегда возвращает значение.
