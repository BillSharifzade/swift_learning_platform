## @description

### Контекст
В «Волне» появится раздел «Статистика»: на странице каждого трека будет видно, сколько раз его слушали. Для этого плеер должен помнить число прослушиваний каждого трека.

Массив тут неудобен. В нём пришлось бы помнить, что число на третьем месте относится к такому-то треку, а на пятом — к другому. Хочется спрашивать прямо по названию: «сколько раз слушали „Маяк“?»

Тимлид пишет: «Счётчики лежат в словаре `playCounts`. Нужно обработать три события: трек доиграл, статистику перенесли из другого плеера, пользователь открыл страницу трека».

### Новое в Swift
**Словарь** — это коллекция пар «ключ — значение». По ключу сразу находится его значение, как в бумажном словаре по слову находится перевод.

Словарь тоже пишут в квадратных скобках, но каждая запись — это пара через двоеточие:

```swift
var stock = ["Свитер": 4, "Шарф": 10, "Пальто": 1]
```

Здесь ключи — названия товаров, значения — сколько штук на складе. Тип такого словаря — `[String: Int]`: ключи-строки, значения-числа. Ключи не повторяются: у одного ключа всегда одно значение.

**Прочитать значение.** В квадратных скобках пишут ключ и значение «на случай, если такого ключа нет»:

```swift
print(stock["Шарф", default: 0])    // 10
print(stock["Платье", default: 0])  // 0 — такого ключа нет
```

Зачем нужен `default:`? В массиве ты сама следишь, чтобы индекс существовал. В словаре угадать заранее нельзя: ключ может быть, а может и не быть. Поэтому при чтении сразу говорят, что вернуть в запасном случае.

> ⚠️ Читать можно и без `default:`, но тогда Swift вернёт значение в особой «обёртке» — с ней ты познакомишься в модуле про опционалы. Пока всегда пиши `default:`. Если в выводе появилось `Optional(10)` или `nil`, а проверка заговорила про «опционал», значит, `default:` где-то забыт.

**Записать значение.** Ключ в скобках, знак равенства и значение. Если ключа не было — появится новая запись. Если был — старое значение заменится:

```swift
stock["Платье"] = 6    // новая запись
stock["Свитер"] = 3    // было 4, стало 3
```

**Изменить значение относительно старого.** Чтение с `default:` можно соединить со знакомым `+=`:

```swift
stock["Шарф", default: 0] += 5      // было 10, стало 15
stock["Перчатки", default: 0] += 2  // записи не было: 0 + 2 = 2
```

Swift берёт текущее значение (или запасное, если ключа нет), прибавляет число и записывает результат обратно. Это самый частый способ вести счётчики.

> 💡 Пустой словарь записывается как `[:]`, и тип ему нужно указать явно: `var stock: [String: Int] = [:]`.

### Задача
В редакторе есть словарь `playCounts` и данные трёх событий. Не переименовывай их — проверка подставит другие данные.

1. Трек `finishedTrack` только что доиграл до конца. Увеличь его счётчик в `playCounts` на 1. Если трека в словаре ещё нет, отсчёт идёт от нуля.
2. Выведи строку про этот трек: название, запятая, `прослушиваний:` и новое значение счётчика.
3. Пользователь перенёс статистику из другого плеера. Запиши в `playCounts` для трека `importedTrack` значение `importedCount`. Если у трека уже был счётчик, он заменяется.
4. Выведи такую же строку про `importedTrack`.
5. Пользователь открыл страницу трека `openedTrack`. Выведи такую же строку про него. Если трека нет в словаре, счётчик равен 0. Сам словарь на этом шаге не меняй.

### Пример
Для данных из редактора:

```text
Апрель, прослушиваний: 4
Океан внутри, прослушиваний: 25
Белый шум, прослушиваний: 0
```

Трек «Апрель» слушали 3 раза, стало 4. «Океан внутри» получил перенесённое значение. А «Белый шум» ещё ни разу не слушали — записи о нём в словаре нет.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
var playCounts = ["Маяк": 12, "Апрель": 3, "Комета": 7]
let finishedTrack = "Апрель"
let importedTrack = "Океан внутри"
let importedCount = 25
let openedTrack = "Белый шум"

// 1. Трек finishedTrack доиграл: увеличь его счётчик на 1
playCounts[finishedTrack, default: 0] += 1

// 2. Выведи строку про finishedTrack
print("\(finishedTrack), прослушиваний: \(playCounts[finishedTrack, default: 0])")

// 3. Перенос статистики: запиши importedCount для importedTrack
playCounts[importedTrack] = importedCount

// 4. Выведи строку про importedTrack
print("\(importedTrack), прослушиваний: \(playCounts[importedTrack, default: 0])")

// 5. Выведи строку про openedTrack (если трека нет в словаре — 0)
print("\(openedTrack), прослушиваний: \(playCounts[openedTrack, default: 0])")
```

## @hint1
В задаче пять шагов, и на каждый хватит одной строки. Два шага меняют словарь, три — читают из него и печатают.

Шаг первый — счётчик. Нужно взять текущее число прослушиваний трека, прибавить единицу и записать обратно. В Swift это делается одной строкой: слева обращение к словарю по ключу с запасным значением ноль, затем оператор «прибавить и записать», затем единица. Запасное значение здесь важно: если трек слушают впервые, записи о нём ещё нет, и отсчёт начнётся с нуля.

Шаг третий — простая запись: слева словарь с ключом в квадратных скобках, справа новое значение. Никакого запасного значения при записи не нужно.

Шаги два, четыре и пять печатают одинаково устроенную строку: название трека, запятая, слово «прослушиваний», двоеточие и число из словаря. Число читается по ключу и обязательно с запасным значением ноль — прямо внутри интерполяции. Отличаются три строки только тем, какая константа служит ключом.

Ключи нигде не пиши текстом в кавычках: используй константы `finishedTrack`, `importedTrack` и `openedTrack`.

## @hint2
Вот три действия со словарём на другом примере — чтение, запись и изменение счётчика:

```swift
var stock = ["Свитер": 4, "Шарф": 10]
let item = "Шарф"

stock[item, default: 0] += 1          // счётчик вырос на 1
stock["Платье"] = 6                   // запись нового значения
print("\(item), на складе: \(stock[item, default: 0])")
```

Ключом может быть не только текст в кавычках, но и константа со строкой — как `item` в этом примере.

## @hint3
Первые три шага готовы. Допиши два последних вывода:

```swift
playCounts[finishedTrack, default: 0] += 1
print("\(finishedTrack), прослушиваний: \(playCounts[finishedTrack, default: 0])")

playCounts[importedTrack] = importedCount
print("\(importedTrack), прослушиваний: \(playCounts[___, default: 0])")

print("\(___), прослушиваний: \(playCounts[___, default: ___])")
```

В четвёртой строке ключ — трек, статистику которого перенесли. В последней строке оба первых пропуска — трек, страницу которого открыли, а последний пропуск — число на случай, если такого трека в словаре нет.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Строка `playCounts[finishedTrack, default: 0] += 1` делает три вещи подряд: читает значение по ключу (а если ключа нет — берёт `0`), прибавляет единицу и записывает результат в словарь по тому же ключу. Для «Апреля» было 3, стало 4. Для трека, которого в словаре не было, получится `0 + 1`, и в словаре появится новая запись со значением 1.

`playCounts[importedTrack] = importedCount` — обычная запись. Ей всё равно, был ли такой ключ: если был — значение заменится, если нет — добавится новая пара.

Три команды `print` читают значения. В последней ключа «Белый шум» в словаре нет, поэтому срабатывает `default: 0`. Важно, что чтение с `default:` **ничего не записывает** в словарь: запись о треке «Белый шум» так и не появляется.

**Почему везде `default:`.** Словарь не может знать заранее, есть ли в нём нужный ключ. `default:` — это твой ответ на вопрос «а что, если нет?». Для счётчика естественный ответ — ноль: трек, которого нет в статистике, слушали ноль раз.

**Почему ключи — константы, а не текст.** Проверка запускает программу с другими треками. Если написать `playCounts["Апрель", default: 0] += 1`, код будет работать только для одного трека.

**Типичные ошибки:**

- `playCounts[finishedTrack] += 1` без `default:` — Swift не соберёт программу: он не уверен, что по этому ключу есть число;
- `print(playCounts[openedTrack])` без `default:` — в выводе появится `Optional(...)` или `nil`;
- `playCounts[finishedTrack] = 1` — счётчик не увеличивается, а становится равным единице;
- `default: 1` в первом шаге — тогда новый трек сразу получит 2 прослушивания;
- `playCounts[openedTrack] = 0` на последнем шаге — это затрёт настоящий счётчик, если трек уже слушали.
