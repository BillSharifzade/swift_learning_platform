## @description

### Контекст
Во время тренировки таймер «Пульса» подаёт сигнал через равные промежутки — например, каждые пять минут. На каждом сигнале браслет записывает пульс, а экран показывает отметку: минута и пульс.

Тимлид описывает два особых случая: «Иногда датчик теряет контакт с кожей, и записи за эту минуту просто нет. Такую отметку не показываем. А если пульс выше безопасного — выводим предупреждение и сразу останавливаем таймер. Здоровье важнее плана».

### Новое в Swift
**Цикл с шагом: `stride`.** Диапазон `1...30` перебирает числа подряд: 1, 2, 3... А сигналы нужны на 5-й, 10-й, 15-й минуте. Для счёта с шагом есть функция `stride` (по-английски — «шаг»):

```swift
for meter in stride(from: 100, through: 400, by: 100) {
    print("Отметка \(meter) м")
}
```

Получится 100, 200, 300, 400. У функции три параметра: `from` — откуда начать, `by` — шаг, а конец задаётся одним из двух слов:

- `through` — конец **включается**: `stride(from: 100, through: 400, by: 100)` дойдёт до 400;
- `to` — конец **не включается**: `stride(from: 100, to: 400, by: 100)` остановится на 300.

С отрицательным шагом счёт идёт назад: `stride(from: 3, through: 1, by: -1)` даст 3, 2, 1 — готовый обратный отсчёт перед стартом.

**Пропустить повтор: `continue`.** Команда `continue` говорит: «с этим элементом всё, переходи к следующему». Остаток тела на этом повторе не выполняется, но цикл продолжает работу:

```swift
let weekPlan = ["Бег", "Отдых", "Йога", "Отдых", "Силовая"]
for activity in weekPlan {
    if activity == "Отдых" {
        continue
    }
    print("Собери сумку: \(activity)")
}
```

Строки появятся только для бега, йоги и силовой.

**Остановить цикл: `break`.** Команда `break` завершает цикл целиком, даже если элементы ещё остались. Программа сразу переходит к коду после закрывающей скобки цикла:

```swift
let sessions = [20, 35, 50, 25]
var freeMinutes = 60
for session in sessions {
    if session > freeMinutes {
        print("На остальное времени не хватит")
        break
    }
    freeMinutes -= session
    print("Успеваем тренировку на \(session) мин")
}
print("План готов")
```

Первые две тренировки помещаются. На третьей свободных минут остаётся 5, условие срабатывает, и цикл прекращается. Четвёртую тренировку программа даже не рассматривает. Строка `План готов` выводится в любом случае: она стоит после цикла.

Коротко: `continue` — «пропусти этот повтор», `break` — «выйди из цикла совсем».

### Задача
В редакторе есть входные данные и вывод заголовка. Словарь `pulseLog` хранит показания браслета: ключ — минута, значение — пульс. Не переименовывай входные данные: проверка подставит другие.

1. Пройди циклом по отметкам времени: от `interval` до `totalMinutes` **включительно**, с шагом `interval`. Используй `stride`.
2. На каждой отметке возьми пульс из `pulseLog` по минуте. Если записи нет, считай пульс равным `0` — для этого подойдёт чтение с `default: 0`.
3. Пульс равен `0` — датчик молчал. Пропусти отметку через `continue`, ничего не выводя.
4. Пульс **больше** `maxPulse` — выведи строку с предупреждением, как в примере, и останови цикл через `break`.
5. В остальных случаях выведи обычную строку: минута и пульс.
6. После цикла выведи `Таймер выключен`.

### Пример
Для данных из редактора:

```text

5 мин: пульс 112
10 мин: пульс 128
20 мин: пульс 141
25 мин: пульс 176 - слишком высокий, стоп
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let totalMinutes = 30
let interval = 5
let maxPulse = 170
let pulseLog = [5: 112, 10: 128, 20: 141, 25: 176, 30: 150]

print("Тренировка: \(totalMinutes) мин, сигнал каждые \(interval) мин")

// Пройди по отметкам: от interval до totalMinutes включительно, с шагом interval.
// На каждой отметке:
//   - возьми пульс из pulseLog (если записи нет, считай его равным 0);
//   - пульс 0: датчик молчал, пропусти отметку;
//   - пульс больше maxPulse: выведи предупреждение и останови цикл;
//   - иначе выведи обычную строку "5 мин: пульс 112".
for minute in stride(from: interval, through: totalMinutes, by: interval) {
    let pulse = pulseLog[minute, default: 0]

    if pulse == 0 {
        continue
    }

    if pulse > maxPulse {
        print("\(minute) мин: пульс \(pulse) - слишком высокий, стоп")
        break
    }

    print("\(minute) мин: пульс \(pulse)")
}

// После цикла выведи "Таймер выключен"
print("Таймер выключен")
```

## @rules
- must: /\bstride\s*\(/ :: Отметки времени идут с шагом `interval`, поэтому цикл нужно построить на `stride(from:through:by:)`.
- must: /\bcontinue\b/ :: Отметку без показаний пропускай командой `continue` — в этой задаче мы тренируем именно её.
- must: /\bbreak\b/ :: Когда пульс выше `maxPulse`, цикл нужно остановить командой `break`.

## @hint1
Вся задача — один цикл `for-in`, в теле которого по очереди разбираются три случая.

Сначала сам цикл. Отметки времени идут не подряд, а с шагом, поэтому вместо диапазона нужна функция `stride`. Начало — `interval` (первый сигнал звучит через один промежуток после старта), шаг — тоже `interval`. Конец — `totalMinutes`, и он должен включаться: если тренировка длится 20 минут, сигнал на 20-й минуте нужен. Вспомни, какое из двух слов включает конец.

В теле цикла первым делом получи пульс для текущей минуты из словаря `pulseLog`. Читай с запасным значением ноль и сохрани результат в константу.

Дальше три случая, и порядок важен. Первый: пульс равен нулю. Показывать нечего, переходим к следующей отметке — это `continue`. Второй: пульс больше `maxPulse`. Выводим строку с предупреждением и выходим из цикла — это `break`. Третий — всё в порядке: выводим обычную строку. Третий случай не нужно оборачивать в `else`: если сработал `continue` или `break`, до этой строки выполнение просто не дойдёт.

Последняя команда — `print` после закрывающей скобки цикла.

## @hint2
Каркас цикла выглядит так:

```swift
for minute in stride(from: interval, through: totalMinutes, by: interval) {
    let pulse = pulseLog[minute, default: 0]

    // здесь три случая
}
```

А так записывается «пропусти этот повтор»:

```swift
if pulse == 0 {
    continue
}
```

Проверка на опасный пульс устроена похоже, только внутри неё сначала `print`, а потом `break`.

## @hint4
Вот готовое решение:

{{solution}}

**Цикл.** `stride(from: interval, through: totalMinutes, by: interval)` для данных из редактора даёт 5, 10, 15, 20, 25, 30. Слово `through` включает конец, поэтому 30-я минута входит в список. С `to` последним сигналом была бы 25-я минута, и в тренировке без остановок терялась бы финальная отметка.

**Чтение пульса.** `pulseLog[minute, default: 0]` возвращает пульс, если запись за эту минуту есть, и 0, если её нет. Так случай «нет записи» превращается в обычное число, которое удобно проверять.

**`continue`.** На 15-й минуте записи нет, пульс равен 0. Команда `continue` прекращает текущий повтор, и цикл берёт следующую отметку — 20. Строки ниже для 15-й минуты не выполняются, поэтому на экране её нет.

**`break`.** На 25-й минуте пульс 176, это больше 170. Сначала выводится предупреждение, затем `break` завершает цикл. Отметка 30 уже не обрабатывается, хотя запись для неё есть. Выполнение переходит к строке после цикла, и печатается `Таймер выключен`.

**Почему нет `else`.** После `continue` и `break` код ниже в теле цикла на этом повторе не выполняется. Поэтому обычная строка может стоять в конце без всяких условий: до неё доходят только отметки с нормальным пульсом. Такой приём — сначала отсеять особые случаи, потом заняться главным — делает код плоским и легко читаемым.

**Почему сравнение строгое.** По условию таймер останавливается, когда пульс **выше** безопасного. Пульс ровно 170 при границе 170 — ещё норма.

**Типичные ошибки:**

- `to` вместо `through` — пропадает последняя отметка;
- `break` там, где нужен `continue` — таймер останавливается на первой же пропущенной записи;
- `break` стоит раньше `print` — предупреждение не успевает вывестись;
- `>=` вместо `>` — тренировка останавливается при пульсе ровно на границе.
