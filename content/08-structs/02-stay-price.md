## @description

### Контекст
На экране брони гость видит короткую сводку о жилье и сумму за выбранное число ночей. Сейчас каждый экран считает эту сумму сам: в карточке одна формула, в корзине другая, и в одной из них недавно забыли про плату за уборку.

Тимлид просит навести порядок: «Расчёт должен жить в одном месте — в самой модели. Научи `Apartment` считать стоимость проживания и описывать себя. Экран брони уже написан и вызывает эти методы, только самих методов пока нет».

### Новое в Swift
Структура может не только хранить данные, но и уметь что-то с ними делать. Функция, объявленная внутри структуры, называется **методом**.

```swift
struct Host {
    let name: String
    let responseMinutes: Int

    func greeting() -> String {
        "Здравствуйте! Меня зовут \(name)."
    }

    func repliesFaster(than minutes: Int) -> Bool {
        responseMinutes < minutes
    }
}
```

Метод пишется так же, как обычная функция: `func`, имя, параметры, тип результата. Отличий два.

**Первое: метод видит свойства своего экземпляра.** Внутри `greeting()` написано просто `name` — без параметра и без точки. Метод сам знает, у какого хозяина его вызвали, и берёт имя именно у него.

**Второе: метод вызывают через точку** — у конкретного экземпляра:

```swift
let host = Host(name: "Билол", responseMinutes: 15)
print(host.greeting())
print(host.repliesFaster(than: 30))
```

```text
Здравствуйте! Меня зовут Билол.
true
```

У другого хозяина тот же метод вернёт другой текст, потому что данные у него свои.

Методы одной структуры могут вызывать друг друга — тоже просто по имени:

```swift
    func badge() -> String {
        if repliesFaster(than: 60) {
            return "Отвечает быстро"
        }
        return "Отвечает в течение дня"
    }
```

> 💡 Раньше ты написала бы отдельную функцию `greeting(for: host)`. Метод удобнее: данные и действия над ними лежат рядом. Открыла структуру — и видно всё, что умеет хозяин.

### Задача
В редакторе есть структура `Apartment` со свойствами `title`, `city`, `pricePerNight` и `cleaningFee`. Последнее — плата за уборку, её берут один раз за всё проживание. Добавь в структуру три метода:

1. `totalPrice(nights:)` — принимает число ночей (`Int`) и возвращает `Int`: цена за ночь, умноженная на число ночей, плюс уборка.
2. `summary()` — без параметров, возвращает `String` вида `Студия у набережной, Казань: 3200 руб. за ночь`.
3. `stayDescription(nights:)` — принимает число ночей (`Int`) и возвращает `String` вида `Ночей: 3, к оплате: 10600 руб.`. Сумму не считай заново — вызови внутри метод `totalPrice(nights:)`.

Код экрана брони под структурой менять не нужно. Он уже вызывает новые методы, поэтому не соберётся, пока ты их не добавишь.

### Пример
```swift
let apartment = Apartment(title: "Студия у набережной", city: "Казань", pricePerNight: 3200, cleaningFee: 1000)
apartment.totalPrice(nights: 3)        // 10600
apartment.summary()                    // "Студия у набережной, Казань: 3200 руб. за ночь"
apartment.stayDescription(nights: 3)   // "Ночей: 3, к оплате: 10600 руб."
```

Экран брони должен вывести:

```text
Студия у набережной, Казань: 3200 руб. за ночь
Ночей: 3, к оплате: 10600 руб.
```

## @solution
```swift
struct Apartment {
    let title: String
    let city: String
    let pricePerNight: Int
    let cleaningFee: Int

    // Добавь сюда методы totalPrice(nights:), summary() и stayDescription(nights:)
    func totalPrice(nights: Int) -> Int {
        pricePerNight * nights + cleaningFee
    }

    func summary() -> String {
        "\(title), \(city): \(pricePerNight) руб. за ночь"
    }

    func stayDescription(nights: Int) -> String {
        "Ночей: \(nights), к оплате: \(totalPrice(nights: nights)) руб."
    }
}

// Экран брони. Этот код уже готов и ждёт твои методы — менять его не нужно
let apartment = Apartment(title: "Студия у набережной", city: "Казань", pricePerNight: 3200, cleaningFee: 1000)
print(apartment.summary())
print(apartment.stayDescription(nights: 3))
```

## @rules
- must: /(?<!func\s+)\btotalPrice\s*\(\s*nights\s*:/ :: Внутри `stayDescription(nights:)` не считай сумму заново — вызови метод `totalPrice(nights:)`.

## @hint1
Все три метода пишутся внутри фигурных скобок структуры — там, где стоит комментарий, после свойств. Каждый метод — это обычная функция со словом `func`.

Первый метод получает число ночей и возвращает целое число. В его теле одна формула. Цену за ночь и плату за уборку не нужно передавать параметрами: это свойства, и метод видит их просто по именам. Следи за тем, что уборка прибавляется один раз, а не умножается на ночи.

Второй метод ничего не получает и возвращает строку. Она собирается интерполяцией из трёх свойств: название, запятая, город, двоеточие, цена и слова «руб. за ночь».

Третий метод снова получает число ночей и возвращает строку. В ней две вставки: само число ночей и сумма к оплате. Сумму посчитает первый метод — вызови его по имени прямо внутри вставки и передай ему свой параметр.

## @hint2
Метод объявляется внутри структуры и обращается к свойствам по именам. А другой метод той же структуры вызывается просто по имени, без точки:

```swift
struct Host {
    let name: String
    let responseMinutes: Int

    func repliesFaster(than minutes: Int) -> Bool {
        responseMinutes < minutes
    }

    func badge() -> String {
        "\(name): быстрый ответ - \(repliesFaster(than: 60))"
    }
}
```

У тебя так же: `stayDescription(nights:)` вызывает `totalPrice(nights:)` внутри вставки `\( )`.

## @hint3
Первый метод готов. Во втором и третьем заполни пропуски:

```swift
    func totalPrice(nights: Int) -> Int {
        pricePerNight * nights + cleaningFee
    }

    func summary() -> String {
        "\(title), \(___): \(___) руб. за ночь"
    }

    func stayDescription(nights: Int) -> String {
        "Ночей: \(nights), к оплате: \(___) руб."
    }
```

В `summary()` не хватает двух свойств: города и цены за ночь. В `stayDescription(nights:)` на месте пропуска — вызов метода `totalPrice`, которому передаётся параметр `nights`.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Методы объявлены внутри `struct Apartment { ... }`, поэтому принадлежат квартире. Когда экран вызывает `apartment.summary()`, метод выполняется для экземпляра `apartment`: имена `title`, `city` и `pricePerNight` внутри метода означают свойства именно этой квартиры. Вызови тот же метод у дома в Выборге — подставятся его данные.

**Почему параметр только один.** В `totalPrice(nights:)` приходит лишь то, чего квартира не знает сама, — число ночей. Цена и уборка уже лежат в свойствах. В этом главное удобство методов: не нужно каждый раз передавать данные, которые и так есть у экземпляра.

**Почему `stayDescription` вызывает `totalPrice`.** Формула стоимости должна быть записана один раз. Если завтра к ней добавится, например, сбор за позднее заселение, ты поправишь один метод, и текст для гостя изменится сам. Две копии формулы рано или поздно разойдутся — с этого и началась задача.

**Про `return`.** В каждом методе одно выражение, поэтому слово `return` можно не писать — это тот же неявный возврат, что у обычных функций. С `return` тоже правильно.

**Типичные ошибки:**

- методы написаны после закрывающей скобки структуры — тогда это обычные функции, они не видят `pricePerNight`, и вызвать их через точку нельзя;
- `(pricePerNight + cleaningFee) * nights` — так уборка оплачивается за каждую ночь;
- в `totalPrice` добавлены параметры для цены и уборки — они не нужны, эти данные уже есть в свойствах;
- при вызове внутри вставки забыта метка: `totalPrice(nights)` вместо `totalPrice(nights: nights)`.
