## @description

### Контекст
Ты в команде фитнес-трекера «Пульс». Первая задача — экран круговой тренировки. В ней одно и то же упражнение повторяется несколько раундов, и перед стартом приложение показывает их список: так сразу видно, сколько работы впереди.

Тимлид пишет в трекере задач: «Выведи, пожалуйста, список раундов. Их количество приходит из настроек тренировки: у кого-то три, у кого-то восемь. Так что написать пять `print` подряд не получится».

### Новое в Swift
До сих пор каждая команда в твоём коде выполнялась один раз. Но в приложениях постоянно нужно повторять одно и то же действие: показать каждый трек плейлиста, каждый товар корзины, каждый раунд тренировки. Для этого есть **цикл** — конструкция, которая выполняет один и тот же код несколько раз подряд.

Самый частый цикл в Swift — `for-in`:

```swift
for day in 1...3 {
    print("День \(day)")
}
```

```text
День 1
День 2
День 3
```

Разберём запись по частям:

- `for` — слово, с которого начинается цикл;
- `day` — **переменная цикла**. Имя ты придумываешь сама. Объявлять её заранее через `let` или `var` не нужно: цикл создаёт её сам;
- `in 1...3` — откуда брать значения. `1...3` — это **диапазон**: все целые числа от 1 до 3 включительно. Ты уже встречала диапазоны в `switch`;
- в фигурных скобках — **тело цикла**: код, который повторяется.

Работает это так. Цикл берёт первое число диапазона, кладёт его в `day` и выполняет тело. Потом берёт следующее число и выполняет тело ещё раз. Когда числа закончились, цикл завершается, и программа идёт дальше — к коду после закрывающей скобки.

Границей диапазона может быть не только число, но и константа:

```swift
let lapCount = 4
for lap in 1...lapCount {
    print("Круг \(lap)")
}
print("Финиш")
```

Тело выполнится четыре раза, а `Финиш` напечатается один раз: эта команда стоит уже после цикла, за закрывающей скобкой.

> 💡 Код внутри фигурных скобок принято сдвигать вправо на четыре пробела. Так сразу видно, что повторяется, а что нет.

### Задача
В редакторе уже есть данные тренировки — `workoutName` и `rounds` — и вывод заголовка. Не переименовывай данные: проверка подставит другие значения.

1. С помощью цикла `for-in` выведи по одной строке на каждый раунд: слово `Раунд`, номер раунда, слово `из` и общее количество раундов. Номера идут от 1 до `rounds`.
2. После цикла один раз выведи строку `Тренировка завершена!`

### Пример
Для данных из редактора:

```text
Тренировка: Табата
Раунд 1 из 5
Раунд 2 из 5
Раунд 3 из 5
Раунд 4 из 5
Раунд 5 из 5
Тренировка завершена!
```

А если бы раундов было два, строк с раундами тоже было бы две: `Раунд 1 из 2` и `Раунд 2 из 2`.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let workoutName = "Табата"
let rounds = 5

// Заголовок тренировки
print("Тренировка: \(workoutName)")

// Выведи строку для каждого раунда: "Раунд 1 из 5", "Раунд 2 из 5" и так далее
for round in 1...rounds {
    print("Раунд \(round) из \(rounds)")
}

// После цикла выведи "Тренировка завершена!"
print("Тренировка завершена!")
```

## @rules
- must: /\bfor\s+\w+\s+in\b/ :: Строки с раундами нужно вывести циклом `for-in`, а не отдельными командами `print`: количество раундов бывает разным.

## @hint1
Посмотри на пример: строки с раундами отличаются только номером. Значит, это одна и та же команда `print`, которую нужно выполнить несколько раз, каждый раз с новым номером. Это и есть работа для цикла.

Цикл начинается словом `for`. После него идёт имя переменной цикла — в ней по очереди окажутся номера раундов. Дальше слово `in` и диапазон: от единицы до количества раундов. Количество не пиши цифрой: оно лежит в константе `rounds`, и проверка подставит туда другие числа.

В фигурных скобках — одна команда `print`. В её тексте две вставки: номер текущего раунда (переменная цикла) и общее количество (`rounds`).

Финальная строка про завершение тренировки нужна один раз. Поэтому её `print` стоит после закрывающей фигурной скобки цикла, а не внутри.

## @hint2
Так выглядит цикл, у которого граница диапазона взята из константы:

```swift
let lapCount = 4
for lap in 1...lapCount {
    print("Круг \(lap)")
}
```

В твоём цикле граница — `rounds`, а в тексте две вставки: переменная цикла и `rounds`.

## @hint3
Осталось заполнить два пропуска:

```swift
for round in 1...___ {
    print("Раунд \(___) из \(rounds)")
}

print("Тренировка завершена!")
```

В первом пропуске — константа с количеством раундов. Во втором — переменная цикла, в которой лежит номер текущего раунда.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Диапазон `1...rounds` — это числа от 1 до значения `rounds`. Для данных из редактора это 1, 2, 3, 4, 5. Цикл по очереди кладёт каждое число в переменную `round` и выполняет тело — команду `print`. На первом повторе `round` равна 1, и печатается `Раунд 1 из 5`. На втором — 2, и так до пяти. После пятого повтора числа в диапазоне заканчиваются, цикл завершается, и выполняется следующая команда — вывод строки `Тренировка завершена!`.

**Почему `rounds`, а не `5`.** Если написать `1...5`, программа будет верной только для одной тренировки. Настройки у пользователей разные, и проверка это учитывает: она запускает твой код с тремя, одним и восемью раундами. Значение, которое может измениться, всегда берут из константы или переменной.

**Почему последний `print` стоит после скобки.** Всё, что внутри фигурных скобок, повторяется на каждом раунде. Если перенести финальную строку внутрь, она напечатается пять раз — после каждого раунда.

**Типичные ошибки:**

- `for round in 1...5` — число вместо константы, на других тренировках результат неверный;
- `for round in 0...rounds` — появится лишний `Раунд 0`. Раунды люди считают с единицы;
- `1..rounds` с двумя точками — в диапазоне их три;
- пропущено слово `in` или фигурные скобки вокруг тела цикла;
- в тексте написано `\(rounds)` дважды вместо `\(round)` и `\(rounds)` — имена отличаются одной буквой, будь внимательна.
