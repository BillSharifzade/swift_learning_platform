## @description

### Контекст
Финальная задача первого спринта. Бариста просит экран со сводкой заказа: кто заказал, что, какого размера, сколько платить и с собой ли. А ещё на экране есть статус — он меняется, пока заказ готовится.

Тимлид говорит: «Ты уже умеешь всё, что для этого нужно. Собери сводку сама — от начала до конца».

### Что пригодится
В этой задаче нет ничего нового — только то, что ты уже делала:

- **Константы и переменные.** `let` — для того, что не меняется. `var` — для того, что меняется. Новое значение переменной присваивается без слова `var`: `status = "Готовится"`.
- **Интерполяция.** Значение вставляется в текст через `\( )`: `"Гость: \(customer)"`. Вставлять можно значения любых типов, в том числе `true` и `false`.
- **Порядок команд.** Каждый `print` выводит свою строку. Что раньше в коде — то раньше на экране.

Маленькая подсказка про скобки в тексте. Обычные круглые скобки внутри строки — просто символы. Вставка начинается только там, где перед скобкой стоит обратная черта:

```swift
let dish = "Сырники"
let weight = 180
print("\(dish) (\(weight) г)")
```

```text
Сырники (180 г)
```

### Задача
В редакторе уже есть данные заказа. Не переименовывай их — проверка подставит другие значения.

1. Объяви **переменную** `status` со значением `"Принят"`.
2. Выведи сводку из шести строк, как в примере. Все данные вставляй через интерполяцию:
   - заголовок `=== Заказ ===`;
   - `Гость:` и имя гостя;
   - `Напиток:`, название и размер в круглых скобках;
   - `К оплате:`, цена и `руб.`;
   - `С собой:` и значение `isTakeaway`;
   - `Статус:` и значение `status`.
3. Заказ начали готовить: измени `status` на `"Готовится"`.
4. Ещё раз выведи строку со статусом.

### Пример
Для данных из редактора:

```text
=== Заказ ===
Гость: Билол
Напиток: Раф лавандовый (M)
К оплате: 320 руб.
С собой: true
Статус: Принят
Статус: Готовится
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let customer = "Билол"
let drink = "Раф лавандовый"
let size = "M"
let price = 320
let isTakeaway = true

// 1. Объяви переменную status
var status = "Принят"

// 2. Выведи сводку заказа (шесть строк)
print("=== Заказ ===")
print("Гость: \(customer)")
print("Напиток: \(drink) (\(size))")
print("К оплате: \(price) руб.")
print("С собой: \(isTakeaway)")
print("Статус: \(status)")

// 3. Измени статус на "Готовится"
status = "Готовится"

// 4. Выведи строку со статусом ещё раз
print("Статус: \(status)")
```

## @rules
- must: /\bvar\s+status\b/ :: Статус меняется, поэтому `status` нужно объявить через `var`.
- must: /\\\(\s*status\s*\)/ :: Статус нужно вставлять в текст через интерполяцию: `"Статус: \(status)"`.

## @hint1
Иди по шагам из задания — они же отмечены комментариями в редакторе.

Шаг первый: статус будет меняться, значит, это переменная, а не константа. Начальное значение — текст «Принят» в кавычках.

Шаг второй: шесть команд `print`, по одной на строку сводки. Заголовок — обычный текст без вставок. В остальных пяти строках сначала идёт постоянная часть («Гость:», «Напиток:» и так далее), а за ней — вставка с именем нужной константы. В строке с напитком две вставки: название и размер, причём размер стоит в обычных круглых скобках.

Шаг третий: присвой переменной новое значение. Слово `var` здесь уже не нужно.

Шаг четвёртый: повтори команду вывода статуса — точно такую же, как в конце сводки. Теперь она выведет новое значение.

## @hint2
Самая хитрая строка — с напитком: в ней рядом обычные скобки и вставки. Вот похожий пример:

```swift
let dish = "Сырники"
let weight = 180
print("\(dish) (\(weight) г)")
```

Скобка с обратной чертой перед ней — вставка значения. Скобка без черты — обычный символ, который попадёт на экран.

## @hint3
Начало готово. Допиши строки про оплату и «с собой», а потом смену статуса:

```swift

print("Гость: \(customer)")
print("Напиток: \(drink) (\(size))")
print("К оплате: ___ руб.")
print("С собой: ___")
print("Статус: \(status)")

status = ___
print("Статус: \(status)")
```

В первых двух пропусках — вставки с константами `price` и `isTakeaway`. В третьем — новый статус, текстом в кавычках.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Пять констант наверху — данные заказа. `status` объявлена через `var`, потому что её значение изменится. Шесть команд `print` выводят сводку: в каждой строке постоянный текст склеивается со значениями через `\( )`. Затем строка `status = "Готовится"` кладёт в переменную новый текст, и последний `print` выводит уже его.

**Почему две одинаковые команды выводят разное.** `print("Статус: \(status)")` встречается дважды, буква в букву. Но интерполяция подставляет то значение, которое лежит в переменной **в момент выполнения** команды. Между двумя командами значение изменилось — изменился и результат. В этом и смысл переменных: код один, а данные живые.

**Почему `true` выводится словом.** `isTakeaway` имеет тип `Bool`. При вставке в строку Swift превращает его в текст `true` или `false`. В настоящем приложении вместо этого показали бы «Да» или «Нет» — как это сделать, ты узнаешь в модуле про условия.

**Типичные ошибки:**

- `let status` вместо `var` — тогда на шаге 3 Swift не даст изменить значение;
- `var status = "Готовится"` на шаге 3 — это попытка создать вторую переменную с тем же именем;
- перед обычной скобкой случайно поставлена черта или, наоборот, у вставки она забыта;
- данные написаны прямо в тексте (`"Гость: Билол"`) — на первой проверке это пройдёт, а на заказе гостя `coffee_lover` нет.
