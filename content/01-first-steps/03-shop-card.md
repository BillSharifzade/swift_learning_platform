## @description

### Контекст
В приложении появляется экран «О нас»: название кофейни, адрес и часы работы. Эти сведения показываются сразу в нескольких местах — в шапке, в чеке, в уведомлениях.

Тимлид предупреждает: «Не пиши название прямо в каждом `print`. Если владелец завтра переименует кофейню, нам придётся искать и править текст по всему проекту. Заведи для этих данных константы».

### Новое в Swift
Данные в программе хранят в именованных «коробочках». Если значение положили один раз и больше менять не собираются, коробочка называется **константой**. Она объявляется словом `let`:

```swift
let city = "Казань"
```

Читается так: «пусть `city` будет равно "Казань"». Слева от знака `=` — имя, справа — значение.

Теперь имя можно использовать вместо самого значения. Например, вывести:

```swift
print(city)
```

На экране появится `Казань`.

Обрати внимание на важную разницу:

```swift
print(city)     // выведет: Казань
print("city")   // выведет: city
```

**Без кавычек** — это имя: Swift заглянет в коробочку и достанет значение. **В кавычках** — это просто текст из четырёх букв.

**Как называть.** Имена пишут латиницей, без пробелов. Если слов несколько, каждое следующее начинают с большой буквы: `openingTime`, `phoneNumber`. Такой стиль называют camelCase — «верблюжий», из-за «горбов» в середине. Хорошее имя объясняет, что лежит внутри.

> 💡 Зачем это нужно? Значение записано в одном месте. Понадобится изменить — меняешь одну строку, и новое значение появляется всюду, где используется имя.

### Задача
1. Объяви константу `shopName` со значением `"Лавандовый раф"`.
2. Объяви константу `address` со значением `"ул. Садовая, 12"`.
3. Объяви константу `workingHours` со значением `"Ежедневно с 8:00 до 22:00"`.
4. Выведи все три значения — каждое своей командой `print`, в этом же порядке. В скобках у `print` должны стоять **имена констант**, а не текст в кавычках.

### Пример
```text
Лавандовый раф
ул. Садовая, 12
Ежедневно с 8:00 до 22:00
```

## @solution
```swift
// Данные для экрана «О нас»
// Объяви три константы: shopName, address, workingHours
let shopName = "Лавандовый раф"
let address = "ул. Садовая, 12"
let workingHours = "Ежедневно с 8:00 до 22:00"

// Выведи их по очереди
print(shopName)
print(address)
print(workingHours)
```

## @output
```
Лавандовый раф
ул. Садовая, 12
Ежедневно с 8:00 до 22:00
```

## @rules
- must: /\blet\s+shopName\b/ :: `shopName` должна быть константой — объяви её через `let`.
- must: /\blet\s+address\b/ :: `address` должна быть константой — объяви её через `let`.
- must: /\blet\s+workingHours\b/ :: `workingHours` должна быть константой — объяви её через `let`.
- must: /print\(\s*shopName\s*\)/ :: Выводи название через константу: `print(shopName)` — без кавычек.
- must: /print\(\s*address\s*\)/ :: Выводи адрес через константу: `print(address)` — без кавычек.
- must: /print\(\s*workingHours\s*\)/ :: Выводи часы работы через константу: `print(workingHours)` — без кавычек.

## @hint1
Задача состоит из двух частей: сначала положить данные в константы, потом вывести их.

Каждая константа объявляется на своей строке и строится по одной схеме: слово `let`, пробел, имя, знак равенства и значение — текст в двойных кавычках. Имена бери точно из задания: `shopName`, `address`, `workingHours`. Обрати внимание на большие буквы в середине имён — для Swift `shopname` и `shopName` это разные имена.

После этого напиши три команды `print`. В скобках у каждой — только имя константы, без кавычек. Тогда Swift выведет не само имя, а то, что в константе лежит.

## @hint2
Вот как объявить константу и вывести её значение — на примере города:

```swift
let city = "Казань"
print(city)
```

Тебе нужно сделать то же самое три раза: для названия, адреса и часов работы. Сначала все три объявления, потом три вывода.

## @hint3
Первая константа и первый вывод готовы. Допиши остальное по образцу:

```swift
let shopName = "Лавандовый раф"
let address = "___"
let ___ = "Ежедневно с 8:00 до 22:00"

print(shopName)
print(___)
print(___)
```

В пропусках — адрес из задания, имя третьей константы и имена двух констант, которые осталось вывести.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Первые три строки создают три константы. Слово `let` говорит Swift: «заведи коробочку с таким именем и положи в неё это значение — навсегда». Следующие три строки достают значения и выводят их. Когда Swift видит `print(shopName)`, он находит константу с именем `shopName`, берёт из неё текст `Лавандовый раф` и показывает его.

**Почему константы, а не текст прямо в `print`?** Сейчас разницы на экране нет. Но представь, что название кофейни встречается в приложении двадцать раз. С константой его достаточно исправить в одной строке. Без неё — в двадцати местах, и хоть в одном обязательно ошибёшься.

**Почему `let`?** Название и адрес кофейни не меняются, пока приложение работает. Объявив их константами, мы просим Swift следить за этим: если кто-то случайно попробует изменить `shopName`, код просто не соберётся. В Swift принято всё объявлять через `let`, пока не понадобилось обратное.

**Типичные ошибки:**

- `print("shopName")` — в кавычках это текст, и на экране окажется слово `shopName`, а не название;
- опечатка в имени: объявлена `adress`, а выводится `address` — Swift скажет, что не знает такого имени;
- константа используется раньше, чем объявлена: команды выполняются сверху вниз, поэтому объявление должно стоять выше вывода.
