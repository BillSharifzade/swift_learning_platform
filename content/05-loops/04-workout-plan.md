## @description

### Контекст
Экран «План тренировки» показывает нумерованный список упражнений с длительностью. Данные приходят двумя массивами: в `exercises` лежат названия, в `durations` — минуты. Порядок одинаковый: длительность стоит под тем же индексом, что и название.

Тимлид добавляет: «И ещё у нас появился усиленный режим. Когда он включён, каждое упражнение длится на несколько минут дольше. Сначала обнови длительности в массиве, потом выводи план».

### Новое в Swift
Цикл `for exercise in exercises` выдаёт сами элементы, но не говорит, какой это элемент по счёту. А номер часто нужен: чтобы пронумеровать список, чтобы изменить элемент или чтобы взять данные из соседнего массива. Для этого есть два инструмента.

**`enumerated()` — элемент вместе с индексом.** Этот метод превращает массив в набор пар «индекс, элемент». Пара — это кортеж, и его можно сразу разобрать на две части в круглых скобках:

```swift
let achievements = ["Первая тренировка", "Неделя без пропусков", "Марафон"]
for (index, title) in achievements.enumerated() {
    print("\(index + 1). \(title)")
}
```

```text
1. Первая тренировка
2. Неделя без пропусков
3. Марафон
```

Индексы в массиве начинаются с нуля, а люди считают с единицы. Поэтому на экран выводится `index + 1`.

**`indices` — все индексы массива.** Свойство `indices` даёт диапазон допустимых индексов: от нуля до последнего. Оно нужно, когда элементы требуется **изменить**:

```swift
var weights = [20, 35, 50]
for index in weights.indices {
    weights[index] += 5
}
print(weights)   // [25, 40, 55]
```

Почему нельзя проще — `for weight in weights { weight += 5 }`? Переменная цикла — это копия элемента, причём неизменяемая. Swift такой код не соберёт. Чтобы поменять сам массив, к элементу обращаются по индексу: `weights[index]`.

Индекс пригодится и тогда, когда данные лежат в двух массивах: по одному и тому же индексу можно взять элемент из каждого.

```swift
let days = ["Пн", "Ср", "Пт"]
let distances = [3, 5, 4]
for index in days.indices {
    print("\(days[index]): \(distances[index]) км")
}
```

> 💡 В чужом коде ты встретишь запись `0..<weights.count` — это диапазон от 0 до `count`, не включая сам `count`. `indices` означает то же самое, но короче. И для пустого массива он безопасен: индексов нет — цикл не выполнится ни разу.

### Задача
В редакторе есть массивы `exercises` и `durations` и константа `extraMinutes` — добавка усиленного режима. В массивах всегда одинаковое количество элементов. Не переименовывай входные данные: проверка подставит другие.

1. Циклом по `durations.indices` увеличь каждый элемент массива `durations` на `extraMinutes`.
2. После заголовка циклом по `exercises.enumerated()` выведи нумерованный план. Строка состоит из номера с точкой, названия, дефиса и новой длительности со словом `мин`. Нумерация начинается с 1.

### Пример
Для данных из редактора (к каждой длительности прибавлено 2 минуты):

```text
План тренировки:
1. Разминка - 7 мин
2. Приседания - 12 мин
3. Планка - 5 мин
4. Выпады - 10 мин
5. Растяжка - 8 мин
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let exercises = ["Разминка", "Приседания", "Планка", "Выпады", "Растяжка"]
var durations = [5, 10, 3, 8, 6]
let extraMinutes = 2

// 1. Усиленный режим: увеличь каждый элемент durations на extraMinutes
for index in durations.indices {
    durations[index] += extraMinutes
}

// 2. Выведи нумерованный план: "1. Разминка - 7 мин" и так далее
print("План тренировки:")
for (index, exercise) in exercises.enumerated() {
    print("\(index + 1). \(exercise) - \(durations[index]) мин")
}
```

## @rules
- must: /\.indices\b/ :: Длительности нужно изменить в цикле по `durations.indices` — так ты обращаешься к каждому элементу по индексу.
- must: /\.enumerated\s*\(\s*\)/ :: Нумерованный список выведи циклом по `exercises.enumerated()` — он даёт и индекс, и название.

## @hint1
В задаче два цикла, и каждый решает свою часть.

Первый цикл меняет массив `durations`. Обычный перебор элементов здесь не подойдёт: переменная цикла — только копия, и изменить через неё массив нельзя. Поэтому цикл идёт не по элементам, а по индексам — по `durations.indices`. В теле цикла ты обращаешься к элементу по индексу в квадратных скобках и прибавляешь к нему `extraMinutes` оператором `+=`.

Второй цикл выводит план и стоит после заголовка. Здесь нужны сразу и номер, и название, поэтому цикл идёт по `exercises.enumerated()`. Переменных цикла две, они записываются в круглых скобках через запятую: сначала индекс, потом элемент.

В строке вывода три вставки. Номер — это индекс плюс один, потому что индексы начинаются с нуля. Название — вторая переменная цикла. Длительность берётся из массива `durations` по тому же индексу.

## @hint2
Так элементы массива меняются по индексу:

```swift
var weights = [20, 35, 50]
for index in weights.indices {
    weights[index] += 5
}
```

А так в цикле получают индекс и элемент одновременно:

```swift
for (index, title) in achievements.enumerated() {
    print("\(index + 1). \(title)")
}
```

В твоей строке вывода будет ещё одна вставка — длительность из `durations` по тому же индексу.

## @hint3
Заполни три пропуска:

```swift
for index in durations.___ {
    durations[index] += extraMinutes
}

print("План тренировки:")
for (index, exercise) in exercises.___ {
    print("\(index + 1). \(exercise) - \(durations[___]) мин")
}
```

В первом пропуске — свойство со всеми индексами массива. Во втором — метод, который выдаёт пары «индекс, элемент» (не забудь круглые скобки вызова). В третьем — индекс текущего упражнения.

## @hint4
Вот готовое решение:

{{solution}}

**Первый цикл: изменение массива.** `durations.indices` — это индексы 0, 1, 2, 3, 4. На каждом повторе в `index` лежит очередной индекс, а строка `durations[index] += extraMinutes` увеличивает элемент, который стоит на этом месте. После цикла массив превращается из `[5, 10, 3, 8, 6]` в `[7, 12, 5, 10, 8]`.

**Почему не `for duration in durations`.** Переменная цикла получает копию элемента и ведёт себя как константа. Строку `duration += extraMinutes` Swift не соберёт. А если бы и собрал, изменилась бы копия, а не массив. Правило простое: хочешь читать элементы — перебирай их самих, хочешь менять — перебирай индексы.

**Второй цикл: нумерованный вывод.** `exercises.enumerated()` выдаёт пары: `(0, "Разминка")`, `(1, "Приседания")` и так далее. Запись `(index, exercise)` сразу раскладывает пару по двум переменным. Название у нас уже есть, а длительность берём из второго массива по тому же индексу: `durations[index]`. Это безопасно, потому что в массивах одинаковое количество элементов.

**Почему `index + 1`.** Первый элемент массива стоит под индексом 0, но план с пункта «0. Разминка» выглядел бы странно. Единица прибавляется только при выводе, а для обращения к `durations` используется сам `index`.

**Типичные ошибки:**

- забыта единица — нумерация начинается с нуля;
- `durations[index + 1]` — сдвинутый индекс возьмёт чужую длительность, а на последнем повторе выйдет за границы массива, и программа упадёт;
- пропущены круглые скобки вокруг `(index, exercise)` или после `enumerated`;
- в строке вывода написано `durations[index] + extraMinutes`, а сам массив не изменён — экран выглядит верно, но в данных остались старые значения.
