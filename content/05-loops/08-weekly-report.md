## @description

### Контекст
Финальная задача модуля — отчёт по активности. «Пульс» хранит активные минуты за каждый день, и дни сгруппированы по неделям: получается массив, каждый элемент которого — тоже массив.

Продакт-менеджер описывает экран: «Строка на каждую неделю — сколько всего активных минут. А внизу главная цифра для мотивации: лучшая серия, то есть сколько дней подряд выполнялась дневная цель. Серия на границе недель не обрывается: воскресенье и следующий понедельник — соседние дни».

### Новое в Swift
Почти всё здесь ты уже умеешь. Новое одно: цикл можно поставить **внутрь другого цикла**. Это нужно как раз для данных «массив массивов»: внешний цикл берёт очередной внутренний массив, а внутренний цикл проходит по его элементам.

```swift
let waterByDay = [[250, 300, 200], [500, 250, 250], [330, 330]]

for (index, glasses) in waterByDay.enumerated() {
    var dayTotal = 0
    for glass in glasses {
        dayTotal += glass
    }
    print("День \(index + 1): \(dayTotal) мл")
}
```

```text
День 1: 750 мл
День 2: 1000 мл
День 3: 660 мл
```

На каждом повторе внешнего цикла внутренний выполняется **целиком**, от первого стакана до последнего. Потом внешний цикл переходит к следующему дню, и внутренний запускается заново.

**Где объявить переменную — решает, сколько она живёт.** `dayTotal` объявлена внутри внешнего цикла, поэтому для каждого дня создаётся заново, с нулём. Если бы она стояла до обоих циклов, сумма копилась бы за все дни сразу. Отсюда правило:

- значение «за одну неделю» объявляй внутри внешнего цикла;
- значение «за всё время» объявляй до циклов.

**Как посчитать серию подряд.** Нужны два счётчика. `currentStreak` — длина серии, которая идёт прямо сейчас. `bestStreak` — самая длинная серия из всех, что уже встретились. День удачный — текущая серия растёт на 1, и если она обогнала лучшую, лучшая обновляется. День неудачный — текущая серия обнуляется, а лучшая остаётся как была.

```text
Цель выполнена:  да  да  нет  да  да  да
currentStreak:    1   2    0   1   2   3
bestStreak:       1   2    2   2   2   3
```

Вторая половина этого приёма тебе знакома: так же ты искала рекорд недели по шагам.

### Задача
В редакторе есть входные данные, вывод заголовка и две переменные для серии: `currentStreak` и `bestStreak`. Не переименовывай входные данные: проверка подставит другие.

1. Внешним циклом пройди по массиву `weeks`. Тебе понадобится номер недели, начиная с 1.
2. Для каждой недели объяви переменную `weekMinutes` с нулём и внутренним циклом прибавь к ней минуты каждого дня.
3. В том же внутреннем цикле обновляй серию. Если минут за день **не меньше** `dailyGoal`: увеличь `currentStreak` на 1 и, если она стала больше `bestStreak`, запиши её в `bestStreak`. Иначе обнули `currentStreak`.
4. После внутреннего цикла выведи строку недели: номер и сумма минут, как в примере.
5. После внешнего цикла выведи строку с лучшей серией.

### Пример

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let dailyGoal = 30
let weeks = [[45, 30, 10, 60, 35, 20, 50], [40, 30, 35, 0, 25, 30, 45], [30, 15, 60, 20, 40, 35, 10]]

print("Отчёт по активности (цель: \(dailyGoal) мин в день)")

// Серия дней подряд с выполненной целью: текущая и лучшая.
// Объявлены до циклов, потому что серия не обрывается на границе недель
var currentStreak = 0
var bestStreak = 0

// 1. Внешний цикл: по неделям (нужен номер недели).
// 2. Внутри него: переменная weekMinutes и внутренний цикл по дням.
//    Для каждого дня прибавь минуты к weekMinutes и обнови серию.
// 3. После внутреннего цикла выведи строку недели: "Неделя 1: 250 мин"
for (index, week) in weeks.enumerated() {
    var weekMinutes = 0

    for minutes in week {
        weekMinutes += minutes

        if minutes >= dailyGoal {
            currentStreak += 1
            if currentStreak > bestStreak {
                bestStreak = currentStreak
            }
        } else {
            currentStreak = 0
        }
    }

    print("Неделя \(index + 1): \(weekMinutes) мин")
}

// 4. После всех недель выведи "Лучшая серия: 4 дн. подряд"
print("Лучшая серия: \(bestStreak) дн. подряд")
```

## @hint1
Задача собирается из приёмов, которые ты уже отработала. Новое только одно: один цикл стоит внутри другого.

Внешний цикл идёт по `weeks`. В строке отчёта нужен номер недели, поэтому удобно идти по `weeks.enumerated()`: тогда у тебя будут и индекс, и сама неделя. Неделя — это массив чисел, минуты по дням.

Первой строкой в теле внешнего цикла объяви `weekMinutes` с нулём. Она стоит именно здесь, внутри, чтобы для каждой недели сумма начиналась заново.

Дальше внутренний цикл — по дням текущей недели. В его теле два дела. Первое: прибавить минуты дня к `weekMinutes`. Второе: обновить серию. Если минут не меньше `dailyGoal`, текущая серия растёт на единицу, и её нужно сравнить с лучшей: если текущая больше, лучшая получает её значение. Если цель не выполнена, текущая серия обнуляется.

Когда внутренний цикл закончился, неделя посчитана: выводи её строку. Этот `print` стоит внутри внешнего цикла, но после закрывающей скобки внутреннего.

Строка с лучшей серией выводится один раз, после обоих циклов. Переменные `currentStreak` и `bestStreak` внутри циклов не обнуляй и заново не объявляй: серия общая для всех недель.

## @hint2
Самая тонкая часть — обновление серии для одного дня. Она выглядит так:

```swift
if minutes >= dailyGoal {
    currentStreak += 1
    if currentStreak > bestStreak {
        bestStreak = currentStreak
    }
} else {
    currentStreak = 0
}
```

Здесь `minutes` — переменная внутреннего цикла. Этот фрагмент стоит во внутреннем цикле рядом со строкой, которая прибавляет минуты к `weekMinutes`.

## @hint4
Вот готовое решение:

{{solution}}

**Два цикла.** Внешний цикл берёт недели по одной. `enumerated()` даёт пару: индекс и массив дней, который мы назвали `week`. Внутренний цикл проходит по дням этой недели. Пока он не закончится, внешний цикл ждёт. Поэтому `print` со строкой недели стоит после внутреннего цикла: к этому моменту `weekMinutes` уже посчитана полностью.

**Почему `weekMinutes` внутри, а серия снаружи.** `weekMinutes` — значение одной недели. Она объявлена в теле внешнего цикла и на каждой неделе создаётся заново с нулём. Перенеси её выше — и вторая неделя показала бы 455 минут вместо 205, потому что сумма продолжила бы расти. С серией наоборот: она должна переживать смену недель. Последний день первой недели (50 минут) и три первых дня второй (40, 30, 35) дают серию из четырёх дней. Если обнулять `currentStreak` в начале каждой недели, лучшей серией оказались бы 3 дня, и это неправда.

**Как работает серия.** В удачный день `currentStreak` растёт. Сразу после этого она сравнивается с `bestStreak`: это поиск максимума, только вместо элементов массива — длина текущей серии. В неудачный день `currentStreak` становится нулём, но `bestStreak` помнит рекорд.

**Почему рекорд обновляется сразу, а не когда серия прервалась.** Серия может идти до самого последнего дня и не прерваться вовсе. Если обновлять `bestStreak` только в ветке `else`, такая серия останется незамеченной.

**Типичные ошибки:**

- `weekMinutes` объявлена до внешнего цикла — суммы недель складываются друг с другом;
- `currentStreak = 0` в начале каждой недели — серия рвётся на границе недель;
- `bestStreak` обновляется только при обрыве серии — теряется серия в конце данных;
- `>` вместо `>=` — день, когда минут ровно столько, сколько в цели, не засчитывается;
- `print` недели попал внутрь внутреннего цикла — строка печатается после каждого дня.
