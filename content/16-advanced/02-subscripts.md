## @description

### Контекст
В «Чернилах» заметки лежат в папках. Экран списка спрашивает у папки: «Какая заметка в строке 3?» Раньше он писал `folder.notes[3]`. В отчёте о падениях нашлась ошибка `Index out of range`: пока список был открыт, синхронизация удалила заметку на другом устройстве, и строки 3 больше не было.

Тимлид предлагает: «Закроем массив и дадим папке квадратные скобки, как у массива, только безопасные. Нет заметки — пусть возвращается `nil`, а не падает приложение. И заодно сделаем доступ по заголовку, как у словаря: виджету "Покупки" нужно читать и менять текст одной строкой».

### Новое в Swift
Квадратные скобки ты уже писала много раз: `tracks[0]`, `prices["кофе"]`. Такое обращение называется **сабскрипт** (`subscript`). Его можно объявить и в своём типе. Сабскрипт похож на метод, но у него нет имени, а вызывается он скобками `[ ]`:

```swift
struct Bookmarks {
    private var pages = ["Главная", "Новости", "Погода"]

    subscript(index: Int) -> String {
        return pages[index]
    }
}

let bookmarks = Bookmarks()
print(bookmarks[1])   // Новости
```

После слова `subscript` в круглых скобках — параметры, после стрелки — тип результата. Такой сабскрипт только читает.

**Чтение и запись.** Чтобы в сабскрипт можно было ещё и присваивать, внутри пишут два блока: `get` (что отдать при чтении) и `set` (что сделать при записи). Присвоенное значение приходит в `set` под именем `newValue`:

```swift
struct Settings {
    private var values: [String: String] = [:]

    subscript(key: String) -> String? {
        get {
            return values[key]
        }
        set {
            values[key] = newValue
        }
    }
}

var settings = Settings()
settings["theme"] = "dark"           // работает set, newValue равно "dark"
print(settings["theme"] ?? "нет")    // работает get: dark
settings["theme"] = nil              // newValue равно nil
```

У `newValue` тот же тип, что у результата сабскрипта. Здесь это `String?`, поэтому присвоить можно и `nil`. В структуре `set` меняет её содержимое, поэтому экземпляр должен быть объявлен через `var`.

**Метки.** У функций параметр по умолчанию требует метку. У сабскрипта — наоборот: `subscript(key: String)` вызывается без метки, просто `settings["theme"]`. Если метка нужна, её пишут отдельным словом перед именем параметра, как у функций:

```swift
subscript(named name: String) -> String? { ... }   // settings[named: "theme"]
```

В одном типе может быть несколько сабскриптов с разными параметрами или метками. Swift выбирает нужный по тому, что стоит в скобках, — как при перегрузке функций.

> 💡 Проверить, есть ли в массиве такой номер, помогает `indices` — диапазон всех его номеров: `pages.indices.contains(5)`. А номер первого подходящего элемента вернёт `firstIndex(where:)` — родственник знакомых тебе `firstIndex(of:)` и `first(where:)`. Он даёт `Int?`.

### Задача
В редакторе есть структуры `Note` и `Folder`. Массив `notes` в папке закрыт. Добавь в `Folder` два сабскрипта:

1. **Заметка по номеру.** Параметр `index` типа `Int`, вызов без метки: `folder[0]`. Результат — `Note?`. Только чтение. Если такой номер в массиве есть — вернуть заметку, иначе (номер отрицательный или слишком большой) — `nil`.
2. **Текст по заголовку.** Параметр типа `String` с меткой `title`: `folder[title: "Покупки"]`. Результат — `String?`.
   - `get`: текст первой заметки с точно таким заголовком или `nil`, если её нет.
   - `set`, когда заметка с этим заголовком есть: новый текст заменяет старый. Если присвоили `nil` — заметка удаляется из папки.
   - `set`, когда такой заметки нет: если присвоили текст — в конец папки добавляется новая заметка с этим заголовком и текстом. Если присвоили `nil` — ничего не происходит.

Массив `notes` оставь закрытым. Код экрана внизу уже готов: когда сабскрипты появятся, он соберётся.

### Пример
```swift
var folder = Folder(name: "Дом", notes: [Note(title: "Врач", text: "четверг, 10:30")])
folder[0]?.title                   // Optional("Врач")
folder[1]                          // nil
folder[title: "Врач"]              // Optional("четверг, 10:30")
folder[title: "Врач"] = "пятница, 9:00"
folder[title: "Паспорт"] = "забрать в МФЦ"
folder.count                       // 2
folder[title: "Врач"] = nil
folder.count                       // 1
```

## @solution
```swift
// Заметка
struct Note {
    var title: String
    var text: String
}

// Папка с заметками. Массив закрыт: экран работает с папкой через квадратные скобки
struct Folder {
    let name: String
    private var notes: [Note]

    init(name: String, notes: [Note] = []) {
        self.name = name
        self.notes = notes
    }

    var count: Int {
        notes.count
    }

    // 1. Заметка по номеру: folder[0]. Нет такого номера — nil
    subscript(index: Int) -> Note? {
        guard notes.indices.contains(index) else {
            return nil
        }
        return notes[index]
    }

    // 2. Текст по заголовку: folder[title: "Покупки"] — чтение и запись
    subscript(title title: String) -> String? {
        get {
            return notes.first(where: { $0.title == title })?.text
        }
        set {
            if let index = notes.firstIndex(where: { $0.title == title }) {
                if let newText = newValue {
                    notes[index].text = newText
                } else {
                    notes.remove(at: index)
                }
            } else if let newText = newValue {
                notes.append(Note(title: title, text: newText))
            }
        }
    }
}

// Экран списка. Этот код уже готов — менять его не нужно
var home = Folder(name: "Дом", notes: [
    Note(title: "Покупки", text: "молоко, хлеб"),
    Note(title: "Врач", text: "четверг, 10:30"),
])
print(home[0]?.title ?? "пусто")
print(home[5]?.title ?? "пусто")

home[title: "Покупки"] = "молоко, хлеб, яблоки"
home[title: "Пароль от Wi-Fi"] = "lavanda-2024"
home[title: "Врач"] = nil
print(home[title: "Покупки"] ?? "нет заметки")
print("Заметок в папке: \(home.count)")
```

## @rules
- must: /\bsubscript\s*\(\s*(?:_\s+)?index\s*:\s*Int\s*\)/ :: Объяви сабскрипт по номеру: `subscript(index: Int) -> Note?`.
- must: /\bsubscript\s*\(\s*title\s+\w+\s*:\s*String\s*\)/ :: Сабскрипту по заголовку нужна метка: `subscript(title title: String) -> String?`.
- mustnot: /^(?!.*\bprivate\b).*\bvar\s+notes\s*:/m :: Массив `notes` должен остаться закрытым: `private var notes`.

## @hint1
Сабскрипты пишутся внутри `Folder`, на месте двух комментариев с номерами.

Первый сабскрипт только читает, поэтому блоки `get` и `set` ему не нужны. Сначала спроси у массива `notes`, есть ли среди его номеров переданный (для этого есть `indices` и `contains`). Если нет — верни `nil`. Если есть — верни заметку по этому номеру. Удобно начать с `guard`.

Второй сабскрипт получает заголовок. Так как его вызывают с меткой `title`, в объявлении слово `title` нужно написать два раза: первое — метка, второе — имя параметра. Внутри два блока.

В `get` найди первую заметку с таким заголовком (`first(where:)`) и возьми у неё текст. Заметки может не быть, поэтому к тексту обращайся через `?.`.

В `set` сначала узнай номер заметки с этим заголовком через `firstIndex(where:)`. Дальше четыре случая: заметка есть и пришёл текст — замени текст; заметка есть и пришёл `nil` — удали её; заметки нет и пришёл текст — добавь новую; заметки нет и пришёл `nil` — ничего не делай. Присвоенное значение лежит в `newValue`.

## @hint2
Объявления обоих сабскриптов:

```swift
subscript(index: Int) -> Note? {
    // только чтение: guard и return
}

subscript(title title: String) -> String? {
    get {
        // текст первой заметки с этим заголовком
    }
    set {
        // newValue — присвоенный текст или nil
    }
}
```

Поиск номера заметки по заголовку:

```swift
if let index = notes.firstIndex(where: { $0.title == title }) {
    // заметка есть, её номер — index
}
```

## @hint4
Вот готовое решение:

{{solution}}

**Сабскрипт по номеру.** Он только читает, поэтому записан коротко, без `get`. `notes.indices` — это диапазон всех допустимых номеров, для трёх заметок это `0..<3`. Если переданного номера там нет, `guard` сразу возвращает `nil`. Обычный массив в такой ситуации уронил бы приложение, а папка честно отвечает «такой заметки нет». Экран списка обработает это через `?.` или `??`, как в коде внизу.

**Почему `title title`.** Параметры сабскрипта по умолчанию вызываются без метки. Первое слово `title` — метка для вызова `folder[title: "..."]`, второе — имя параметра внутри. Без метки вызов выглядел бы как `folder["Покупки"]`, и было бы непонятно, что строка — это заголовок.

**Как устроен `set`.** Сначала ищем номер заметки. Дальше два вложенных `if let`. Внешний отвечает на вопрос «заметка есть?», внутренний — «присвоили текст или `nil`?». Так получаются все четыре случая, а четвёртый (заметки нет, присвоен `nil`) просто ничего не делает. Это то же поведение, что у словаря: `dict[key] = nil` удаляет ключ.

**Почему массив остался закрытым.** Теперь у экрана нет способа обратиться к `notes[5]` напрямую. Единственный путь — через сабскрипты, а они проверяют границы. Ошибка из отчёта о падениях стала невозможной.

**Типичные ошибки:**

- `subscript(title: String)` без второго слова — тогда вызов `folder[title: "..."]` не соберётся, Swift ждёт `folder["..."]`;
- проверка `index < notes.count` без `index >= 0` — отрицательный номер уронит программу;
- в `set` сразу `notes.append(...)` без поиска — в папке появятся две заметки с одним заголовком.
