## @description

### Контекст
Новый проект — «Копилка», приложение для учёта личных финансов. Оно показывает, сколько денег пришло, сколько ушло и на что.

В приложении есть отчёты: за неделю и за месяц. Каждый начинается с одинаковой шапки из двух строк. Раньше эти строки просто копировали в каждый отчёт. Недавно дизайнер попросила поменять текст шапки — и его пришлось искать и править во всех местах сразу. Одно место пропустили, и в релиз ушла старая шапка.

Тимлид просит: «Вынеси шапку в функцию. Пусть текст живёт в одном месте, а отчёты просто её вызывают».

### Новое в Swift
До сих пор твой код выполнялся сверху вниз, строка за строкой. Если одно и то же действие было нужно в трёх местах, его приходилось писать три раза.

**Функция** — это кусочек кода, у которого есть имя. Ты один раз описываешь, что нужно сделать, а потом запускаешь этот кусочек по имени — столько раз, сколько понадобится.

Создание функции называется **объявлением**. Оно начинается со слова `func`:

```swift
func printFooter() {
    print("Спасибо, что считаешь деньги вместе с нами")
    print("Версия приложения: 2.4")
}
```

Разберём по частям:

- `func` — «дальше идёт функция»;
- `printFooter` — имя, его придумываешь ты. Имена функций пишут так же, как имена переменных: с маленькой буквы, без пробелов, каждое следующее слово — с большой. Обычно имя начинается с глагола, ведь функция что-то *делает*;
- `()` — круглые скобки. Пока они пустые; что в них бывает, ты узнаешь в следующей задаче;
- `{ ... }` — **тело функции**: команды, которые она выполняет. Их принято сдвигать вправо на четыре пробела.

Важный момент: объявление само **ничего не выполняет**. Swift только запоминает: «есть функция `printFooter`, вот её команды». Чтобы команды сработали, функцию нужно **вызвать** — написать её имя и круглые скобки:

```swift
print("Баланс: 5000 руб.")
printFooter()
print("Баланс: 7200 руб.")
printFooter()
```

```text
Баланс: 5000 руб.
Спасибо, что считаешь деньги вместе с нами
Версия приложения: 2.4
Баланс: 7200 руб.
Спасибо, что считаешь деньги вместе с нами
Версия приложения: 2.4
```

Каждый вызов выполняет всё тело функции целиком, а потом программа продолжается со следующей строки.

> ⚠️ Скобки при вызове обязательны. `printFooter` без скобок — это просто имя, функция не запустится.

> 💡 Ты уже давно вызываешь функции: `print(...)` — тоже функция, только написали её создатели Swift. Теперь ты пишешь свои.

### Задача
1. Объяви функцию `printReportHeader` без параметров (скобки пустые). В её теле — две команды `print`, которые выводят шапку:
   - `=== Копилка ===`
   - `Учёт личных финансов`
2. Вызови функцию перед строкой отчёта за неделю.
3. Вызови её ещё раз перед строкой отчёта за месяц.

Текст шапки должен быть написан в коде только один раз — внутри функции. Готовые строки `print` с расходами не меняй.

### Пример
```text
=== Копилка ===
Учёт личных финансов
Расходы за неделю: 8400 руб.
=== Копилка ===
Учёт личных финансов
Расходы за месяц: 31200 руб.
```

## @solution
```swift
// 1. Объяви функцию printReportHeader(): она печатает две строки шапки
func printReportHeader() {
    print("=== Копилка ===")
    print("Учёт личных финансов")
}

// Отчёт за неделю
// 2. Вызови функцию здесь, перед строкой отчёта
printReportHeader()
print("Расходы за неделю: 8400 руб.")

// Отчёт за месяц
// 3. И ещё раз здесь
printReportHeader()
print("Расходы за месяц: 31200 руб.")
```

## @rules
- must: /\bfunc\s+printReportHeader\s*\(\s*\)\s*\{/ :: Объяви функцию `printReportHeader`: слово `func`, имя, пустые круглые скобки и тело в фигурных скобках.
- must: /(\bprintReportHeader\s*\(\s*\)[\s\S]*){3}/ :: Функцию нужно вызвать два раза: перед отчётом за неделю и перед отчётом за месяц.
- mustnot: /(=== Копилка ===[\s\S]*){2}/ :: Текст шапки должен встречаться в коде один раз — внутри функции. Там, где шапка нужна снова, вызови `printReportHeader()`.

## @hint1
В этой задаче две части: сначала описать функцию, потом дважды ею воспользоваться.

Объявление пишется в самом верху, под первым комментарием. Оно начинается со слова `func`, за ним идёт имя `printReportHeader`, пустые круглые скобки и фигурные скобки. Между фигурными скобками — тело функции: две команды `print`, по одной на каждую строку шапки. Точно такие команды ты писала много раз, только теперь они стоят внутри функции.

Если остановиться на этом и нажать «Проверить», шапка на экране не появится: объявление только рассказывает Swift, что функция существует. Чтобы она сработала, её нужно вызвать — написать имя и пустые круглые скобки отдельной строкой.

Вызовов нужно два: один над строкой про неделю, второй над строкой про месяц. Места для них отмечены комментариями.

## @hint2
Объявление функции и её вызов выглядят так:

```swift
func printFooter() {
    print("Спасибо, что считаешь деньги вместе с нами")
    print("Версия приложения: 2.4")
}

printFooter()
```

Первые четыре строки — объявление: Swift запомнил функцию, но ничего не напечатал. Последняя строка — вызов: вот теперь обе команды из тела выполнятся.

Твоя функция устроена так же, только имя и тексты другие, а вызовов два.

## @hint3
Объявление почти готово, первый вызов стоит на месте. Допиши вторую строку шапки и второй вызов:

```swift
func printReportHeader() {
    print("=== Копилка ===")
    print(___)
}

printReportHeader()
print("Расходы за неделю: 8400 руб.")

___
print("Расходы за месяц: 31200 руб.")
```

В первом пропуске — вторая строка шапки, текстом в кавычках. Во втором — вызов функции: её имя и пустые круглые скобки.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Первые строки — объявление. Слово `func` создаёт функцию с именем `printReportHeader`, а в фигурных скобках лежит её тело — две команды `print`. В этот момент на экране ничего не появляется: Swift только запоминает, что делать, когда функцию позовут.

Дальше программа идёт сверху вниз, как всегда. Она встречает строку `printReportHeader()` — это вызов. Swift «заходит» в функцию, выполняет обе команды из тела и возвращается обратно. Следующая строка печатает расходы за неделю. Затем второй вызов — и шапка печатается ещё раз, теми же двумя командами.

**Почему так лучше, чем скопировать строки.** Текст шапки теперь записан в одном месте. Если дизайнер снова попросит его поменять, ты исправишь одну строку внутри функции — и шапка изменится во всех отчётах сразу. Забыть какое-то место уже невозможно. К тому же код отчётов стал читаться как план: «шапка, потом расходы».

**Типичные ошибки:**

- функция объявлена, но ни разу не вызвана — шапка не печатается совсем;
- вызов без скобок: `printReportHeader` вместо `printReportHeader()` — Swift видит имя, но ничего не запускает;
- слово `func` перед вызовом: `func printReportHeader()` второй раз — это попытка объявить ещё одну функцию с тем же именем, а не вызвать существующую;
- команды `print` написаны после закрывающей фигурной скобки — тогда они уже не часть функции и выполнятся только один раз.
