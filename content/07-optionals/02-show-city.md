## @description

### Контекст
Тестировщица прислала снимок экрана профиля. Под именем вместо города написано `Город: Optional("Казань")`. А у тех, кто город не указал, — `Город: nil`. Такое увидят все пользователи, если не исправить до релиза.

Эту строку писал коллега, и он торопился. Тимлид просит: «Почини строку с городом. И заодно сделай такую же для подписчиков. В настройках приватности их число можно скрыть — тогда с сервера вместо числа приходит `nil`».

### Новое в Swift
Ты уже знаешь, что опционал — это коробочка: в ней либо значение, либо пусто. Если вставить коробочку в текст, напечатается сама коробочка:

```swift
let nickname: String? = "sunny_bilol"
print("Ник: \(nickname)")
```

```text
Ник: Optional("sunny_bilol")
```

При вставке в строку Swift только предупреждает. А в большинстве других мест он строг и такой код вообще не соберёт:

```swift
let loud = nickname.uppercased()   // ошибка: сначала загляни в коробочку
let text: String = nickname        // ошибка: String? — это не String
```

Это защита. Компилятор не даёт забыть про случай «значения нет». Пока ты не решишь, что делать с пустой коробочкой, программа не запустится — и не сломается на глазах у пользователя.

Достать значение из коробочки — значит **развернуть опционал**. Самый надёжный способ — `if let`:

```swift
if let name = nickname {
    print("Ник: \(name)")
} else {
    print("Ник не задан")
}
```

Читается так: «если в `nickname` есть значение — положи его в новую константу `name` и выполни блок». Внутри фигурных скобок `name` — обычный `String`, без всякой коробочки. Если же в `nickname` лежит `nil`, выполнится блок `else`. Там константы `name` нет: доставать было нечего.

**Короткая запись.** Обычно новой константе дают то же имя, что и у опционала. Тогда можно не повторяться:

```swift
if let nickname {
    print("Ник: \(nickname)")   // здесь nickname — уже обычный String
} else {
    print("Ник не задан")
}
```

`if let` работает с опционалом любого типа. Например, с числом:

```swift
let unread: Int? = 0

if let unread {
    print("Новых сообщений: \(unread)")
} else {
    print("Сообщения не загружены")
}
```

```text
Новых сообщений: 0
```

> ⚠️ `0` и `nil` — разные вещи. Ноль — это значение: коробочка не пуста, в ней лежит число 0. А `nil` означает «мы не знаем, сколько».

### Задача
1. Нажми «Проверить», ничего не меняя. Посмотри на вывод программы — именно это увидела тестировщица.
2. Исправь функцию `cityLine(_:)`. Если город есть, она возвращает строку вида `Город: Казань`. Если передан `nil` — строку `Город не указан`.
3. Допиши функцию `followersLine(_:)`. У неё один параметр типа `Int?` без метки. Если число есть, она возвращает строку вида `Подписчики: 128`. Если передан `nil` — строку `Подписчики скрыты`. Сейчас в ней стоит заглушка `return ""` — замени её своим кодом.
4. В обеих функциях разворачивай опционал через `if let`.

### Пример
```swift
cityLine("Казань")      // "Город: Казань"
cityLine(nil)           // "Город не указан"
followersLine(128)      // "Подписчики: 128"
followersLine(0)        // "Подписчики: 0"
followersLine(nil)      // "Подписчики скрыты"
```

После исправления программа напечатает:

```text
Город: Казань
Город не указан
Подписчики: 128
Подписчики скрыты
```

```swift
// Строка с городом под именем в профиле.
// Сейчас на экране получается Optional("Казань") — исправь это через if let
func cityLine(_ city: String?) -> String {
    return "Город: \(city)"
}

// Строка с числом подписчиков. Если пользователь скрыл число, приходит nil
func followersLine(_ followers: Int?) -> String {
    // Замени заглушку: "Подписчики: 128" или "Подписчики скрыты"
    return ""
}

// Так строки выглядят на экране профиля
print(cityLine("Казань"))
print(cityLine(nil))
print(followersLine(128))
print(followersLine(nil))
```

## @solution
```swift
// Строка с городом под именем в профиле.
func cityLine(_ city: String?) -> String {
    if let city {
        return "Город: \(city)"
    } else {
        return "Город не указан"
    }
}

// Строка с числом подписчиков. Если пользователь скрыл число, приходит nil
func followersLine(_ followers: Int?) -> String {
    if let followers {
        return "Подписчики: \(followers)"
    } else {
        return "Подписчики скрыты"
    }
}

// Так строки выглядят на экране профиля
print(cityLine("Казань"))
print(cityLine(nil))
print(followersLine(128))
print(followersLine(nil))
```

## @rules
- must: /\bif\s+let\b[\s\S]*\bif\s+let\b/ :: Разверни опционал через `if let` в обеих функциях — в коде должно быть два `if let`.

## @hint1
Начни с `cityLine`. Сейчас в строку вставляется параметр `city` как есть, а он опционал — коробочка. Поэтому в тексте и появляется слово `Optional`.

Сначала нужно заглянуть в коробочку. Для этого есть `if let`: после этих слов пишется имя опционала, а дальше в фигурных скобках — что делать, если значение нашлось. Внутри этого блока `city` становится обычной строкой, и её можно спокойно вставлять в текст. Там же стоит `return` с готовой строкой.

Для случая, когда города нет, нужна ветка `else`. В ней — `return` с текстом «Город не указан». Вставлять туда нечего: значения нет.

Функция `followersLine` устроена точно так же. Отличие одно: в коробочке лежит число, а не строка. Заглушку `return ""` удали — вместо неё будет `if let` с двумя ветками.

## @hint2
Так `if let` выглядит внутри функции — на примере ника:

```swift
func nicknameLine(_ nickname: String?) -> String {
    if let nickname {
        return "Ник: \(nickname)"
    } else {
        return "Ник не задан"
    }
}
```

В первой ветке `nickname` — уже обычная строка. Во второй значения нет, поэтому возвращается готовый текст. Обе твои функции строятся по этому образцу.

## @hint3
Первая функция почти готова, вторую допиши по её образцу:

```swift
func cityLine(_ city: String?) -> String {
    if let ___ {
        return "Город: \(city)"
    } else {
        return ___
    }
}

func followersLine(_ followers: Int?) -> String {
    if let followers {
        return ___
    } else {
        return "Подписчики скрыты"
    }
}
```

В первом пропуске — имя опционала, который нужно развернуть. Во втором — текст для случая, когда города нет. В третьем — строка со вставкой числа подписчиков.

## @hint4
Вот готовое решение:

{{solution}}

**Что было не так.** В заготовке стояло `return "Город: \(city)"`, а `city` имеет тип `String?`. В текст попадала коробочка целиком: `Optional("Казань")`, если город есть, и `nil`, если его нет. Программа при этом собиралась — при вставке в строку Swift только предупреждает. Но пользователю такой текст показывать нельзя.

**Как работает решение.** `if let city` проверяет, есть ли в коробочке значение. Если есть — оно попадает в константу `city` обычного типа `String`, и в первой ветке мы вставляем в текст уже её. Если в коробочке `nil` — выполняется `else`, и функция возвращает готовую фразу. Оба случая обработаны явно, поэтому ни `Optional`, ни `nil` на экране больше не появятся.

**Почему `if let`, а не сравнение с `nil`.** Можно проверить `city != nil`, но внутри такого `if` переменная `city` всё равно останется коробочкой, и слово `Optional` никуда не денется. `if let` делает два дела сразу: проверяет и достаёт значение.

**Почему ноль подписчиков не «скрыт».** `followersLine(0)` возвращает `Подписчики: 0`. В коробочке лежит число 0 — это настоящее значение, и `if let` его достаёт. В ветку `else` попадает только `nil`.

**Типичные ошибки:**

- `if let city` написан, но ветки `else` нет — тогда для `nil` функция ничего не возвращает, и Swift не соберёт код;
- `return` с текстом «Город не указан» стоит внутри первой ветки, а не в `else`;
- в `followersLine` проверка `followers == 0` вместо работы с `nil` — ноль подписчиков превращается в «скрыто»;
- в тексте потерян пробел после двоеточия — проверка сравнивает строки символ в символ.
