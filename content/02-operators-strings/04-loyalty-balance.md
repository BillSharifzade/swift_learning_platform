## @description

### Контекст
В «Гардеробе» есть бонусная программа. За каждую покупку начисляются баллы, ими можно оплатить часть следующего заказа, а в день рождения магазин делает подарок — умножает все накопленные баллы.

На экране «Мои бонусы» покупательница видит историю: сколько баллов было и сколько становилось после каждого события. Тимлид просит тебя написать расчёт этой истории.

В кофейне ты уже меняла бонусный счёт, но каждый раз клала в переменную готовое число. В жизни новое значение почти всегда зависит от старого: было 300, начислили ещё 450.

### Новое в Swift
Изменить переменную «относительно самой себя» можно уже знакомыми средствами:

```swift
var stock = 40          // платьев на складе
stock = stock - 3       // три платья купили
print(stock)            // 37
```

Строка `stock = stock - 3` читается так: «возьми текущее значение `stock`, вычти три и положи результат обратно в `stock`».

Такое действие нужно постоянно, поэтому для него есть короткая запись — **составное присваивание**. Оператор и знак `=` пишутся слитно. Тот же пример теперь выглядит так:

```swift
var stock = 40
stock -= 3              // то же, что stock = stock - 3
print(stock)            // 37
```

Так работают все арифметические операторы:

| Короткая запись | Полная запись | Смысл |
|---|---|---|
| `stock += 20` | `stock = stock + 20` | увеличить на 20 |
| `stock -= 3` | `stock = stock - 3` | уменьшить на 3 |
| `stock *= 2` | `stock = stock * 2` | увеличить в 2 раза |

Справа может стоять не только число, но и имя константы или переменной:

```swift
let newBatch = 20       // привезли новую партию
stock += newBatch
print(stock)            // 57

var deliveryCost = 300
let expressRate = 2     // срочная доставка вдвое дороже
deliveryCost *= expressRate
print(deliveryCost)     // 600
```

Два правила:

- Слева должна быть **переменная** (`var`). Константу изменить нельзя — ни обычным присваиванием, ни составным.
- Между оператором и знаком `=` нет пробела: `+=`, а не `+ =`.

> 💡 Короткая запись — не просто экономия символов. В ней имя переменной написано один раз, значит, меньше шансов ошибиться и случайно изменить не ту переменную.

### Задача
В редакторе есть данные: `startBalance` — сколько баллов было на счёте, `purchaseBonus` — сколько начислили за покупку, `spentOnOrder` — сколько списали в оплату заказа, `birthdayMultiplier` — во сколько раз магазин умножает баллы в день рождения. Не переименовывай их — проверка подставит другие значения.

Переменная `balance` и первая строка истории уже написаны. Допиши три события. После каждого выведи баланс.

1. Покупка: увеличь `balance` на `purchaseBonus` оператором `+=`. Выведи строку `После покупки:` и баланс.
2. Оплата баллами: уменьши `balance` на `spentOnOrder` оператором `-=`. Выведи строку `После оплаты:` и баланс.
3. День рождения: умножь `balance` на `birthdayMultiplier` оператором `*=`. Выведи строку `После дня рождения:` и баланс.

### Пример
Для данных из редактора:

```text
На счёте: 300
После покупки: 750
После оплаты: 550
После дня рождения: 1100
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let startBalance = 300
let purchaseBonus = 450
let spentOnOrder = 200
let birthdayMultiplier = 2

// Баланс меняется, поэтому это переменная
var balance = startBalance
print("На счёте: \(balance)")

// 1. Покупка: начисли баллы и выведи баланс
balance += purchaseBonus
print("После покупки: \(balance)")

// 2. Оплата баллами: спиши баллы и выведи баланс

// 3. День рождения: умножь баллы и выведи баланс
balance *= birthdayMultiplier
print("После дня рождения: \(balance)")
```

## @rules
- must: /\bbalance\s*\+=/ :: В этой задаче мы тренируем короткую запись. Начисли баллы оператором `+=`: слева `balance`, справа — сколько прибавить.
- must: /\bbalance\s*-=/ :: В этой задаче мы тренируем короткую запись. Спиши баллы оператором `-=`: слева `balance`, справа — сколько вычесть.
- must: /\bbalance\s*\*=/ :: В этой задаче мы тренируем короткую запись. Умножь баллы оператором `*=`: слева `balance`, справа — множитель.

## @hint1
В редакторе уже есть образец: переменная `balance` создана, и первая строка истории выведена. Каждое из трёх событий — это две строки кода: сначала изменить `balance`, потом вывести.

Для изменения используй составное присваивание. Слева пишется имя переменной, потом оператор со знаком равенства слитно, потом — на сколько изменить. При покупке баллы прибавляются: нужен плюс со знаком равенства и `purchaseBonus`. При оплате вычитаются: минус со знаком равенства и `spentOnOrder`. В день рождения умножаются: звёздочка со знаком равенства и `birthdayMultiplier`.

Слово `var` повторять не нужно — переменная уже существует.

Вывод после каждого события устроен как первая строка истории, меняется только текст перед двоеточием. Вставка везде одна и та же — `balance`: к моменту каждого `print` в переменной лежит уже новое значение.

Числа 450, 200 и 2 прямо в коде не пиши — используй имена констант. Проверка подставит другие данные.

## @hint2
Составное присваивание выглядит так:

```swift
var stock = 40
let newBatch = 20

stock += newBatch     // теперь 60
stock -= 3            // теперь 57
```

У тебя вместо `stock` — `balance`, а справа от операторов — константы из входных данных.

## @hint3
Первое событие готово. Допиши два других по образцу:

```swift
balance += purchaseBonus
print("После покупки: \(balance)")

balance ___ spentOnOrder
print("После оплаты: \(balance)")

balance ___ birthdayMultiplier
print("После дня рождения: \(___)")
```

В первом пропуске — оператор, который уменьшает переменную. Во втором — оператор, который умножает её. В третьем — имя переменной с балансом.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Сначала в `balance` лежит `300`. Строка `balance += purchaseBonus` берёт это значение, прибавляет `450` и кладёт результат обратно — в переменной теперь `750`. Затем `balance -= spentOnOrder` вычитает `200`, остаётся `550`. Наконец `balance *= birthdayMultiplier` умножает на `2`, получается `1100`. Каждый `print` стоит сразу после изменения и поэтому показывает свежее значение.

**Почему во всех `print` одна и та же вставка.** `\(balance)` подставляет то, что лежит в переменной в момент выполнения команды. Переменная одна, а значение в ней меняется от события к событию. Так и устроена история операций в настоящем приложении.

**Почему `+=`, а не `balance = balance + purchaseBonus`.** Обе записи дают одинаковый результат. Но в короткой имя переменной написано один раз. В длинной легко ошибиться: например, написать `balance = bonus + purchaseBonus` и не заметить. Опытные разработчики почти всегда пишут коротко.

**Почему порядок важен.** Если сначала умножить, а потом начислить и списать, итог будет другим: `300 * 2 + 450 - 200` — это `850`, а не `1100`. Программа выполняет строки сверху вниз, и события должны идти в том порядке, в каком они произошли.

**Типичные ошибки:**

- пробел внутри оператора: `balance + = purchaseBonus` — оператор пишется слитно;
- знаки в обратном порядке: `balance =+ purchaseBonus` — оператора `=+` в Swift нет, программа не соберётся;
- `var balance += ...` — слово `var` нужно только при создании переменной;
- `print` стоит перед изменением — тогда выведется старое значение.
