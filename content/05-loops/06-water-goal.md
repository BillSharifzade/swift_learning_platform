## @description

### Контекст
Экран «Вода» помогает выпивать дневную норму. Продакт-менеджер просит две вещи. Первая — план: сколько ещё стаканов нужно выпить и сколько воды будет набираться после каждого. Вторая — расписание напоминаний до конца дня.

Про напоминания есть уточнение: «Первое показываем сразу, как только пользователь их включил. Всегда, даже поздно вечером, — чтобы он увидел, что всё заработало. Следующие идут через равные промежутки, пока не наступит время сна».

### Новое в Swift
Цикл `for-in` удобен, когда заранее известно, по чему идти: по диапазону или по массиву. Но иногда известно только, **когда пора остановиться**. Сколько стаканов до нормы? Зависит от того, сколько уже выпито. Для таких случаев есть цикл `while` — «пока».

```swift
var battery = 25
var minutes = 0
while battery < 100 {
    battery += 25
    minutes += 10
}
print("Браслет заряжен за \(minutes) мин")
```

`while` проверяет условие **перед** каждым повтором. Если оно истинно — выполняет тело и проверяет снова. Если ложно — цикл заканчивается. Здесь заряд меняется так: 50, 75, 100. После третьего повтора условие `100 < 100` ложно, и в `minutes` остаётся 30.

Если условие ложно с самого начала, тело не выполнится ни разу. При `battery = 100` заряжать нечего, и `minutes` останется нулём.

> ⚠️ **Бесконечный цикл.** В теле `while` обязательно должно меняться то, что проверяется в условии. Если забыть строку `battery += 25`, заряд навсегда останется 25, условие всегда будет истинным, и цикл не остановится никогда. На сайте такая программа через несколько секунд будет остановлена, а ты увидишь сообщение, что она не уложилась во время и что причина, скорее всего, в бесконечном цикле. Это частая и нестрашная ошибка: найди цикл и проверь, что его условие когда-нибудь станет ложным.

**`repeat-while`** — тот же цикл, но проверка стоит **после** тела. Поэтому тело всегда выполняется хотя бы один раз:

```swift
var signal = 40
var attempt = 0
repeat {
    attempt += 1
    signal += 30
    print("Попытка \(attempt): сигнал \(signal)%")
} while signal < 90
```

Сначала выполняется тело, и только потом Swift смотрит на условие. Здесь будет две попытки: сигнал станет 70, потом 100. Но даже если бы сигнал сразу был 95, одна попытка всё равно бы прошла. С обычным `while` в этом случае не было бы ни одной.

Как выбрать цикл:

- знаешь, по чему идти, — `for-in`;
- знаешь только условие остановки — `while`;
- то же самое, но первый повтор нужен в любом случае — `repeat-while`.

### Задача
В редакторе есть входные данные и три переменные: `total` (сколько выпито, в миллилитрах), `glasses` (счётчик стаканов) и `hour` (час напоминания). Не переименовывай входные данные: проверка подставит другие.

**Часть 1 — цикл `while`.**

1. Пока `total` меньше `dailyGoal`: прибавь к `total` объём стакана `glassSize`, увеличь `glasses` на 1 и выведи строку с номером стакана и новым значением `total`, как в примере.
2. После цикла выведи `Стаканов до нормы:` и значение `glasses`. Если норма уже выполнена, строк про стаканы не будет, а в итоге окажется 0.

**Часть 2 — цикл `repeat-while`.**

3. Выведи напоминание для часа `hour` и прибавь к `hour` промежуток `intervalHours`. Повторяй, пока `hour` меньше `bedtimeHour`. Первое напоминание выводится всегда.

Для данных из редактора:

```text
Стакан 2: всего 1400 мл
Стакан 3: всего 1650 мл
```

```text
Напоминание в 23:00
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let dailyGoal = 2000
let glassSize = 250
let consumed = 900
let currentHour = 14
let bedtimeHour = 22
let intervalHours = 3

print("Норма: \(dailyGoal) мл, выпито: \(consumed) мл")

// Часть 1. План по стаканам
var total = consumed
var glasses = 0

// Пока total меньше нормы: добавь стакан и выведи строку "Стакан 1: всего 1150 мл"
while total < dailyGoal {
    total += glassSize
    glasses += 1
    print("Стакан \(glasses): всего \(total) мл")
}

// Выведи "Стаканов до нормы: 5"
print("Стаканов до нормы: \(glasses)")

// Часть 2. Напоминания
var hour = currentHour

// Выведи "Напоминание в 14:00" и сдвинь hour на intervalHours.
// Повторяй, пока hour меньше bedtimeHour. Первое напоминание нужно всегда
repeat {
    print("Напоминание в \(hour):00")
    hour += intervalHours
} while hour < bedtimeHour
```

## @rules
- must: /\brepeat\b/ :: Напоминания выводи циклом `repeat-while`: первое напоминание должно появиться всегда, а обычный `while` при ложном условии не выполнится ни разу.
- must: /^[ \t]*while\b/m :: План по стаканам считай циклом `while`: если норма уже выполнена, тело цикла не должно выполниться ни разу.

## @hint1
В задаче два цикла, и разница между ними в одном: нужен ли первый повтор в любом случае.

Часть со стаканами. Если норма уже выполнена, добавлять ничего не надо — ни одного повтора. Значит, проверка должна стоять до тела: это цикл `while`. Его условие сравнивает `total` с `dailyGoal`. В теле три действия, и порядок важен. Сначала увеличь `total` на объём стакана, затем увеличь счётчик `glasses`, и только потом выводи строку: в ней должны быть уже новые значения. После закрывающей скобки цикла выведи итог со счётчиком.

Часть с напоминаниями. Первое напоминание нужно всегда, даже если час уже больше времени сна. Значит, сначала тело, потом проверка: это `repeat-while`. В теле два действия: вывести строку с текущим `hour` и прибавить к `hour` промежуток `intervalHours`. Условие после слова `while` сравнивает `hour` с `bedtimeHour`.

В обоих циклах проверь себя: есть ли в теле строка, которая меняет переменную из условия? Без неё цикл не остановится.

## @hint2
Так выглядят оба цикла на других данных. Сначала проверка, потом тело:

```swift
while battery < 100 {
    battery += 25
    minutes += 10
}
```

Сначала тело, потом проверка:

```swift
repeat {
    attempt += 1
    signal += 30
} while signal < 90
```

В твоей задаче в теле каждого цикла есть ещё команда `print`.

## @hint3
Заполни четыре пропуска:

```swift
while total < ___ {
    total += glassSize
    glasses += ___
    print("Стакан \(glasses): всего \(total) мл")
}

print("Стаканов до нормы: \(glasses)")

var hour = currentHour

repeat {
    print("Напоминание в \(hour):00")
    hour += ___
} while hour < ___
```

В первом пропуске — дневная норма. Во втором — на сколько растёт счётчик за один стакан. В третьем — промежуток между напоминаниями. В четвёртом — час, после которого напоминания не нужны.

## @hint4
Вот готовое решение:

{{solution}}

**Цикл `while`.** Перед каждым повтором Swift проверяет условие `total < dailyGoal`. Для данных из редактора: 900 меньше 2000 — тело выполняется, `total` становится 1150, `glasses` — 1, печатается первая строка. Так продолжается, пока после пятого стакана `total` не станет 2150. Проверка `2150 < 2000` ложна, цикл заканчивается. Если бы выпито было 2100 с самого начала, условие оказалось бы ложным сразу, и тело не выполнилось бы ни разу. Это ровно то, что нужно: стаканов до нормы 0.

**Почему `print` стоит в конце тела.** В строке должны быть номер стакана и объём уже с этим стаканом. Поэтому сначала меняются обе переменные, а потом выводится текст.

**Цикл `repeat-while`.** Тело выполняется до проверки. Напоминание для текущего часа выводится в любом случае, затем час сдвигается, и только тогда проверяется условие `hour < bedtimeHour`. При данных из редактора: 14, 17, 20, а 23 уже не меньше 22 — стоп. Если включить напоминания в 23 часа, одно напоминание всё равно появится — так просил продакт-менеджер. С обычным `while` в этом случае не вывелось бы ничего.

**Почему циклы не бесконечные.** В первом цикле на каждом повторе растёт `total`, во втором — `hour`. Обе переменные участвуют в условиях и рано или поздно их нарушат. Если убрать строку `total += glassSize`, условие останется истинным навсегда, и программу остановит только ограничение по времени.

**Типичные ошибки:**

- забыта строка, которая меняет `total` или `hour`, — цикл бесконечный;
- `<=` вместо `<` — появится лишний стакан, когда норма набрана ровно, и лишнее напоминание ровно в час сна;
- `print` стоит в начале тела `while` — в строках окажутся старые значения;
- у `repeat` условие написано перед фигурными скобками — оно должно стоять после закрывающей скобки, со словом `while`.
