## @description

### Контекст
Твоя первая задача в «Волне» — шапка экрана плейлиста. Дизайнер нарисовала её так: сверху метки плейлиста, ниже — сколько в нём треков, с какого трека начнётся воспроизведение и каким закончится.

Тимлид пишет: «Список треков приходит с сервера, пример я положил в `tracks`. Меток на сервере пока нет — заведи их прямо в коде. И учти: плейлисты бывают разной длины».

До сих пор в одной константе у тебя лежало одно значение. В плейлисте значений много, и для этого нужен новый инструмент.

### Новое в Swift
**Массив** — это список значений одного типа, которые стоят по порядку. Он записывается в квадратных скобках, значения разделяются запятыми:

```swift
let cities = ["Казань", "Сочи", "Тула"]
let prices = [320, 270, 290]
```

Значения внутри массива называют **элементами**. У массива есть свой тип: `[String]` — «массив строк», `[Int]` — «массив целых чисел». Его можно указать явно, как и любой другой тип: `let cities: [String] = ["Казань", "Сочи", "Тула"]`.

**Сколько элементов.** Это знакомое тебе по строкам свойство `count`:

```swift
print(cities.count)   // 3
```

**Элемент по номеру.** Номер элемента называется **индексом**. Индекс пишут в квадратных скобках сразу после имени массива:

```swift
print(cities[0])   // Казань
print(cities[1])   // Сочи
```

Самое важное: счёт идёт **с нуля**. Первый элемент имеет индекс `0`, второй — `1`, третий — `2`.

**Последний элемент.** Раз счёт начинается с нуля, индекс последнего элемента всегда на единицу меньше количества. В массиве из трёх городов это `2`, то есть `3 - 1`. Чтобы код работал для списка любой длины, это записывают формулой:

```swift
print(cities[cities.count - 1])   // Тула
```

> ⚠️ Элемента с индексом `cities.count` не существует. Если написать `cities[3]`, программа запустится, но на этой строке аварийно остановится с сообщением `Index out of range` — «индекс за пределами массива». Это самая частая ошибка при работе с массивами.

**Массив целиком.** Его можно вывести одной командой — или вставить в текст через `\( )`:

```swift
print("Города: \(cities)")   // Города: ["Казань", "Сочи", "Тула"]
```

Такой вид со скобками и кавычками удобен разработчику: сразу видно, что лежит внутри.

### Задача
В редакторе уже есть массив `tracks` — треки плейлиста. Не переименовывай его: проверка подставит другие плейлисты, в том числе другой длины.

1. Объяви константу `tags` — массив из трёх строк: `"утро"`, `"спокойное"`, `"инди"`. Именно в таком порядке.
2. Выведи слово `Метки:` и массив `tags` целиком — через интерполяцию.
3. Выведи `Треков:` и количество треков в `tracks`.
4. Выведи `Первый:` и первый трек плейлиста.
5. Выведи `Последний:` и последний трек плейлиста. Код должен работать для плейлиста любой длины.

### Пример
Для данных из редактора:

```text
Метки: ["утро", "спокойное", "инди"]
Треков: 4
Первый: Рассвет над рекой
Последний: Тёплый плед
```

А если в плейлисте всего один трек `Июльский дождь`, он и первый, и последний:

```text
Метки: ["утро", "спокойное", "инди"]
Треков: 1
Первый: Июльский дождь
Последний: Июльский дождь
```

```swift
// Входные данные (их подменяет проверка — не переименовывай)
let tracks = ["Рассвет над рекой", "Кофе и дождь", "Северное сияние", "Тёплый плед"]
```

## @hint1
Иди по шагам из комментариев в редакторе — на каждый шаг нужна одна строка кода.

Шаг первый: массив создаётся так же, как любая константа, только справа от знака равенства стоят квадратные скобки, а в них три строки через запятую. Посмотри, как записан `tracks` в первой строке редактора, — `tags` устроен точно так же, только значения другие.

Шаги со второго по пятый — это четыре команды `print`, и в каждой постоянный текст склеен с данными через интерполяцию. Метки вставляются целиком: во вставке просто имя массива. Количество треков — это свойство `count` у `tracks`. Первый трек — элемент с индексом ноль, ведь счёт идёт с нуля.

Над последним шагом подумай отдельно. Написать номер последнего элемента цифрой нельзя: в другом плейлисте треков будет больше или меньше. Но индекс последнего элемента всегда связан с количеством элементов — он на единицу меньше. Значит, внутри квадратных скобок может стоять не число, а небольшое вычисление.

## @hint2
Массив — это значения в квадратных скобках через запятую. Количество элементов даёт `count`, а отдельный элемент достают по индексу, считая с нуля:

```swift
let cities = ["Казань", "Сочи", "Тула"]

print("Городов: \(cities.count)")
print("Первый: \(cities[0])")
print("Последний: \(cities[cities.count - 1])")
```

В твоей задаче всё то же самое, только массив называется `tracks`. И не забудь сначала создать свой массив `tags`.

## @hint3
Метки и первые строки готовы. Допиши два индекса:

```swift
let tags = ["утро", "спокойное", "инди"]

print("Метки: \(tags)")
print("Треков: \(tracks.count)")
print("Первый: \(tracks[___])")
print("Последний: \(tracks[___])")
```

В первом пропуске — индекс первого элемента (помни, с какого числа начинается счёт). Во втором — не число, а формула: количество треков минус один.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `let tags = ["утро", "спокойное", "инди"]` создаёт массив из трёх строк. Swift сам понимает, что его тип — `[String]`, потому что внутри лежат строки. `tracks.count` возвращает количество элементов, `tracks[0]` — первый элемент. Вставка `\(tags)` превращает весь массив в текст со скобками и кавычками.

**Почему последний трек — это `tracks[tracks.count - 1]`.** В плейлисте из четырёх треков индексы такие: 0, 1, 2, 3. Последний индекс — `3`, а это `4 - 1`. В плейлисте из одного трека единственный индекс — `0`, то есть `1 - 1`. Формула «количество минус один» верна всегда. Сначала Swift вычисляет то, что в квадратных скобках, получает число и только потом достаёт элемент с этим номером.

**Почему нельзя написать `tracks[3]`.** Для плейлиста из редактора это сработает. Но проверка запускает твой код и с другими плейлистами. В плейлисте из шести треков `tracks[3]` — это четвёртый трек, а не последний. А в плейлисте из одного трека элемента с индексом `3` нет вообще, и программа аварийно остановится.

**Типичные ошибки:**

- `tracks[1]` для первого трека — счёт начинается с нуля, под индексом `1` лежит второй;
- `tracks[tracks.count]` для последнего — такого элемента не существует, программа остановится с `Index out of range`;
- круглые скобки вместо квадратных: `("утро", "спокойное", "инди")` — это уже не массив;
- забыта запятая между элементами или кавычки вокруг метки.
