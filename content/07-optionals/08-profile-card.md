## @description

### Контекст
Финальная задача модуля. Всё, что ты делала по отдельности — строка с городом, ник, возраст из текста, главное фото, — собирается в одну карточку профиля. Её показывают в ленте, в поиске и в списке подписчиков.

Сервер присылает профиль «сырым»: это словарь `[String: String]`, в котором все значения — текст, и любого ключа может не оказаться. Отдельно приходит массив с именами файлов фотографий — возможно, пустой.

Тимлид ставит задачу: «Напиши функцию, которая превращает сырые данные в готовые строки карточки. Экран не должен ничего знать про `nil` — он просто показывает строки. Исключение одно: профиль без имени показывать нельзя вообще, и функция должна честно об этом сообщить».

### Что пригодится
Нового в этой задаче нет. Вот все инструменты модуля — выбирай подходящий для каждого поля:

- **`guard let`** — когда без значения продолжать нет смысла. Условия можно перечислить через запятую: `guard let code = data["code"], !code.isEmpty else { return nil }`.
- **`if let`** — когда значение есть не всегда и с ним нужно сделать что-то дополнительное. Два шага подряд тоже пишутся через запятую: `if let text = data["size"], let size = Int(text) { ... }`.
- **`??`** — когда на случай `nil` есть запасное значение.
- **`?.`** — когда нужно вызвать метод у значения, которого может не быть. Часто в паре с `??`.
- **Источники опционалов:** словарь по ключу без `default:`, `Int("...")`, свойство `first` у массива.
- **Функция может вернуть опционал.** Тип результата `[String]?` означает «массив строк или ничего». Вернуть можно и массив, и `nil`.

Строки удобно собирать в массив-переменную, а необязательные добавлять через `append`:

```swift
var lines = ["Пробежка в парке", "Начало: 8:00"]

let place: String? = "У главного входа"
if let place {
    lines.append("Место: \(place)")
}
```

И одно напоминание: принудительная развёртка `!` в этой задаче запрещена. После прошлой задачи ты знаешь почему.

### Задача
Допиши функцию `profileCard(from:photos:)`. Она принимает словарь `[String: String]` и массив `[String]`, а возвращает `[String]?` — строки карточки по порядку.

1. **Имя** лежит по ключу `"name"`. Если ключа нет или имя — пустая строка, функция возвращает `nil`.
2. **Первая строка** — имя. Если по ключу `"age"` лежит целое число, после имени идут запятая, пробел и возраст: `Билол, 28`. Если ключа нет или там не число — только имя.
3. **Вторая строка** — `Ник: ` и ник из ключа `"nickname"`, переведённый в маленькие буквы. Если ключа нет — `Ник: не задан`.
4. **Третья строка** — `Город: ` и значение ключа `"city"`. Если ключа нет — `Город: не указан`.
5. **Четвёртая строка** — `Фото: ` и первый элемент массива `photos`. Если массив пуст — `Фото: нет`.
6. **Пятая строка** — `О себе: ` и значение ключа `"bio"`. Она добавляется, только если ключ есть. Если его нет, в карточке четыре строки.

Код под функцией уже готов: он показывает карточку так, как это делает экран. Менять его не нужно.

### Пример
Для данных из редактора программа напечатает:

```text
Билол, 28
Ник: sunny_bilol
Город: Казань
Фото: bilol-1.jpg
О себе: Люблю горы и кофе
```

Другие вызовы:

```swift
profileCard(from: ["name": "Ночная сова"], photos: [])
// ["Ночная сова", "Ник: не задан", "Город: не указан", "Фото: нет"]

profileCard(from: ["nickname": "ghost"], photos: ["ghost.jpg"])
// nil — у профиля нет имени
```

## @solution
```swift
// Пример ответа сервера: все значения — текст, любого ключа может не быть
let serverProfile = [
    "name": "Билол",
    "age": "28",
    "nickname": "Sunny_Bilol",
    "city": "Казань",
    "bio": "Люблю горы и кофе"
]
let serverPhotos = ["bilol-1.jpg", "bilol-2.jpg"]

// Собирает строки карточки профиля. Если показать профиль нельзя, возвращает nil
func profileCard(from raw: [String: String], photos: [String]) -> [String]? {
    // 1. Имя обязательно: если его нет или оно пустое, карточки не будет
    guard let name = raw["name"], !name.isEmpty else {
        return nil
    }

    // 2. Заголовок: имя и, если возраст указан числом, возраст через запятую
    var title = name
    if let ageText = raw["age"], let age = Int(ageText) {
        title += ", \(age)"
    }

    // 3. Ник маленькими буквами, город и главное фото — с запасными текстами
    let nickname = raw["nickname"]?.lowercased() ?? "не задан"
    let city = raw["city"] ?? "не указан"
    let photo = photos.first ?? "нет"

    // 4. Собери строки карточки. Строку "О себе" добавь, только если она есть
    var lines = [title, "Ник: \(nickname)", "Город: \(city)", "Фото: \(photo)"]
    if let bio = raw["bio"] {
        lines.append("О себе: \(bio)")
    }
    return lines
}

// Так экран показывает карточку
if let card = profileCard(from: serverProfile, photos: serverPhotos) {
    for line in card {
        print(line)
    }
} else {
    print("Профиль недоступен")
}
```

## @rules
- mustnot: /[\w\)\]]!(?!=)/ :: В коде есть принудительная развёртка — восклицательный знак после значения. Замени её на `guard let`, `if let`, `??` или `?.`.

## @hint1
Иди по комментариям внутри функции — они совпадают с пунктами задания.

Шаг первый: имя. Без него карточки нет, значит, это работа для `guard let`. Достань значение из словаря по ключу и там же, через запятую, проверь, что строка не пустая. В блоке `else` верни `nil` — тип результата это позволяет.

Шаг второй: заголовок. Заведи переменную и положи в неё имя. Возраст добавляется не всегда, поэтому здесь подойдёт `if let` с двумя шагами через запятую: сначала текст из словаря по ключу, потом число из этого текста. Внутри блока допиши к заголовку запятую, пробел и возраст. Ветка `else` не нужна.

Шаг третий: три значения с запасными текстами. Город — словарь по ключу и оператор из двух вопросительных знаков. Фото — свойство `first` и тот же оператор. Ник — то же самое, но между словарём и запасным текстом стоит перевод в маленькие буквы через `?.`.

Шаг четвёртый: собери массив-переменную из четырёх строк. Потом через `if let` достань текст «О себе» и, если он есть, добавь пятую строку методом `append`. В конце верни массив вместо заглушки.

## @hint2
Два самых непривычных места — заголовок с необязательным возрастом и ник маленькими буквами. Вот похожий код на других данных:

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Функция идёт сверху вниз и для каждого поля выбирает свой способ развёртки.

- Имя: `guard let name = raw["name"], !name.isEmpty`. Без имени продолжать нельзя, поэтому ранний выход с `nil`. После `guard` константа `name` — обычная строка.
- Возраст: `if let ageText = raw["age"], let age = Int(ageText)`. Два опционала подряд: словарь может не содержать ключа, а текст может не быть числом. Если оба шага удались, заголовок дополняется. Если нет — ничего не происходит, и это нормально.
- Ник: `raw["nickname"]?.lowercased() ?? "не задан"`. Цепочка вызывает метод, только если ник есть, а `??` подставляет запасной текст.
- Город и фото: `??` в чистом виде. У словаря и у `first` результат — опционал, запасное значение превращает его в обычную строку.
- «О себе»: `if let` и `append`. Строка появляется, только когда есть что показать.

**Почему функция возвращает `[String]?`.** У неё два разных исхода: «вот карточка» и «карточку показать нельзя». Пустой массив для второго случая был бы той самой договорённостью, о которой легко забыть. А `nil` заставляет вызывающий код обработать этот случай — посмотри на `if let card` внизу: экран либо печатает строки, либо сообщает, что профиль недоступен.

**Почему разные инструменты, а не один.** Всё можно написать через `if let`, но получится втрое длиннее. Выбор инструмента сам рассказывает, что происходит: `guard` — без этого нельзя, `??` — есть значение по умолчанию, `?.` — сделай, если есть, `if let` — дополнительное действие.

**Типичные ошибки:**

- строка «О себе» добавляется всегда, с запасным текстом — по условию её не должно быть вовсе;
- `raw["nickname"].lowercased()` без вопросительного знака — Swift не даст вызвать метод у коробочки;
- возраст вставлен без проверки: `"\(name), \(raw["age"])"` — в карточке появится `Optional("28")`;
- внутри функции используется `serverProfile` вместо параметра `raw` — на данных из редактора всё сойдётся, а на других профилях нет.
