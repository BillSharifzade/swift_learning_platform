## @description

### Контекст
В «Уюте» у каждого объявления есть название, город, цена за ночь и число гостей. Сейчас на экране карточки эти данные лежат в четырёх отдельных константах. Пока квартира одна, это терпимо. Но в выдаче поиска их сотни, и заводить по четыре константы на каждую уже невозможно.

Тимлид пишет: «Заведи, пожалуйста, модель квартиры — тип `Apartment`. Через неё будут работать все экраны: карточка, поиск, бронь. Начни с малого: четыре поля и вывод карточки».

### Новое в Swift
До сих пор ты пользовалась готовыми типами: `String`, `Int`, `Bool`. Теперь создашь свой.

**Структура** — это собственный тип, который собирает связанные данные под одним именем. Её удобно представлять как бланк анкеты: в бланке перечислено, какие поля нужно заполнить. Объявляется структура словом `struct`:

```swift
struct Host {
    let name: String
    let yearsOnService: Int
    let isSuperhost: Bool
}
```

- `Host` — имя типа. Имена типов пишут с большой буквы, как `String` и `Int`.
- В фигурных скобках — **свойства**: константы, которые есть у каждого хозяина жилья. У свойства указывают имя и тип, а значение не пишут — оно у каждого хозяина своё.

Сама структура — только бланк. Чтобы появился конкретный хозяин, бланк нужно заполнить. Заполненный бланк называют **экземпляром** структуры:

```swift
let host = Host(name: "Билол", yearsOnService: 4, isSuperhost: true)
```

Пишется имя типа, а в скобках — значения всех свойств. Перед каждым значением стоит имя свойства и двоеточие — так же, как метки аргументов при вызове функции. Порядок тот же, в котором свойства объявлены в структуре. Такую запись Swift понимает сам, ничего дополнительно писать не нужно.

Чтобы прочитать свойство, после имени экземпляра ставят точку и имя свойства:

```swift
print(host.name)
print("Лет на сервисе: \(host.yearsOnService)")
```

```text
Билол
Лет на сервисе: 4
```

Запись `host.name` ведёт себя как обычная константа: её можно вывести, вставить в строку, сравнить, передать в функцию.

> 💡 Зачем это нужно. `host` — одно значение, а не три разрозненных. Его можно целиком положить в массив, передать в функцию или вернуть из неё. Данные одного хозяина уже не перепутаются с данными другого.

### Задача
1. Объяви структуру `Apartment` с четырьмя свойствами — именно в таком порядке, все через `let`:
   - `title` типа `String` — название объявления;
   - `city` типа `String` — город;
   - `pricePerNight` типа `Int` — цена за ночь в рублях;
   - `maxGuests` типа `Int` — сколько гостей помещается.
2. Создай константу `apartment` — экземпляр `Apartment`: название `Студия у набережной`, город `Казань`, цена `3200`, гостей `2`.
3. Выведи карточку из трёх строк, как в примере. Все данные читай из `apartment` через точку и вставляй в текст интерполяцией.

### Пример
```text
Студия у набережной, Казань
Цена за ночь: 3200 руб.
Гостей: до 2
```

## @solution
```swift
// 1. Объяви структуру Apartment с четырьмя свойствами
struct Apartment {
    let title: String
    let city: String
    let pricePerNight: Int
    let maxGuests: Int
}

// 2. Создай константу apartment — студию в Казани
let apartment = Apartment(title: "Студия у набережной", city: "Казань", pricePerNight: 3200, maxGuests: 2)

// 3. Выведи карточку (три строки), читая данные из apartment
print("\(apartment.title), \(apartment.city)")
print("Цена за ночь: \(apartment.pricePerNight) руб.")
print("Гостей: до \(apartment.maxGuests)")
```

## @output
```
Студия у набережной, Казань
Цена за ночь: 3200 руб.
Гостей: до 2
```

## @rules
- must: /apartment\s*\.\s*title\b/ :: Название для карточки нужно прочитать из экземпляра: `apartment.title`.
- must: /apartment\s*\.\s*city\b/ :: Город для карточки нужно прочитать из экземпляра: `apartment.city`.
- must: /apartment\s*\.\s*pricePerNight\b/ :: Цену для карточки нужно прочитать из экземпляра: `apartment.pricePerNight`.
- must: /apartment\s*\.\s*maxGuests\b/ :: Число гостей для карточки нужно прочитать из экземпляра: `apartment.maxGuests`.

## @hint1
В задаче три шага, и они идут в том же порядке, что комментарии в редакторе.

Шаг первый — «бланк». После слова `struct` пишешь имя типа `Apartment` с большой буквы и открываешь фигурные скобки. Внутри — четыре строки, по одной на свойство. Каждая строка начинается со слова `let`, затем имя свойства, двоеточие и тип. Значений в этих строках нет. Порядок свойств важен: сначала название, потом город, цена и гости.

Шаг второй — «заполненный бланк». Объяви константу `apartment`. Справа от знака равенства — имя типа и круглые скобки, а в них четыре пары «имя свойства, двоеточие, значение» через запятую, в том же порядке, что в структуре. Тексты — в кавычках, числа — без.

Шаг третий — три команды `print`. Данные в текст попадают через интерполяцию, только внутри скобок теперь не просто имя, а имя экземпляра, точка и имя свойства. Не пиши название и цену прямо в тексте: карточка должна собираться из свойств.

## @hint2
Вот как объявляется структура, создаётся экземпляр и читается свойство — на примере хозяина жилья:

```swift
struct Host {
    let name: String
    let yearsOnService: Int
}

let host = Host(name: "Билол", yearsOnService: 4)
print("Хозяин: \(host.name)")
```

Твоя структура устроена так же, только свойств четыре и называются они иначе. А в `print` после имени `apartment` ставь точку и нужное свойство.

## @hint3
Структура готова наполовину, экземпляр и первая строка карточки — тоже. Допиши остальное:

```swift
struct Apartment {
    let title: String
    let city: String
    let pricePerNight: ___
    let ___: Int
}

let apartment = Apartment(title: "Студия у набережной", city: "Казань", pricePerNight: 3200, maxGuests: ___)

print("\(apartment.title), \(apartment.city)")
print("Цена за ночь: \(apartment.___) руб.")
print("Гостей: до ___")
```

В структуре не хватает типа у цены и имени последнего свойства. При создании — числа гостей. В карточке — имени свойства с ценой и целой вставки с числом гостей (черта, скобки, `apartment`, точка, свойство).

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Блок `struct Apartment { ... }` ничего не создаёт и не выводит. Он только описывает новый тип: у любой квартиры есть название, город, цена и число гостей. Настоящая квартира появляется строкой ниже: `Apartment(title: ..., city: ..., ...)` берёт «бланк» и заполняет все четыре поля. Результат — одно значение, оно лежит в константе `apartment`. Запись `apartment.title` достаёт из него одно поле.

**Почему так, а не четыре константы.** Четыре отдельные константы ничем не связаны: Swift не знает, что `title` и `pricePerNight` относятся к одной квартире. Структура связывает их в одно целое. Теперь квартиру можно передать в функцию одним аргументом или сложить сто квартир в массив. А тип `Apartment` гарантирует, что у каждой из них заполнены все поля и цена — именно число.

**Почему при создании нужны имена свойств.** Запись `Apartment("Студия у набережной", "Казань", 3200, 2)` не сработает. Swift требует метки, чтобы по коду было видно, где цена, а где число гостей, и чтобы их нельзя было перепутать местами.

**Типичные ошибки:**

- значения прямо в структуре: `let title = "Студия у набережной"` — тогда у всех квартир было бы одно и то же название;
- другой порядок значений при создании — он должен совпадать с порядком свойств в структуре;
- `struct apartment` с маленькой буквы: имя типа — `Apartment`, а `apartment` — имя константы, это разные имена;
- текст карточки написан готовым, без `apartment.title` и остальных свойств — на экране то же самое, но при другой квартире карточка покажет неправду.
