## @description

### Контекст
В «Копилке» у пользователя несколько счетов: основной, накопительный, счёт на отпуск. Любой из них можно пополнить — одной суммой или сразу несколькими, например, когда в банкомат вносят наличные в три приёма.

Тикет от тимлида: «Нужна функция пополнения. Сколько сумм придёт, заранее неизвестно: одна, три, пять. И функция должна менять тот баланс, который ей передали, — вызывающий код сам говорит, какой счёт пополнить. Суммы, равные нулю или меньше нуля, считаем ошибкой ввода и пропускаем».

### Новое в Swift
В этой задаче два новых приёма. Оба — про параметры.

**Сколько угодно аргументов.** Если после типа параметра поставить три точки, при вызове можно передать любое количество значений через запятую. Внутри функции такой параметр — обычный массив:

```swift
func totalPoints(_ points: Int...) -> Int {
    var sum = 0
    for value in points {
        sum += value
    }
    return sum
}

totalPoints(10)           // 10
totalPoints(10, 25, 5)    // 40
totalPoints()             // 0 — можно и совсем без значений
```

Здесь `points` имеет тип `[Int]`, поэтому по нему можно пройти циклом `for`.

**Изменить переменную, которую передали.** Обычный параметр — это константа, в которую попадает *копия* значения. Изменить его нельзя, да и переменная снаружи от этого не изменилась бы. Чтобы функция работала с самой переменной, перед типом параметра пишут слово `inout`:

```swift
func applyDiscount(_ percent: Int, to price: inout Int) {
    price -= price * percent / 100
}

var subscriptionPrice = 400
applyDiscount(25, to: &subscriptionPrice)
print(subscriptionPrice)   // 300
```

При вызове перед именем переменной ставится знак `&`. Он как подпись: «я знаю, что эта переменная изменится». Без него Swift вызов не примет.

У функции `applyDiscount` нет стрелки и нет `return`: она ничего не возвращает, её результат — изменённая переменная.

Что важно помнить про `inout`:

- передать можно только переменную, объявленную через `var`. Константу или просто число — нельзя: их невозможно изменить;
- внутри функции `inout`-параметр ведёт себя как обычная переменная: его можно читать и менять.

> 💡 `inout` используют нечасто. Обычно функция получает значения и возвращает результат — так проще понять, что она делает. Но когда нужно изменить именно то, что передали, `inout` говорит об этом прямо.

### Задача
В редакторе есть переменная `mainBalance` — баланс основного счёта.

1. Объяви функцию `deposit`. Она ничего не возвращает. Параметры:
   - `amounts` — суммы пополнений: тип `Int...`, при вызове метка не пишется;
   - баланс счёта: метка `to`, внутреннее имя `balance`, тип `inout Int`.
2. Функция прибавляет к `balance` каждую сумму, которая **больше нуля**. Суммы, равные нулю или меньше нуля, пропускает.
3. Пополни `mainBalance` **одним вызовом** `deposit` сразу на три суммы: `5000`, `1500` и `250`.
4. Выведи баланс строкой, как в примере.

### Пример
Вывод программы:

```text
Баланс: 18750 руб.
```

Проверка вызовет функцию и с другими счетами:

```swift
var savings = 1000
deposit(500, to: &savings)              // savings == 1500
deposit(500, -200, 0, 300, to: &savings) // savings == 2300: -200 и 0 пропущены
deposit(to: &savings)                   // сумм нет, savings не меняется
```

## @solution
```swift
// Баланс основного счёта (в рублях)
var mainBalance = 12000

// 1. Объяви функцию deposit(_:to:): она прибавляет суммы к переданному балансу
func deposit(_ amounts: Int..., to balance: inout Int) {
    for amount in amounts {
        if amount > 0 {
            balance += amount
        }
    }
}

// 2. Пополни mainBalance одним вызовом: суммы 5000, 1500 и 250
deposit(5000, 1500, 250, to: &mainBalance)

// 3. Выведи баланс
print("Баланс: \(mainBalance) руб.")
```

## @rules
- must: /deposit\s*\((\s*\d+\s*,){3}\s*to\s*:\s*&\s*mainBalance\s*\)/ :: Пополни `mainBalance` одним вызовом `deposit`: три суммы через запятую, а в конце `to: &mainBalance`.

## @hint1
Начни с объявления — в нём всё новое.

Первый параметр называется `amounts`, перед ним стоит подчёркивание, чтобы при вызове не писать метку. Его тип — целое число с тремя точками сразу после слова `Int`. Три точки означают: «значений может быть сколько угодно».

Второй параметр записан двумя именами: метка `to` и внутреннее имя `balance`. Перед его типом стоит слово `inout`. Благодаря ему функция меняет не копию, а саму переменную, которую передали. Стрелки и типа результата у функции нет: она ничего не возвращает.

В теле `amounts` — обычный массив. Пройди по нему циклом `for`. Каждую сумму проверь: если она больше нуля, прибавь её к `balance`. Если нет — ничего не делай, цикл сам перейдёт к следующей.

Теперь вызов. Сначала через запятую идут три суммы без меток. Потом метка `to`, двоеточие и имя переменной `mainBalance`, перед которым стоит знак `&`. После вызова в `mainBalance` уже лежит новое значение — остаётся его напечатать.

## @hint2
Вот оба приёма по отдельности. Параметр с тремя точками принимает сколько угодно значений, а `inout` позволяет изменить переданную переменную:

```swift
func totalPoints(_ points: Int...) -> Int {
    var sum = 0
    for value in points {
        sum += value
    }
    return sum
}

func applyDiscount(_ percent: Int, to price: inout Int) {
    price -= price * percent / 100
}

var subscriptionPrice = 400
applyDiscount(25, to: &subscriptionPrice)
```

В твоей функции оба приёма встречаются вместе: первый параметр — с тремя точками, второй — `inout`. Отдельная переменная для суммы не нужна: прибавляй прямо к `balance`.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Запись `_ amounts: Int...` означает: при вызове можно передать сколько угодно целых чисел без метки. Внутри функции они собраны в массив `amounts`. Цикл проходит по нему, и каждая сумма больше нуля прибавляется к `balance`. Ноль и отрицательные числа условие не пропускает, а цикл спокойно идёт дальше.

`balance` объявлен как `inout Int`. Поэтому строка `balance += amount` меняет не копию внутри функции, а ту переменную, которую передали при вызове. В вызове `deposit(5000, 1500, 250, to: &mainBalance)` это `mainBalance`: после него там `12000 + 5000 + 1500 + 250 = 18750`.

**Почему `inout`, а не `return`.** Можно было написать функцию, которая возвращает новый баланс: `mainBalance = deposited(mainBalance, 5000, 1500, 250)`. Это тоже рабочий вариант. Но тогда легко забыть присвоить результат — и деньги «потеряются». С `inout` действие читается прямо: «пополни вот этот счёт». А знак `&` в вызове предупреждает читателя кода, что переменная изменится.

**Почему три точки, а не массив.** Параметр типа `[Int]` тоже подошёл бы, но вызывать пришлось бы с квадратными скобками: `deposit([5000, 1500, 250], to: &mainBalance)`. Три точки делают частый случай — одну сумму — совсем простым: `deposit(500, to: &savings)`.

**Типичные ошибки:**

- забыт знак `&` при вызове — Swift не разрешит передать переменную в `inout`-параметр без него;
- слово `inout` поставлено перед именем, а не перед типом: правильно `to balance: inout Int`;
- в функцию передана константа, объявленная через `let`, или просто число — их изменить нельзя;
- вместо пропуска неправильной суммы написан `break` — он оборвёт цикл, и правильные суммы после неё не зачислятся;
- внутри функции изменена `mainBalance` вместо `balance` — тогда функция пополняет только один счёт, какой бы ей ни передали.
