Новый проект — музыкальный плеер «Волна». В нём есть плейлисты, очередь воспроизведения, статистика прослушиваний, эквалайзер и любимые исполнители. Ты приходишь в команду, которая делает экраны плеера, и получаешь задачи из трекера — как обычно, небольшие и настоящие.

До сих пор одна константа или переменная хранила у тебя одно значение: одну цену, одно название, один статус. Но в плейлисте десятки треков, а в статистике — счётчик для каждого из них. Заводить по переменной на каждый трек невозможно. Для этого в Swift есть **коллекции** — значения, внутри которых лежит много других значений.

В этом модуле ты познакомишься с четырьмя видами коллекций. **Массив** хранит список по порядку: треки в плейлисте. **Словарь** хранит пары «ключ — значение»: трек и число его прослушиваний. **Множество** хранит значения без повторов: любимые исполнители. **Кортеж** собирает несколько связанных значений в одно: название, исполнитель и длительность трека.

Коллекции есть в каждом приложении: лента новостей, корзина, список чатов, настройки — всё это они. Циклов в этом модуле ещё не будет: ты научишься создавать коллекции, доставать из них нужное, менять их и получать из них новые.
