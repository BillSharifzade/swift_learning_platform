## @description

### Контекст
В карточке блюда есть кнопка и подпись про доставку. Дизайнер описала их так:

- кнопка называется «В корзину», а если блюдо закончилось — «Нет в наличии»;
- под кнопкой написано «Бесплатно», если доставка ничего не стоит, а иначе — цена, например «149 руб.».

В обоих случаях нужно выбрать **один из двух текстов** и положить его в константу: готовую константу потом получит кнопка на экране. Тимлид добавил в комментарии к задаче: «Тут по одной строке на каждый текст, без `if`. Используй тернарный оператор».

### Новое в Swift
С `if` / `else` выбор из двух значений занимает шесть строк: объявить переменную, проверить условие, присвоить в одной ветке, присвоить в другой. Для такого простого случая в Swift есть короткая запись — **тернарный оператор**. «Тернарный» значит «тройной»: у него три части.

```swift
let isVegan = true
let badge = isVegan ? "Веганское" : "Обычное"
```

Читается как вопрос и два ответа: «блюдо веганское? Если да — "Веганское", если нет — "Обычное"».

Общий вид:

```text
условие ? значение_если_да : значение_если_нет
```

- до знака `?` стоит условие — любое значение типа `Bool`;
- между `?` и `:` — то, что получится, если условие истинно;
- после `:` — то, что получится, если оно ложно.

Главное отличие от `if`: тернарный оператор **даёт значение**. Поэтому его можно поставить справа от знака `=` и сразу объявить константу через `let` — заводить `var` и менять её в ветках не нужно.

Условием может быть и сравнение, а значения можно собирать интерполяцией:

```swift
let spiceLevel = 3
let spiceText = spiceLevel == 0 ? "Не острое" : "Острота: \(spiceLevel) из 5"
```

В `spiceText` окажется `Острота: 3 из 5`.

Два правила:

- оба значения должны быть **одного типа** — например, оба `String`. Написать «или текст, или число» нельзя;
- вокруг `?` и `:` ставь **пробелы**. Без пробела перед `?` Swift поймёт запись по-другому и сообщит об ошибке.

> 💡 Тернарный оператор хорош для простого выбора «одно из двух». Если в ветках нужно выполнить несколько команд или вариантов больше двух, обычный `if` читается лучше.

### Задача
В редакторе есть название блюда `dish`, признак наличия `isAvailable` и стоимость доставки `deliveryCost`. Название уже выводится. Не переименовывай данные — проверка подставит другие значения.

1. Объяви константу `buttonTitle`: если блюдо в наличии, в ней текст `В корзину`, иначе — `Нет в наличии`.
2. Объяви константу `deliveryLabel`: если `deliveryCost` равна нулю, в ней текст `Бесплатно`, иначе — стоимость и `руб.`, например `149 руб.`
3. Выведи две строки: `Кнопка:` и значение `buttonTitle`, затем `Доставка:` и значение `deliveryLabel`.

Обе константы получи тернарным оператором, без `if`.

### Пример
Для данных из редактора (блюдо в наличии, доставка бесплатная):

```text
Том-ям с креветками
Кнопка: В корзину
Доставка: Бесплатно
```

Если блюдо закончилось, а доставка стоит 149 руб.:

```text
Том-ям с креветками
Кнопка: Нет в наличии
Доставка: 149 руб.
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let dish = "Том-ям с креветками"
let isAvailable = true
let deliveryCost = 0

print(dish)

// 1. Текст кнопки: "В корзину" или "Нет в наличии"
let buttonTitle = isAvailable ? "В корзину" : "Нет в наличии"

// 2. Подпись про доставку: "Бесплатно" или стоимость в рублях
let deliveryLabel = deliveryCost == 0 ? "Бесплатно" : "\(deliveryCost) руб."

// 3. Выведи обе строки
print("Кнопка: \(buttonTitle)")
print("Доставка: \(deliveryLabel)")
```

## @rules
- mustnot: /\bif\b/ :: В этой задаче обойдись без `if`: оба текста выбираются тернарным оператором `условие ? одно : другое`.
- must: /\?[\s\S]*:/ :: В коде не видно тернарного оператора. Он записывается так: `условие ? значение_если_да : значение_если_нет`.

## @hint1
Каждая из двух констант — это один вопрос и два возможных ответа.

Для `buttonTitle` вопрос уже готов: это сама константа `isAvailable`, в ней лежит `true` или `false`. После неё ставится знак вопроса, потом текст для случая «да», двоеточие и текст для случая «нет». Вся эта запись стоит справа от знака равенства в объявлении константы.

Для `deliveryLabel` вопрос нужно составить: стоимость доставки равна нулю? Это сравнение через двойной знак равенства. Ответ «да» — готовый текст. Ответ «нет» — тоже текст, но его нужно собрать: вставка со стоимостью, пробел и `руб.` с точкой. Оба ответа должны быть строками, поэтому число идёт внутри кавычек через интерполяцию.

Не забудь пробелы вокруг знака вопроса и двоеточия.

В конце — два `print`: в каждом постоянная часть и вставка с именем константы.

## @hint2
Тернарный оператор сразу даёт значение, которое можно положить в константу:

```swift
let spiceLevel = 3
let spiceText = spiceLevel == 0 ? "Не острое" : "Острота: \(spiceLevel) из 5"
```

До `?` — условие, между `?` и `:` — значение для `true`, после `:` — значение для `false`. Если в роли условия уже готовая константа типа `Bool`, сравнивать её ни с чем не нужно.

## @hint3
Обе строки почти готовы:

```swift
let buttonTitle = isAvailable ? "В корзину" : "___"
let deliveryLabel = deliveryCost ___ 0 ? "Бесплатно" : "\(___) руб."

print("Кнопка: \(buttonTitle)")
print("Доставка: \(deliveryLabel)")
```

В первой строке — текст кнопки для блюда, которое закончилось. Во второй — знак сравнения «равно» и имя константы со стоимостью доставки.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В первой строке Swift смотрит на `isAvailable`. Там `true`, поэтому из двух текстов выбирается тот, что стоит между `?` и `:`, — «В корзину». Он и попадает в `buttonTitle`. Во второй строке сначала вычисляется сравнение `deliveryCost == 0`. Для данных из редактора оно истинно, и в `deliveryLabel` оказывается «Бесплатно». Если бы доставка стоила 149 руб., сравнение дало бы `false`, и Swift взял бы значение после двоеточия: вставка `\(deliveryCost)` превратилась бы в `149`, получилось бы «149 руб.».

**Почему не `if`.** То же самое можно записать через `var buttonTitle = ""` и `if` / `else` с двумя присваиваниями. Но это шесть строк вместо одной, и константа превращается в переменную, хотя менять её потом никто не собирается. Тернарный оператор сразу даёт значение, поэтому результат можно объявить через `let`. Чем меньше в коде переменных, тем меньше мест, где что-то может измениться случайно.

**Почему стоимость в кавычках.** Оба значения тернарного оператора должны быть одного типа. «Бесплатно» — это `String`, значит, и второй вариант должен быть строкой. Поэтому число вставлено в текст через интерполяцию: `"\(deliveryCost) руб."`.

**Типичные ошибки:**

- значения перепутаны местами — сначала всегда идёт вариант для `true`;
- нет пробела перед `?`: запись `isAvailable? "В корзину"` Swift читает иначе и не принимает;
- `deliveryCost = 0` с одним знаком равенства — это присваивание, а не сравнение;
- после двоеточия стоит просто `deliveryCost` без кавычек — тогда один вариант текст, другой число, и Swift сообщит о несовпадении типов.
