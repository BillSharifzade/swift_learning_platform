## @description

### Контекст
Дизайнер прислала макет блока «Доставка» в корзине. В нём четыре элемента, и каждый зависит от состояния корзины:

- плашка «Бесплатная доставка» — если сумма корзины от 5000 рублей;
- кнопка «Оплатить доставку баллами» — если баллов на счёте хватает;
- заглушка «Корзина пуста» — если в корзине нет вещей;
- предупреждение о лимите — если вещей больше, чем можно положить в один заказ.

Показывать и прятать элементы ты научишься в следующем модуле. Сейчас нужна основа: программа должна сама ответить на четыре вопроса «да или нет».

### Новое в Swift
Тип `Bool` ты уже знаешь: в нём всего два значения, `true` и `false`. До сих пор ты писала их в коде сама. Но обычно `Bool` получается как **ответ на вопрос** — результат сравнения двух значений.

Для сравнения есть шесть операторов:

| Оператор | Вопрос | Пример | Результат |
|---|---|---|---|
| `==` | равно? | `5 == 5` | `true` |
| `!=` | не равно? | `5 != 5` | `false` |
| `>` | больше? | `7 > 5` | `true` |
| `<` | меньше? | `7 < 5` | `false` |
| `>=` | больше или равно? | `5 >= 5` | `true` |
| `<=` | меньше или равно? | `7 <= 5` | `false` |

Результат сравнения можно положить в константу — она получит тип `Bool`:

```swift
let stock = 3          // осталось на складе
let wanted = 5         // хочет купить покупательница
let isEnough = stock >= wanted
print(isEnough)        // false
```

Имена таких констант принято начинать со слов `is`, `has` или `can` — «является», «имеет», «может». Тогда код читается как вопрос: `isEnough` — «достаточно ли?».

**Главная ловушка — граница.** Слова «больше 100» и «от 100» означают разное:

```swift
let reviewsCount = 100
print(reviewsCount > 100)     // false: ровно 100 — это ещё не «больше»
print(reviewsCount >= 100)    // true: «от 100» включает и само число 100
```

Когда читаешь условие задачи, всегда спрашивай себя: а что должно быть ровно на границе?

> ⚠️ Не путай `=` и `==`. Один знак равенства — это «положи значение». Два — это вопрос «равны ли они?». Двойные операторы `==`, `!=`, `>=`, `<=` пишутся слитно, без пробела внутри.

### Задача
В редакторе есть данные корзины:

- `cartTotal` — сумма корзины, `freeDeliveryFrom` — от какой суммы доставка бесплатная;
- `bonusBalance` — баллы на счёте, `deliveryBonusCost` — сколько баллов стоит доставка;
- `itemsCount` — сколько вещей в корзине, `maxItemsPerOrder` — сколько вещей можно положить в один заказ.

Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `isDeliveryFree`: `true`, если сумма корзины **не меньше** порога. Ровно на пороге доставка уже бесплатная.
2. Объяви константу `canPayWithBonuses`: `true`, если баллов на счёте **не меньше**, чем стоит доставка.
3. Объяви константу `isCartEmpty`: `true`, если вещей в корзине ноль.
4. Объяви константу `isOverLimit`: `true`, если вещей **больше**, чем можно положить в один заказ. Ровно столько, сколько можно, — это ещё не превышение.
5. Выведи четыре строки, как в примере.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let cartTotal = 4200
let freeDeliveryFrom = 5000
let bonusBalance = 350
let deliveryBonusCost = 300
let itemsCount = 2
let maxItemsPerOrder = 10

// 1. Доставка бесплатная, если сумма корзины не меньше порога
let isDeliveryFree = cartTotal >= freeDeliveryFrom

// 2. Баллов хватает, если их не меньше, чем стоит доставка
let canPayWithBonuses = bonusBalance >= deliveryBonusCost

// 3. Корзина пуста, если вещей ноль
let isCartEmpty = itemsCount == 0

// 4. Лимит превышен, если вещей больше, чем можно в одном заказе
let isOverLimit = itemsCount > maxItemsPerOrder

// 5. Выведи четыре строки с ответами
print("Бесплатная доставка: \(isDeliveryFree)")
print("Хватает баллов на доставку: \(canPayWithBonuses)")
print("Корзина пуста: \(isCartEmpty)")
print("Превышен лимит вещей: \(isOverLimit)")
```

func __t_bool(_ name: String, _ value: Any, _ want: Bool, hint: String) {

## @hint1
Каждая из четырёх констант — это одно сравнение двух значений. Слова `true` и `false` самой писать не нужно: их выдаст оператор сравнения.

Первая константа. «Не меньше порога» значит «больше или равно». Слева `cartTotal`, справа `freeDeliveryFrom`, между ними оператор из двух знаков: «больше» и «равно».

Вторая устроена так же: баллов на счёте должно быть больше или равно цене доставки в баллах. Слева `bonusBalance`, справа `deliveryBonusCost`.

Третья — проверка на равенство: `itemsCount` сравнивается с нулём. Помни, что вопрос «равно ли?» записывается двумя знаками равенства подряд.

Четвёртая — строгое «больше»: `itemsCount` больше, чем `maxItemsPerOrder`. Здесь знак равенства не нужен, потому что ровно десять вещей при лимите десять — это ещё разрешено.

В конце четыре команды `print`: текст до двоеточия из примера и вставка с именем нужной константы. Значение типа `Bool` при вставке само превращается в слово `true` или `false`.

## @hint2
Результат сравнения кладут в константу так:

```swift
let stock = 3
let wanted = 5
let isEnough = stock >= wanted     // false

let reviewsCount = 0
let hasNoReviews = reviewsCount == 0   // true
```

Справа от первого `=` стоит целое выражение-вопрос. Swift вычисляет ответ и кладёт в константу `true` или `false`.

## @hint3
Два сравнения готовы. Подбери операторы для остальных:

```swift
let isDeliveryFree = cartTotal >= freeDeliveryFrom
let canPayWithBonuses = bonusBalance ___ deliveryBonusCost
let isCartEmpty = itemsCount ___ 0
let isOverLimit = itemsCount > maxItemsPerOrder

print("Бесплатная доставка: \(isDeliveryFree)")
print("Хватает баллов на доставку: \(canPayWithBonuses)")
print("Корзина пуста: \(___)")
print("Превышен лимит вещей: \(___)")
```

В первом пропуске — оператор «больше или равно». Во втором — оператор «равно» (два знака). В двух последних — имена констант для третьей и четвёртой строки.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Каждая строка с `let` задаёт вопрос и запоминает ответ. `cartTotal >= freeDeliveryFrom` для данных из редактора — это `4200 >= 5000`. Это неправда, поэтому в `isDeliveryFree` попадает `false`. `350 >= 300` — правда, в `canPayWithBonuses` попадает `true`. `2 == 0` — неправда. `2 > 10` — тоже неправда. При выводе значения типа `Bool` превращаются в слова `true` и `false`.

**Почему в одних местах `>=`, а в другом `>`.** Всё решает граница. Бесплатная доставка действует «от 5000 рублей» — покупательница с корзиной ровно на 5000 должна её получить, поэтому `>=`. С баллами так же: если их ровно столько, сколько стоит доставка, их хватает. А лимит звучит как «не больше 10 вещей»: десять — можно, одиннадцать — уже нет. Превышение — это строго больше, поэтому `>`. Ошибка на единицу на границе — одна из самых частых в программировании, и дополнительные сценарии проверяют именно такие случаи.

**Почему ответы лежат в константах.** В следующем модуле ты научишься писать «если доставка бесплатная, покажи плашку». Там понадобится именно такое значение типа `Bool` с понятным именем. А пока мы просто выводим его на экран.

**Типичные ошибки:**

- `itemsCount = 0` с одним знаком равенства — это попытка изменить константу, а не сравнение;
- `=>` или `> =` вместо `>=` — знаки должны идти в порядке «больше, равно» и без пробела;
- `>` там, где нужно `>=`, — тогда корзина ровно на 5000 рублей не получит бесплатную доставку;
- `let isDeliveryFree = false`, написанное от руки, — на данных из редактора совпадёт, а на других корзинах нет.
