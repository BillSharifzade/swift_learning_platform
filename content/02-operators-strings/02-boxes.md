## @description

### Контекст
У «Гардероба» есть оптовые покупатели: школа танцев заказывает форму на всю группу, компания — футболки для сотрудников. Такие заказы на складе раскладывают по коробкам. В одну коробку помещается определённое число вещей. То, что не заполнило целую коробку, кладут в пакет.

Заведующая складом пишет: «Упаковщики каждый раз считают на калькуляторе, сколько коробок готовить, и ошибаются. Пусть экран сборки заказа сам показывает число полных коробок и сколько вещей останется для пакета».

### Новое в Swift
Четвёртое арифметическое действие — деление. Оно записывается косой чертой `/`.

У деления в Swift есть важная особенность. Когда делятся два **целых** числа, результат — тоже целое число. Дробная часть не округляется, а просто отбрасывается:

```swift
print(7 / 2)     // 3, а не 3.5
print(9 / 10)    // 0
```

Это не ошибка, а удобный инструмент. Он отвечает на вопрос «сколько раз одно число **целиком** помещается в другое». Именно так считают то, что не делится на части: коробки, машины, страницы.

А сколько при этом «не поместилось», показывает оператор `%` — **остаток от деления** (Shift + 5):

```swift
print(7 % 2)     // 1: две двойки — это 6, до семи остаётся 1
```

Вместе эти два оператора встречаются очень часто. Например, так минуты превращают в часы и минуты:

```swift
let deliveryMinutes = 135
let hours = deliveryMinutes / 60
let minutes = deliveryMinutes % 60
print("Курьер приедет через \(hours) ч \(minutes) мин")
```

```text
Курьер приедет через 2 ч 15 мин
```

В 135 минутах два полных часа (`135 / 60` — это `2`), и ещё 15 минут остаётся (`135 % 60` — это `15`).

Два особых случая, о которых полезно знать заранее:

- Число делится без остатка — тогда остаток равен нулю: `120 % 60` — это `0`.
- Делимое меньше делителя — тогда целых частей ноль, а в остатке всё число: `45 / 60` — это `0`, а `45 % 60` — это `45`.

> ⚠️ Делить на ноль нельзя: программа аварийно остановится. В этой задаче вместимость коробки всегда больше нуля.

### Задача
В редакторе есть данные заказа: `itemsCount` — сколько вещей в заказе, `boxCapacity` — сколько вещей помещается в одну коробку. Не переименовывай их — проверка подставит другие значения.

1. Объяви константу `fullBoxes` — сколько коробок заполнится целиком.
2. Объяви константу `leftover` — сколько вещей останется после того, как заполнены все полные коробки. Найди её оператором `%`.
3. Выведи три строки, как в примере.

### Пример
Для данных из редактора (50 вещей, в коробке по 12):

```text
Вещей в заказе: 50
Полных коробок: 4
Останется вещей: 2
```

А для заказа из 36 вещей коробки заполнятся ровно:

```text
Вещей в заказе: 36
Полных коробок: 3
Останется вещей: 0
```

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let itemsCount = 50
let boxCapacity = 12

// 1. Сколько коробок заполнится целиком
let fullBoxes = itemsCount / boxCapacity

// 2. Сколько вещей останется для пакета
let leftover = itemsCount % boxCapacity

// 3. Выведи три строки для экрана сборки
print("Вещей в заказе: \(itemsCount)")
print("Полных коробок: \(fullBoxes)")
print("Останется вещей: \(leftover)")
```

## @rules
- must: /%/ :: Остаток найди оператором `%` — в этой задаче мы учимся именно ему.

## @hint1
Здесь два вычисления, и для каждого есть свой оператор.

Первый вопрос — «сколько раз вместимость коробки целиком помещается в число вещей». На него отвечает деление целых чисел: раздели `itemsCount` на `boxCapacity` косой чертой. Дробную часть Swift отбросит сам — получится как раз число полных коробок. Результат положи в константу `fullBoxes`.

Второй вопрос — «сколько вещей не поместилось». На него отвечает оператор остатка — знак процента. Слева от него снова `itemsCount`, справа `boxCapacity`. Результат положи в константу `leftover`.

Потом три команды `print`: в первой вставка с `itemsCount`, во второй — с `fullBoxes`, в третьей — с `leftover`.

Проверь себя на данных из редактора: 12 помещается в 50 четыре раза (это 48), и ещё 2 вещи остаются.

## @hint2
Деление нацело и остаток — пара операторов, которые почти всегда пишут рядом:

```swift
let deliveryMinutes = 135
let hours = deliveryMinutes / 60      // 2 полных часа
let minutes = deliveryMinutes % 60    // и ещё 15 минут
```

У тебя вместо минут — вещи, а вместо числа 60 — вместимость коробки.

## @hint3
Первая строка и вывод готовы. Допиши вторую:

```swift
let fullBoxes = itemsCount / boxCapacity
let leftover = itemsCount ___ boxCapacity

print("Вещей в заказе: \(itemsCount)")
print("Полных коробок: \(___)")
print("Останется вещей: \(___)")
```

В первом пропуске — оператор остатка от деления. В двух других — имена констант, которые ты только что объявила.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `itemsCount` и `boxCapacity` — целые числа, поэтому `itemsCount / boxCapacity` тоже даёт целое: `50 / 12` — это `4`. На калькуляторе получилось бы 4,1666…, но Swift отбрасывает всё после запятой. Нам это и нужно: коробок бывает четыре или пять, а «четыре с хвостиком» не бывает. Оператор `%` считает, что осталось: `50 % 12` — это `2`, потому что четыре коробки по 12 — это 48 вещей, а до 50 не хватает двух.

**Почему именно эти операторы.** Остаток можно найти и длинным путём: умножить число коробок на вместимость и вычесть из общего количества. Но `%` делает это одним действием, и по коду сразу видно, что имеется в виду. В настоящих приложениях эта пара встречается постоянно: минуты и секунды, страницы списка товаров, ряды и места.

**Проверь граничные случаи.** Если вещей 36, то `36 / 12` — это `3`, а `36 % 12` — это `0`: всё разложилось ровно. Если вещей 7, то `7 / 12` — это `0`, а `7 % 12` — это `7`: ни одной полной коробки, все вещи идут в пакет. Формулы те же, менять ничего не нужно.

**Типичные ошибки:**

- `/` и `%` перепутаны местами — тогда коробок окажется 2, а в остатке 4;
- обратная косая черта `\` вместо прямой `/` — обратная нужна только для вставок в строках;
- ожидание, что `50 / 12` округлится до 5, — Swift не округляет, а отбрасывает дробную часть.
