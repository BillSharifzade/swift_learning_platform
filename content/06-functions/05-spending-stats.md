## @description

### Контекст
На главном экране «Копилки» появится карточка «Траты за неделю». На ней три числа: сколько потрачено всего, какая трата была самой крупной и сколько в среднем уходит на одну покупку.

Разработчик экрана просит: «Мне нужны все три числа разом. Не хочу вызывать три разные функции и три раза проходить по одному и тому же списку. Сделай одну функцию, которая вернёт всё сразу».

### Новое в Swift
Функция возвращает одно значение. Но этим значением может быть **кортеж** — несколько значений в круглых скобках, у каждого своё имя. С кортежами ты уже работала в модуле про коллекции. Теперь кортеж станет результатом функции.

Тип кортежа пишется после стрелки: в круглых скобках через запятую перечислены имена и типы его частей.

```swift
func splitBill(total: Int, people: Int) -> (share: Int, remainder: Int) {
    if people == 0 {
        return (share: 0, remainder: 0)
    }
    let share = total / people
    let remainder = total % people
    return (share: share, remainder: remainder)
}
```

Эта функция делит счёт в кафе на компанию: сколько платит каждый и сколько рублей остаётся «лишними». После `return` стоит кортеж — значения в том же порядке и с теми же именами, что в объявлении.

Результат можно сохранить в константу и читать части через точку:

```swift
let bill = splitBill(total: 3200, people: 3)
print(bill.share)       // 1066
print(bill.remainder)   // 2
```

А можно сразу разобрать на отдельные константы:

```swift
let (share, remainder) = splitBill(total: 3200, people: 3)
```

Обрати внимание на начало функции. Если людей ноль, делить нельзя: деление целого числа на ноль аварийно останавливает программу. Поэтому особый случай проверяется первым, и функция сразу возвращает «пустой» результат. Запомни этот приём — он пригодится в задаче.

Два напоминания. Первое: тип массива записывается в квадратных скобках, например `[Int]` — массив целых чисел. Так же он пишется и у параметра функции. Второе: среднее значение обычно дробное, а деление двух `Int` отбрасывает дробную часть. Чтобы её сохранить, оба числа сначала превращают в `Double`: `Double(sum) / Double(count)`.

### Задача
В редакторе есть список трат за неделю — `weekExpenses`.

1. Объяви функцию `spendingStats`. Параметр: метка `for`, внутреннее имя `expenses`, тип `[Int]` — траты в рублях (все числа больше нуля). Функция возвращает кортеж `(total: Int, largest: Int, average: Double)`:
   - `total` — сумма всех трат;
   - `largest` — самая крупная трата;
   - `average` — средняя трата: сумма, делённая на количество трат, дробным числом.
2. Если список пустой, функция возвращает `(total: 0, largest: 0, average: 0.0)`.
3. Вызови функцию для `weekExpenses`, сохрани результат в константу `stats` и выведи три строки, как в примере.

Сумму и самую крупную трату удобно найти одним циклом `for` — так, как ты делала в модуле про циклы.

### Пример
Вывод программы:

```text
Всего: 5000 руб.
Самая крупная трата: 2350 руб.
В среднем: 1000.0 руб.
```

Проверка вызовет функцию и с другими списками:

```swift
let result = spendingStats(for: [100, 250])
// result.total == 350, result.largest == 250, result.average == 175.0

let empty = spendingStats(for: [])
// empty.total == 0, empty.largest == 0, empty.average == 0.0
```

## @solution
```swift
// Траты за неделю (в рублях)
let weekExpenses = [450, 1200, 300, 2350, 700]

// 1. Объяви функцию spendingStats(for:), которая возвращает кортеж из трёх значений
func spendingStats(for expenses: [Int]) -> (total: Int, largest: Int, average: Double) {
    if expenses.isEmpty {
        return (total: 0, largest: 0, average: 0.0)
    }

    var total = 0
    var largest = 0
    for expense in expenses {
        total += expense
        if expense > largest {
            largest = expense
        }
    }

    let average = Double(total) / Double(expenses.count)
    return (total: total, largest: largest, average: average)
}

// 2. Вызови функцию для weekExpenses, сохрани результат в stats и выведи три строки
let stats = spendingStats(for: weekExpenses)
print("Всего: \(stats.total) руб.")
print("Самая крупная трата: \(stats.largest) руб.")
print("В среднем: \(stats.average) руб.")
```

## @hint1
Раздели работу на три шага: объявление, вычисления, возврат.

Объявление. Параметр — массив целых чисел с меткой `for` и внутренним именем `expenses`. После стрелки — тип кортежа: круглые скобки, а в них три пары «имя: тип» через запятую. Имена и типы возьми из задания: два целых числа и одно дробное.

Вычисления. Первым делом проверь особый случай: если массив пустой, сразу верни кортеж из нулей. Дальше заведи две переменные с нулями — для суммы и для самой крупной траты. Пройди по массиву циклом `for`. На каждом шаге прибавляй трату к сумме и сравнивай её с текущим максимумом: если трата больше, она становится новым максимумом. После цикла посчитай среднее. Сумму и количество элементов перед делением преврати в `Double`, иначе дробная часть пропадёт.

Возврат. После `return` напиши кортеж в круглых скобках: три значения с теми же именами и в том же порядке, что в объявлении.

Для вывода сохрани результат вызова в константу `stats` и обращайся к частям через точку: `stats.total`, `stats.largest`, `stats.average`.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** После стрелки записан тип результата — кортеж из трёх именованных частей. Значит, каждый `return` в функции обязан отдать именно такой кортеж.

Первым идёт особый случай. Для пустого списка считать нечего, и главное — нельзя делить на количество, равное нулю. Поэтому функция сразу возвращает нули и завершается.

Дальше обычное накопление в цикле. `total` копит сумму. `largest` хранит самую крупную трату из уже просмотренных: если очередная трата больше, она занимает это место. Начальное значение `0` подходит, потому что все траты больше нуля — первая же из них его заменит.

Среднее считается после цикла. `Double(total) / Double(expenses.count)` сначала превращает оба целых числа в дробные, а потом делит. Последняя строка собирает три результата в кортеж.

**Почему кортеж, а не три функции.** Три отдельные функции — это три прохода по списку и три вызова на экране. К тому же сумма, максимум и среднее описывают один и тот же список, им естественно быть вместе. Кортеж подходит для таких небольших «пакетов» из двух-трёх связанных значений. Имена частей делают код понятным: `stats.largest` читается лучше, чем «второе число результата».

**Типичные ошибки:**

- `Double(total / expenses.count)` — сначала выполняется деление целых чисел, дробная часть уже потеряна, и превращать в `Double` поздно;
- нет проверки пустого списка — для него среднее получится «не числом» (`nan`), а при делении целых программа аварийно остановится;
- в типе результата нет имён: `-> (Int, Int, Double)` — тогда обращения `stats.total` не работают;
- значения в `return` перепутаны местами — имена подскажут порядок, если писать их явно: `(total: total, largest: largest, average: average)`.
