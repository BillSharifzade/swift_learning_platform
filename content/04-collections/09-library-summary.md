## @description

### Контекст
Финальная задача по плееру «Волна». На экране «Моя музыка» есть сводка, и она должна обновляться каждый раз, когда трек доиграл до конца.

Тимлид описал, что происходит в этот момент: «Движок присылает кортеж `justPlayed` с названием и исполнителем. Дальше три дела. Первое: если трека ещё нет в медиатеке, он добавляется туда сам — мы называем это автодобавлением. Второе: его счётчик прослушиваний растёт на единицу. Третье: исполнитель попадает в набор тех, кого пользователь слушает. После этого печатаем сводку. Всё, что нужно, ты уже умеешь».

В этой задаче встречаются все четыре вида коллекций из модуля.

### Что пригодится
Нового здесь нет. Коротко о том, что понадобится:

- **Кортеж.** К именованным элементам обращаются через точку: `order.total`.
- **Массив.** `contains` отвечает, есть ли элемент. `append` добавляет в конец. `count` даёт количество, а последний элемент лежит под индексом `count - 1`.
- **Словарь.** Счётчик увеличивают так: `stock[item, default: 0] += 1`. Читают тоже с запасным значением: `stock[item, default: 0]`.
- **Множество.** `Set(массив)` убирает повторы, `insert` добавляет значение, если его ещё нет. Порядка у множества нет, поэтому перед выводом — `sorted()`.
- **Условие с отрицанием.** Знак `!` перед выражением переворачивает `true` и `false`. Так записывают «если НЕ содержит»:

```swift
var guests = ["Билол", "Мама"]
let newGuest = "Сестра"

if !guests.contains(newGuest) {
    guests.append(newGuest)
}
```

Без такой проверки гость, который уже есть в списке, оказался бы в нём дважды.

### Задача
В редакторе есть медиатека `library`, счётчики `playCounts`, история исполнителей `artistHistory` и кортеж `justPlayed` с элементами `title` и `artist`. Не переименовывай их — проверка подставит другие данные.

Сначала обнови данные:

1. Если трека с названием `justPlayed.title` ещё нет в `library`, добавь его в конец. Если он там уже есть, массив меняться не должен.
2. Увеличь на 1 счётчик этого трека в `playCounts`. Если счётчика ещё нет, отсчёт идёт от нуля.
3. Объяви переменную `artists` — множество исполнителей из `artistHistory`. Добавь в него `justPlayed.artist`.

Затем выведи сводку из шести строк:

4. `Только что играл:`, название трека, дефис и исполнитель. Вокруг дефиса — по пробелу.
5. `Прослушиваний:` и счётчик этого трека.
6. `Треков в медиатеке:` и их количество.
7. `Последний добавленный:` и последний элемент `library`.
8. `Исполнителей:` и количество исполнителей в `artists`.
9. `Исполнители:` и массив исполнителей по алфавиту.

### Пример
Для данных из редактора:

```text
Только что играл: Океан внутри - Билол
Прослушиваний: 1
Треков в медиатеке: 5
Последний добавленный: Океан внутри
Исполнителей: 3
Исполнители: ["Билол", "Северный ветер", "Тихий час"]
```

Трека «Океан внутри» в медиатеке не было — он добавился пятым. А Билол уже встречался в истории, поэтому исполнителей по-прежнему трое.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
var library = ["Маяк", "Апрель", "Комета", "Белый шум"]
var playCounts = ["Маяк": 12, "Комета": 7]
let artistHistory = ["Северный ветер", "Билол", "Северный ветер", "Тихий час"]
let justPlayed = (title: "Океан внутри", artist: "Билол")

// 1. Автодобавление: если трека нет в library — добавь его в конец
if !library.contains(justPlayed.title) {
    library.append(justPlayed.title)
}

// 2. Увеличь счётчик прослушиваний этого трека на 1
playCounts[justPlayed.title, default: 0] += 1

// 3. Объяви множество artists из artistHistory и добавь в него исполнителя трека
var artists = Set(artistHistory)
artists.insert(justPlayed.artist)

// 4–9. Выведи сводку из шести строк
print("Только что играл: \(justPlayed.title) - \(justPlayed.artist)")
print("Прослушиваний: \(playCounts[justPlayed.title, default: 0])")
print("Треков в медиатеке: \(library.count)")
print("Последний добавленный: \(library[library.count - 1])")
print("Исполнителей: \(artists.count)")
print("Исполнители: \(artists.sorted())")
```

## @rules
- must: /\bsorted\s*\(/ :: У множества нет порядка. Перед выводом отсортируй исполнителей: `artists.sorted()`.

## @hint1
Раздели работу на две части: сначала обнови три коллекции, потом печатай. Если поменять порядок, в сводку попадут старые данные.

Автодобавление — это условие. Вопрос «есть ли трек в медиатеке» задаёт `contains`, а тебе нужен обратный случай — «нет», поэтому перед выражением ставится знак отрицания. Внутри фигурных скобок одна команда: добавить название в конец массива. Ветка `else` не нужна — если трек уже есть, делать нечего. Название трека — это элемент кортежа `justPlayed`, до него добираются через точку.

Счётчик — одна строка, такая же, как в задаче про прослушивания: обращение к словарю по ключу с запасным нулём и оператор «прибавить и записать».

Исполнители — две строки, как в задаче про любимых исполнителей: множество создаётся из массива, а потом в него вставляется одно значение. Множество меняется, значит, это переменная.

В сводке шесть команд `print`. Первая берёт оба элемента кортежа. Вторая читает счётчик с запасным значением. Третья и четвёртая — количество элементов массива и его последний элемент по формуле «количество минус один». Пятая и шестая — количество элементов множества и само множество, отсортированное.

## @hint2
Самое непривычное место — условие «если не содержит». Вот как оно выглядит на другом примере, вместе с обращением к элементу кортежа:

```swift
var guests = ["Билол", "Мама"]
let booking = (name: "Сестра", table: 4)

if !guests.contains(booking.name) {
    guests.append(booking.name)
}
```

Знак `!` стоит вплотную перед выражением и превращает «содержит» в «не содержит».

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** Событие «трек доиграл» меняет три коллекции, и у каждой своя роль.

Медиатека — **массив**: в ней важен порядок добавления, поэтому последний элемент и есть «последний добавленный». Условие `!library.contains(justPlayed.title)` защищает от повторов: массив сам за ними не следит, и без проверки дослушанный дважды трек появился бы в медиатеке два раза.

Счётчики — **словарь**: по названию трека сразу находится число. Строка с `default: 0` и `+= 1` работает и для трека со счётчиком, и для трека без него.

Исполнители — **множество**: здесь важна только уникальность. `insert` добавляет исполнителя, если его ещё нет, и ничего не делает, если он уже есть. Поэтому проверка, как у массива, не нужна. Сравни первый и третий шаги: одна и та же задача «добавить без повторов» решается для массива тремя строками, а для множества — одной.

А сам `justPlayed` — **кортеж**: название и исполнитель одного трека, которые ходят вместе.

**Почему порядок шагов важен.** Все строки сводки читают уже обновлённые данные. Если напечатать количество треков до автодобавления, оно будет на единицу меньше.

**Почему индекс `library.count - 1` здесь безопасен.** Даже если медиатека была пустой, после первого шага в ней есть хотя бы один трек. Без первого шага на пустой медиатеке программа бы остановилась.

**Типичные ошибки:**

- забыт знак `!` — тогда трек добавляется, только если он уже есть, то есть всё наоборот;
- `library.append` без условия — в сценарии, где трек уже в медиатеке, он задвоится;
- `playCounts[justPlayed.title] = 1` — счётчик не растёт, а каждый раз сбрасывается на единицу;
- `artistHistory.count` вместо `artists.count` — это число записей в истории вместе с повторами;
- `artists` напечатано без `sorted()` — порядок исполнителей будет случайным.
