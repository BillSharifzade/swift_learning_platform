## @description

### Контекст
У каждого гостя кофейни есть бонусный счёт. За покупки баллы начисляются, а потом ими можно оплатить десерт. Значит, число баллов постоянно меняется.

Коллега написал заготовку, которая показывает, как счёт меняется в течение дня, и ушёл в отпуск. В трекере задач осталась запись: «Код не собирается, посмотрите, пожалуйста. И ещё не дописан последний шаг — оплата десерта баллами».

Это твой первый опыт исправления чужой ошибки. В работе разработчика такое происходит каждый день.

### Новое в Swift
Ты уже знаешь константы: `let` создаёт «коробочку», значение в которой не меняется никогда.

Если значение должно меняться, нужна **переменная**. Она объявляется словом `var`:

```swift
var cupsSold = 10
```

Чтобы положить в переменную новое значение, пишут её имя, знак `=` и новое значение. Слово `var` второй раз **не пишут** — переменная уже существует:

```swift
var cupsSold = 10
print(cupsSold)   // 10

cupsSold = 11
print(cupsSold)   // 11
```

Старое значение при этом исчезает, на его месте оказывается новое.

Обрати внимание: число пишется **без кавычек**. `10` — это число, а `"10"` — текст из двух символов.

**А что будет, если попробовать изменить константу?**

```swift
let cupsSold = 10
cupsSold = 11     // ошибка!
```

Swift откажется собирать такой код. Это не поломка, а защита: объявив что-то через `let`, ты говоришь «это менять нельзя», и Swift следит, чтобы никто не нарушил обещание.

> 💡 Правило опытных разработчиков: сначала всё объявляй через `let`. Понадобилось изменить значение — замени на `var`. Так случайных изменений будет меньше.

### Задача
1. Нажми «Проверить» прямо сейчас, ничего не меняя. Прочитай объяснение ошибки — это полезный опыт.
2. Исправь ошибку: баллы должны меняться, значит, `bonusPoints` должна быть переменной.
3. Допиши последний шаг: гость оплатил десерт баллами, и на счёте осталось `50`. Положи это значение в `bonusPoints` и выведи его.

### Пример
```text
120
150
50
```

## @starter
```swift
// Бонусный счёт гостя: утром на нём 120 баллов
let bonusPoints = 120
print(bonusPoints)

// Гость купил кофе — баллов стало 150
bonusPoints = 150
print(bonusPoints)

// Гость оплатил баллами десерт — осталось 50
// Допиши изменение и вывод здесь

```

## @solution
```swift
// Бонусный счёт гостя: утром на нём 120 баллов
var bonusPoints = 120
print(bonusPoints)

// Гость купил кофе — баллов стало 150
bonusPoints = 150
print(bonusPoints)

// Гость оплатил баллами десерт — осталось 50
// Допиши изменение и вывод здесь
bonusPoints = 50
print(bonusPoints)
```

## @rules
- must: /\bvar\s+bonusPoints\b/ :: Баллы меняются, поэтому `bonusPoints` нужно объявить через `var`.

## @hint1
Сначала разберись с ошибкой. Посмотри на самое первое объявление: каким словом создана `bonusPoints`? Этим словом создают константы, а константу нельзя менять. Но уже через несколько строк ей пытаются присвоить новое значение — вот Swift и возражает. Чтобы значение можно было менять, в объявлении должно стоять другое слово — то, которым создают переменные.

Теперь последний шаг. Он устроен точно так же, как шаг с покупкой кофе, который уже есть в коде: сначала в `bonusPoints` кладётся новое число, потом оно выводится командой `print`. Слово `var` повторять не нужно — переменная уже создана.

## @hint2
Константа создаётся словом `let`, а переменная — словом `var`. Только переменной можно присвоить новое значение:

```swift
var cupsSold = 10
cupsSold = 11
print(cupsSold)
```

В первой строке кода замени одно слово на другое, и ошибка исчезнет.

## @hint3
Ошибка исправлена, осталось дописать последний шаг:

```swift
var bonusPoints = 120
print(bonusPoints)

bonusPoints = 150
print(bonusPoints)

bonusPoints = ___
print(___)
```

В первом пропуске — сколько баллов осталось после десерта. Во втором — имя переменной, значение которой нужно вывести.

## @hint4
Вот готовое решение:

{{solution}}

**Что было не так.** В заготовке стояло `let bonusPoints = 120`. Слово `let` создаёт константу — значение, которое нельзя менять. А строкой ниже код пытался сделать `bonusPoints = 150`. Swift заметил противоречие ещё до запуска и отказался собирать программу. Мы заменили `let` на `var`, и теперь `bonusPoints` — переменная.

**Как работает решение.** Первая строка создаёт переменную и кладёт в неё `120`. Строка `bonusPoints = 150` заменяет значение на `150`, а `bonusPoints = 50` — на `50`. Каждый `print` выводит то значение, которое лежит в переменной в этот момент. Поэтому на экране три разных числа, хотя имя в скобках везде одно.

**Почему во второй и третьей раз нет слова `var`.** `var` означает «создай новую переменную». Переменная `bonusPoints` уже создана, второй раз создавать её нельзя — Swift сообщит о повторном объявлении. Чтобы изменить значение, достаточно имени и знака `=`.

**Типичные ошибки:**

- `var bonusPoints = 50` в последнем шаге — это попытка создать вторую переменную с тем же именем;
- `bonusPoints = "50"` — в кавычках это текст, а в переменной лежат числа. Тип менять нельзя;
- `print` стоит раньше присваивания — тогда выведется старое значение.
