## @description

### Контекст
В «Волне» готовится новая функция — «Совпадение вкусов». В ней можно сравнить свою музыку с музыкой подруги и увидеть три списка: кого вы слушаете обе, кого подруга может посоветовать и кто попадёт в ваш общий плейлист.

Исходные данные — две истории прослушиваний: своя, `myHistory`, и подруги, `friendHistory`. В истории записан исполнитель каждого прослушанного трека, поэтому одни и те же имена повторяются много раз.

Тимлид предупреждает: «Не сравнивай массивы с повторами — запутаешься. Сначала получи из каждой истории набор уникальных исполнителей. Для этого есть множество».

### Новое в Swift
**Множество** (`Set`) — коллекция, в которой каждое значение встречается только один раз. Порядка у множества, как и у словаря, нет.

Самый частый способ получить множество — сделать его из массива. Повторы при этом исчезают:

```swift
let orders = ["Латте", "Раф", "Латте", "Какао", "Латте"]
var drinks = Set(orders)
print(drinks.count)   // 3 — Латте, Раф и Какао
```

Множество можно записать и напрямую, но тогда тип нужно указать явно — иначе Swift примет квадратные скобки за массив. Тип пишется как `Set<String>`: в угловых скобках стоит тип элементов.

```swift
let parkMenu: Set<String> = ["Латте", "Чай", "Какао"]
```

**Добавить значение** — `insert`. Если такое значение уже есть, ничего не изменится:

```swift
drinks.insert("Чай")   // добавился, теперь значений 4
drinks.insert("Раф")   // уже был — по-прежнему 4
```

**Проверить, есть ли значение** — `contains`, как у массива:

```swift
print(drinks.contains("Чай"))   // true
```

**Сравнить два множества.** Ради этого множества чаще всего и заводят. Пусть `centerMenu` — напитки кофейни в центре, а `parkMenu` — кофейни в парке:

```swift
let centerMenu: Set<String> = ["Латте", "Раф", "Какао"]

centerMenu.union(parkMenu)         // всё из обоих: Какао, Латте, Раф, Чай
centerMenu.intersection(parkMenu)  // только общее: Какао, Латте
centerMenu.subtracting(parkMenu)   // есть в центре, но нет в парке: Раф
```

У `subtracting` важен порядок: из множества слева убирается всё, что есть в множестве в скобках. `parkMenu.subtracting(centerMenu)` даст другой ответ — `Чай`.

**Вывести множество.** Порядка у него нет, поэтому перед показом его сортируют. `sorted()` возвращает обычный массив:

```swift
print(centerMenu.intersection(parkMenu).sorted())   // ["Какао", "Латте"]
```

### Задача
В редакторе есть истории `myHistory` и `friendHistory` и два исполнителя: `likedArtist` и `openedArtist`. Не переименовывай их — проверка подставит другие данные.

1. Объяви переменную `myArtists` — множество исполнителей из `myHistory`.
2. На странице исполнителя `likedArtist` нажали на сердечко: добавь его в `myArtists`.
3. Объяви константу `friendArtists` — множество исполнителей из `friendHistory`.
4. Выведи пять строк. Все списки — по алфавиту:
   - `Моих исполнителей:` и количество исполнителей в `myArtists`;
   - `Общие:` и исполнители, которые есть и в `myArtists`, и в `friendArtists`;
   - `Посоветовать мне:` и исполнители, которые есть у подруги, но которых нет в `myArtists`;
   - `Для общего плейлиста:` и все исполнители из обоих множеств;
   - имя из `openedArtist`, слова `в любимых:` и `true` или `false` — есть ли этот исполнитель в `myArtists`.

### Пример
Для данных из редактора:

```text
Моих исполнителей: 4
Общие: ["Билол", "Снегири", "Тихий час"]
Посоветовать мне: ["Лунный парк"]
Для общего плейлиста: ["Билол", "Лунный парк", "Северный ветер", "Снегири", "Тихий час"]
Лунный парк в любимых: false
```

В `myHistory` шесть записей, но разных исполнителей только трое. Четвёртой стала группа «Снегири» — её добавили сердечком.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let myHistory = ["Северный ветер", "Билол", "Северный ветер", "Тихий час", "Билол", "Северный ветер"]
let friendHistory = ["Билол", "Лунный парк", "Тихий час", "Лунный парк", "Снегири"]
let likedArtist = "Снегири"
let openedArtist = "Лунный парк"

// 1. Объяви переменную myArtists — множество из myHistory
var myArtists = Set(myHistory)

// 2. Сердечко: добавь likedArtist в myArtists
myArtists.insert(likedArtist)

// 3. Объяви константу friendArtists — множество из friendHistory
let friendArtists = Set(friendHistory)

// 4. Выведи пять строк: количество, общие, посоветовать мне, для общего плейлиста, в любимых ли openedArtist
print("Моих исполнителей: \(myArtists.count)")
print("Общие: \(myArtists.intersection(friendArtists).sorted())")
print("Посоветовать мне: \(friendArtists.subtracting(myArtists).sorted())")
print("Для общего плейлиста: \(myArtists.union(friendArtists).sorted())")
print("\(openedArtist) в любимых: \(myArtists.contains(openedArtist))")
```

## @rules
- must: /(\bsorted\s*\([\s\S]*){3}/ :: У множества нет порядка. Каждый из трёх списков перед выводом нужно отсортировать через `sorted()`.

## @hint1
Сначала подготовь два множества, потом печатай.

Множество получается из массива одной командой: пишешь `Set` и в круглых скобках — массив. Повторы исчезнут сами. Так создаются и `myArtists` из `myHistory`, и `friendArtists` из `friendHistory`. Разница одна: в `myArtists` на втором шаге добавляется новый исполнитель, значит, это переменная. А `friendArtists` не меняется — это константа.

Добавление в множество — команда `insert` с одним аргументом, без меток и индексов: мест в множестве нет.

Теперь пять строк вывода. Количество — привычный `count`. Дальше три списка, и для каждого своя команда. «Есть и у меня, и у подруги» — это пересечение, `intersection`. «Есть у подруги, но нет у меня» — вычитание, `subtracting`: подумай, из какого множества какое вычитается. «Все из обоих» — объединение, `union`. Результат каждой команды — снова множество без порядка, поэтому к каждому сразу добавляй `sorted()`.

Последняя строка — вопрос «есть ли исполнитель в множестве», то есть `contains`. Ответ `true` или `false` вставляется в текст как есть.

## @hint2
Вот все нужные команды на другом примере:

```swift
let orders = ["Латте", "Раф", "Латте", "Какао"]
var drinks = Set(orders)          // множество без повторов
drinks.insert("Чай")              // добавить значение

let parkMenu: Set<String> = ["Латте", "Чай", "Лимонад"]

print(drinks.intersection(parkMenu).sorted())   // общее
print(parkMenu.subtracting(drinks).sorted())    // есть в парке, но нет в drinks
print(drinks.union(parkMenu).sorted())          // всё вместе
print(drinks.contains("Раф"))                   // true
```

Обрати внимание на `subtracting`: слева стоит множество, **из которого** убирают.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `Set(myHistory)` берёт массив из шести записей и оставляет по одному экземпляру каждого значения: «Северный ветер», «Билол», «Тихий час». `insert` добавляет группу «Снегири» — исполнителей становится четыре. Если бы она уже была в множестве, `insert` ничего бы не изменил, и считать повторы вручную не пришлось бы.

Дальше три вопроса — три команды. `myArtists.intersection(friendArtists)` оставляет только тех, кто есть в обоих множествах. `friendArtists.subtracting(myArtists)` берёт исполнителей подруги и убирает из них тех, кто уже есть в `myArtists`, — остаётся то, что можно посоветовать. `myArtists.union(friendArtists)` собирает всех, причём каждого по одному разу.

**Почему множество, а не массив.** В массиве `myHistory` «Северный ветер» записан трижды, и `count` дал бы 6 вместо 3. А команд `intersection`, `union` и `subtracting` у массива вообще нет. Множество создано ровно для таких вопросов: «кто есть», «кто общий», «кого не хватает».

**Почему везде `sorted()`.** У множества нет порядка, как и у словаря: без сортировки имена печатались бы в случайной последовательности. `sorted()` превращает множество в массив по алфавиту.

**Типичные ошибки:**

- `myArtists.subtracting(friendArtists)` в строке «Посоветовать мне» — так получатся свои исполнители, которых нет у подруги, то есть ровно наоборот;
- `let myArtists` вместо `var` — тогда `insert` не сработает, константу менять нельзя;
- `myArtists.append(likedArtist)` — у множества нет конца, поэтому нет и `append`, есть только `insert`;
- `insert` стоит после вывода — количество и списки посчитаются без нового исполнителя;
- `myHistory.count` вместо `myArtists.count` — это число записей в истории вместе с повторами.
