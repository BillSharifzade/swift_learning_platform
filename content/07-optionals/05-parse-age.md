## @description

### Контекст
Экран редактирования профиля. Всё, что человек вводит с клавиатуры, приходит в код текстом — даже возраст. Сам профиль сервер присылает словарём `[String: String]`, и любого ключа в нём может не оказаться. А список фотографий — массив, который бывает пустым.

Тимлид говорит: «До сих пор опционалы приходили в твои функции готовыми, через параметры. Пора посмотреть, откуда они берутся. Чаще всего их возвращают стандартные функции — те, у которых что-то может не получиться».

### Новое в Swift
Правило простое: **если у операции может не быть результата, она возвращает опционал**. Ты уже пользовалась такими операциями, просто обходила острые углы.

**Текст в число.** `Int("...")` пытается прочитать число из строки. В строке может оказаться что угодно, поэтому результат — `Int?`:

```swift
let stars = Int("5")        // Optional(5)
let broken = Int("пять")    // nil
let spaced = Int("5 звёзд") // nil — лишние символы тоже мешают
```

**Словарь по ключу.** В «Волне» ты всегда писала `default:`. Без него словарь возвращает опционал — ведь ключа может не быть:

```swift
let settings = ["theme": "dark", "fontSize": "18"]
let theme = settings["theme"]        // Optional("dark")
let language = settings["language"]  // nil — такого ключа нет
```

**Массивы.** Обращение по индексу `scores[0]` на пустом массиве уронит программу. А вот эти свойства и методы безопасны — на пустом массиве они просто возвращают `nil`:

```swift
let scores = [72, 95, 88]
scores.first                 // Optional(72) — первый элемент
scores.last                  // Optional(88) — последний
scores.min()                 // Optional(72) — наименьший
scores.max()                 // Optional(95) — наибольший
scores.firstIndex(of: 88)    // Optional(2) — номер элемента или nil, если его нет
```

**Разворачиваются они как обычно** — через `if let`, `guard let` или `??`. Проверки можно выстроить в цепочку через запятую, и не только в `guard`:

```swift
if let text = settings["fontSize"], let size = Int(text) {
    print("Размер шрифта: \(size)")
}
```

Сначала из словаря достаётся текст, потом из текста — число. Блок выполнится, только если получилось и то, и другое.

**Своя функция тоже может вернуть опционал.** Для этого после стрелки пишут тип с вопросительным знаком. Тогда из функции можно вернуть и значение, и `nil`:

```swift
func discountPercent(for promoCode: String) -> Int? {
    if promoCode == "WELCOME" {
        return 10
    }
    return nil    // такого промокода нет
}
```

Тот, кто вызывает такую функцию, получает коробочку и сам решает, что делать, если она пуста.

### Задача
1. Допиши функцию `parseAge(_:)`. Она принимает текст и возвращает `Int?`. Если в тексте целое число от 14 до 120 включительно — возвращает это число. Во всех остальных случаях — `nil`.
2. Напиши функцию `ageLine(from:)`. Параметр — словарь `[String: String]` с меткой `from`. Функция берёт текст по ключу `"age"` и разбирает его через `parseAge`. Если возраст получен — возвращает строку вида `Возраст: 28`. Если ключа нет или `parseAge` вернула `nil` — строку `Возраст не указан`.
3. Напиши функцию `mainPhoto(_:)`. Параметр — массив `[String]` без метки. Функция возвращает первый элемент массива, а если массив пуст — строку `no-photo.png`.

Словарь читай без `default:`, а первый элемент бери через `first`, не по индексу.

### Пример
```swift
parseAge("28")         // Optional(28)
parseAge("сорок")      // nil
parseAge("7")          // nil — меньше 14

ageLine(from: ["name": "Билол", "age": "28"])    // "Возраст: 28"
ageLine(from: ["nickname": "night_owl"])         // "Возраст не указан"

mainPhoto(["bilol-1.jpg", "bilol-2.jpg"])        // "bilol-1.jpg"
mainPhoto([])                                    // "no-photo.png"
```

## @solution
```swift
// Возраст приходит из поля ввода текстом.
// Верни число, если это целое от 14 до 120, иначе nil
func parseAge(_ text: String) -> Int? {
    guard let age = Int(text), age >= 14, age <= 120 else {
        return nil
    }
    return age
}

// Строка с возрастом для экрана профиля.
// Профиль приходит с сервера словарём, возраст лежит по ключу "age".
func ageLine(from profile: [String: String]) -> String {
    guard let text = profile["age"], let age = parseAge(text) else {
        return "Возраст не указан"
    }
    return "Возраст: \(age)"
}

// Главное фото профиля — первое в списке.
func mainPhoto(_ photos: [String]) -> String {
    return photos.first ?? "no-photo.png"
}
```

## @rules
- must: /\bInt\s*\(/ :: Преврати текст в число через `Int(...)` — это и есть источник опционала в этой задаче.
- must: /\.first\b/ :: Первый элемент массива бери через свойство `first` — оно безопасно для пустого массива.
- mustnot: /\[\s*0\s*\]/ :: Не обращайся к элементу по индексу `[0]`: на пустом массиве программа упадёт. Используй `first`.
- mustnot: /\bdefault\s*:/ :: В этой задаче читай словарь без `default:` — получишь опционал и развернёшь его сама.

## @hint1
Все три функции делают одно и то же: получают опционал от стандартной операции и решают, что делать, если он пуст.

В `parseAge` источник опционала — `Int` с текстом в скобках. Удобно начать с `guard let`: достань число и тут же, через запятые, проверь, что оно не меньше 14 и не больше 120. Если что-то не так, в блоке `else` верни `nil`. После `guard` число уже обычное — верни его.

В `ageLine` источников два. Сначала словарь: обращение по ключу в квадратных скобках без `default:` даёт текст-опционал. Потом твоя же `parseAge` — она тоже возвращает опционал. Оба шага можно записать в одном `guard` через запятую: во втором условии используется текст, развёрнутый в первом. В `else` — строка «Возраст не указан», после `guard` — строка с возрастом.

В `mainPhoto` источник — свойство `first` у массива. Запасное значение на случай пустого массива подставляется оператором из двух вопросительных знаков. Вся функция умещается в одну строку.

## @hint2
Вот как две операции, возвращающие опционал, разворачиваются одна за другой:

```swift
let settings = ["theme": "dark", "fontSize": "18"]

if let text = settings["fontSize"], let size = Int(text) {
    print("Размер шрифта: \(size)")
}
```

С `guard let` работает так же. А первый элемент с запасным значением берётся так:

```swift
let drafts: [String] = []
let title = drafts.first ?? "Черновиков нет"
```

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В `parseAge` выражение `Int(text)` возвращает `Int?`: число, если текст удалось прочитать, и `nil`, если нет. `guard let age = Int(text)` достаёт число, а условия после запятых проверяют диапазон. Не прошла любая из проверок — функция возвращает `nil`. В `ageLine` цепочка из двух шагов: `profile["age"]` даёт текст или `nil`, а `parseAge(text)` — число или `nil`. До строки с возрастом дело доходит, только если оба шага удались. В `mainPhoto` свойство `first` возвращает `String?`, и `??` подставляет имя картинки по умолчанию.

**Почему `parseAge` возвращает опционал, а не ноль.** Ноль — это число, и кто-нибудь обязательно покажет его на экране: «Возраст: 0». А `nil` нельзя использовать, не развернув: компилятор заставит того, кто вызывает функцию, подумать о случае «возраста нет».

**Почему `first`, а не `photos[0]`.** У нового пользователя фотографий нет. Обращение по индексу к пустому массиву остановит программу — приложение просто закроется. `first` в той же ситуации спокойно вернёт `nil`.

**Почему `ageLine` вызывает `parseAge`, а не `Int`.** Правило про возраст от 14 до 120 записано в одном месте. Если бы `ageLine` разбирала текст сама, на экране мог бы появиться возраст 7 или 300.

**Типичные ошибки:**

- `age > 14` вместо `age >= 14` — возраст ровно 14 лет будет отклонён;
- в `parseAge` забыт `return age` после `guard` — функция обязана вернуть значение на любом пути;
- `profile["age", default: "0"]` — получится обычная строка, и случай «ключа нет» потеряется;
- `return photos.first` без `??` — функция обещала `String`, а `first` даёт `String?`.
