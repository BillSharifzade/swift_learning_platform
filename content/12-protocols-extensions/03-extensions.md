## @description

### Контекст
На код-ревью тимлид заметил повторы. Значок с числом непрочитанных собирается в трёх местах: в списке чатов, на иконке приложения и во вкладке «Архив». Проверка «это команда для бота?» скопирована в пять файлов. А строку для списка контактов каждый экран склеивает по-своему.

«Давай вынесем это в расширения, — пишет тимлид. — Тогда у числа появится свойство `badgeText`, у строки — `isBotCommand`, у контакта — `listTitle`. Вызывать их будут как обычные свойства, а логика окажется в одном месте».

### Новое в Swift
**Расширение** (extension) добавляет новые возможности к типу, который уже существует. Даже к тому, который писала не ты, — к `Int`, `String`, `Array`. Записывается словом `extension` и именем типа:

```swift
extension Int {
    var minutesText: String {
        return "\(self) мин."
    }
}

let delay = 15
print(delay.minutesText)    // 15 мин.
print(40.minutesText)       // 40 мин.
```

Теперь у **любого** целого числа в программе есть свойство `minutesText`. Внутри расширения слово `self` означает само значение, у которого свойство вызвали: для `delay.minutesText` это `15`.

Методы и свойства самого типа внутри расширения доступны и без `self`, как внутри структуры:

```swift
extension String {
    var isShout: Bool {
        return !isEmpty && self == uppercased()
    }
}

print("ПОЧЕМУ НЕ ОТВЕЧАЕШЬ".isShout)   // true
print("Скоро буду".isShout)            // false
```

Здесь `isEmpty` и `uppercased()` — свойство и метод той строки, у которой спросили `isShout`.

**Свои типы тоже можно расширять.** Так код раскладывают по смыслу: в самой структуре — данные, в расширении — то, что нужно для экрана:

```swift
struct Chat {
    let title: String
    let membersCount: Int
}

extension Chat {
    var isGroup: Bool {
        return membersCount > 2
    }

    func headerText() -> String {
        return isGroup ? "\(title), участников: \(membersCount)" : title
    }
}
```

> ⚠️ В расширение можно добавлять вычисляемые свойства и методы, но не хранимые свойства. Строка `var draft = ""` внутри `extension` не соберётся: расширение не может изменить то, из чего состоит значение в памяти.

### Задача
1. Напиши расширение `Int` с вычисляемым свойством `badgeText` типа `String` — текст значка непрочитанных:
   - `0` и меньше — пустая строка `""` (значок не показываем);
   - от `1` до `99` — само число текстом;
   - больше `99` — `99+`.
2. Напиши расширение `String` с вычисляемым свойством `isBotCommand` типа `Bool`: `true`, если строка начинается с `/` и в ней больше одного символа. Одна косая черта `/` — ещё не команда.
3. Напиши расширение `Contact` с вычисляемым свойством `listTitle` типа `String`: если контакт в сети — имя и ` (в сети)`, иначе только имя.
4. Саму структуру `Contact` не меняй — всё новое должно быть в расширении.

### Пример
```swift
7.badgeText               // "7"
250.badgeText             // "99+"
"/start".isBotCommand     // true
"Привет".isBotCommand     // false
Contact(name: "Билол", isOnline: true).listTitle     // "Билол (в сети)"
```

Сценарий внизу редактора должен вывести:

```text
Непрочитанных 3, значок: 3
Непрочитанных 99, значок: 99
Непрочитанных 100, значок: 99+
Непрочитанных 0, значок:
/start - команда: true
Привет - команда: false
/ - команда: false
Билол (в сети)
Мама
```

## @solution
```swift
// Контакт в адресной книге "Почтальона". Структуру не меняй
struct Contact {
    let name: String
    let isOnline: Bool
}

// 1. Расширение Int: свойство badgeText для значка непрочитанных
extension Int {
    var badgeText: String {
        if self <= 0 {
            return ""
        }
        return self > 99 ? "99+" : "\(self)"
    }
}

// 2. Расширение String: свойство isBotCommand
extension String {
    var isBotCommand: Bool {
        return hasPrefix("/") && count > 1
    }
}

// 3. Расширение Contact: свойство listTitle для списка контактов
extension Contact {
    var listTitle: String {
        return isOnline ? "\(name) (в сети)" : name
    }
}

// Значки в списке чатов
let unreadCounts = [3, 99, 100, 0]
for count in unreadCounts {
    print("Непрочитанных \(count), значок: \(count.badgeText)")
}

// Что пользователь ввёл в поле сообщения
let inputs = ["/start", "Привет", "/"]
for text in inputs {
    print("\(text) - команда: \(text.isBotCommand)")
}

// Список контактов
let contacts = [Contact(name: "Билол", isOnline: true), Contact(name: "Мама", isOnline: false)]
for contact in contacts {
    print(contact.listTitle)
}
```

## @rules
- must: /\bextension\s+Int\b/ :: Свойство `badgeText` должно жить в расширении: `extension Int { ... }`.
- must: /\bextension\s+String\b/ :: Свойство `isBotCommand` должно жить в расширении: `extension String { ... }`.
- must: /\bextension\s+Contact\b/ :: Свойство `listTitle` должно жить в расширении: `extension Contact { ... }`.
- mustnot: /\bstruct\s+Contact\s*\{[^}]*listTitle/ :: Не меняй саму структуру `Contact`: `listTitle` нужно объявить в расширении `extension Contact`.

## @hint1
Тебе нужны три расширения — по одному на каждый тип. Каждое начинается словом `extension` и именем типа, а внутри фигурных скобок объявляется вычисляемое свойство: `var`, имя, двоеточие, тип и фигурные скобки с кодом, который возвращает значение.

В `badgeText` число, у которого спросили свойство, — это `self`. Сначала разберись с нулём и отрицательными числами: для них пустая строка. Потом с большими: больше 99 — текст `99+`. Во всех остальных случаях верни само число, превращённое в текст через интерполяцию.

В `isBotCommand` нужны два условия сразу: строка начинается с косой черты и символов в ней больше одного. У строки для этого есть `hasPrefix` и `count`, а соединить условия поможет `&&`.

В `listTitle` выбор из двух вариантов по свойству `isOnline`. К свойствам контакта внутри расширения можно обращаться просто по имени: `name`, `isOnline`.

## @hint2
Так выглядит расширение встроенного типа и расширение своей структуры:

```swift
extension Int {
    var minutesText: String {
        return "\(self) мин."
    }
}

extension Chat {
    var isGroup: Bool {
        return membersCount > 2
    }
}
```

Внутри `extension Int` значение числа — это `self`. Внутри `extension Chat` свойства структуры доступны по имени.

## @hint3
Заполни пропуски:

```swift
extension Int {
    var badgeText: String {
        if self <= 0 {
            return ""
        }
        return self > ___ ? "99+" : "\(self)"
    }
}

extension String {
    var isBotCommand: Bool {
        return hasPrefix("/") && ___
    }
}

extension ___ {
    var listTitle: String {
        return isOnline ? "\(name) (в сети)" : name
    }
}
```

В первом пропуске — число, после которого значок превращается в `99+`. Во втором — условие про количество символов. В третьем — имя расширяемого типа.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** `extension Int` дописывает свойство всем целым числам программы сразу. Когда сценарий спрашивает `count.badgeText`, внутри свойства `self` — это значение `count`. Сначала отсекаются ноль и отрицательные числа, затем тернарный оператор выбирает между `99+` и самим числом. `extension String` точно так же учит любую строку отвечать на вопрос «ты команда?». А `extension Contact` добавляет свойство структуре, не трогая её объявление.

**Почему расширение, а не обычная функция.** Можно было написать `func badgeText(for count: Int) -> String` — и это бы работало. Но расширение читается естественнее: `count.badgeText` звучит как «значок этого числа». А ещё его легко найти: Xcode подскажет свойство, как только ты поставишь точку после числа.

**Зачем расширять свою структуру.** `Contact` описывает, что такое контакт: имя и статус. А `listTitle` — это забота экрана. Когда такие вещи лежат в отдельном расширении, структуру проще читать, а экранную логику — менять. В больших проектах расширения часто раскладывают даже по разным файлам.

**Типичные ошибки:**

- `count > 0` вместо `count > 1` в `isBotCommand` — тогда одинокая `/` считается командой;
- `self >= 99` вместо `self > 99` — значок `99+` появится уже при 99 сообщениях;
- `contains("/")` вместо `hasPrefix("/")` — командой станет любое сообщение, где встретилась косая черта;
- `listTitle` дописано прямо в структуру — работать будет, но задача была именно в расширении.
