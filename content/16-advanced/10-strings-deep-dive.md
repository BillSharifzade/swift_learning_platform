## @description

### Контекст
Последняя задача модуля. В «Чернилах» можно ставить хэштеги прямо в тексте: «Купить #продукты к ужину». Под заметкой они превращаются в плашки, а по нажатию на плашку открываются все заметки с этим тегом.

Нужны две функции для карточки заметки. Первая находит в тексте все хэштеги. Вторая делает короткое превью для списка. Тестировщица уже нашла, на чём ломалась старая версия: на эмодзи, на буквах с ударениями и на тегах, которые стоят вплотную друг к другу. Поэтому нужно по-честному разобраться, как устроены строки в Swift.

### Новое в Swift
**Character.** Строка — это коллекция символов типа `Character`. Цикл `for` по строке перебирает именно их. У символа есть полезные свойства: `isLetter` (буква любого алфавита), `isNumber` (цифра), `isWhitespace` (пробел или перенос строки):

```swift
let symbol: Character = "Ж"
symbol.isLetter        // true
Character("5").isNumber          // true
Character("@").isLetter          // false
```

**Unicode.** Под капотом текст хранится как набор кодов Unicode, и один видимый символ может состоять из нескольких кодов. Swift считает символы так, как их видит человек:

```swift
let like = "👍🏽"                 // палец + оттенок кожи
like.count                       // 1 — один символ
like.unicodeScalars.count        // 2 — два кода Unicode
like.utf8.count                  // 8 — восемь байт в памяти
"привет".utf8.count              // 12, хотя букв 6
```

Поэтому длину текста для человека всегда берут через `count`. И никогда не режут строку по байтам: можно разрезать эмодзи пополам.

**Индексы.** Раз символы занимают в памяти разное место, Swift не может мгновенно найти «пятый символ». Поэтому `text[5]` не работает. Позиция в строке — это особый тип `String.Index`:

- `text.startIndex` — позиция первого символа;
- `text.endIndex` — позиция *после* последнего. Символа там нет, это граница;
- `text.index(after: i)` — следующая позиция;
- `text[i]` — символ на позиции `i`;
- индексы можно сравнивать: `i < text.endIndex`.

Вот как дойти до конца первого слова:

```swift
let text = "Купить молоко"
var end = text.startIndex
while end < text.endIndex && !text[end].isWhitespace {
    end = text.index(after: end)
}
let firstWord = text[text.startIndex..<end]     // "Купить"
```

**Substring.** Кусок строки по диапазону индексов — это `Substring`, «окно» в исходную строку. Оно не копирует текст, поэтому работает быстро. `prefix` и `dropFirst` у строк тоже возвращают `Substring`. Методы вроде `lowercased()` работают и с ним и возвращают обычную `String`. Чтобы сохранить кусок надолго, его превращают в строку: `String(firstWord)`.

```swift
let email = "bilol@ink.app"
if let at = email.firstIndex(of: "@") {
    let domain = email[email.index(after: at)...]   // "ink.app", до самого конца
}
```

> 💡 Для поиска по шаблонам в Swift есть регулярные выражения: `#/#(\w+)/#`. Они удобны, но сегодня важнее понять, как устроена строка внутри.

### Задача
1. Напиши функцию `isTagCharacter(_:)`. Параметр — `Character` без метки. Возвращает `Bool`: `true` для буквы, цифры или знака `_`, иначе `false`.
2. Напиши функцию `hashtags(in:)`. Параметр `text` типа `String` с меткой `in`. Возвращает `[String]`:
   - хэштег начинается со знака `#` и продолжается, пока идут символы, для которых `isTagCharacter` даёт `true`. Любой другой символ (пробел, знак препинания, эмодзи, ещё один `#`) или конец текста его заканчивает;
   - в результат тег попадает без `#` и маленькими буквами;
   - `#`, после которого нет ни одного подходящего символа, — не тег;
   - каждый тег — один раз, в порядке первого появления.

   Иди по тексту с помощью индексов (`index(after:)`), а тег вырезай диапазоном индексов.
3. Напиши функцию `preview(of:limit:)`. Параметры: `text` типа `String` с меткой `of` и `limit` типа `Int`. Возвращает `String`: если символов в тексте не больше `limit` — текст целиком, иначе первые `limit` символов и `...` на конце.

### Пример
```swift
hashtags(in: "Купить #продукты и #вино_к_ужину! #Продукты")
// ["продукты", "вино_к_ужину"]
hashtags(in: "#кофе☕#утро")       // ["кофе", "утро"]
hashtags(in: "Цена 100# и #")     // []

preview(of: "Купить хлеб", limit: 20)    // "Купить хлеб"
preview(of: "Купить хлеб", limit: 6)     // "Купить..."
```

## @solution
```swift
// 1. Может ли символ быть частью хэштега: буква, цифра или _
func isTagCharacter(_ character: Character) -> Bool {
    return character.isLetter || character.isNumber || character == "_"
}

// 2. Все хэштеги заметки: без #, маленькими буквами, без повторов
func hashtags(in text: String) -> [String] {
    var tags: [String] = []
    // Иди по тексту индексами: startIndex, index(after:), endIndex
    var index = text.startIndex
    while index < text.endIndex {
        guard text[index] == "#" else {
            index = text.index(after: index)
            continue
        }
        let start = text.index(after: index)
        var end = start
        while end < text.endIndex && isTagCharacter(text[end]) {
            end = text.index(after: end)
        }
        let tag = text[start..<end].lowercased()
        if !tag.isEmpty && !tags.contains(tag) {
            tags.append(tag)
        }
        index = end
    }
    return tags
}

// 3. Превью для списка заметок
func preview(of text: String, limit: Int) -> String {
    guard text.count > limit else {
        return text
    }
    return String(text.prefix(limit)) + "..."
}

// Карточка заметки. Этот код уже готов — менять его не нужно
print(preview(of: "Купить хлеб", limit: 20))
print(preview(of: "Отпуск 🏖️: билеты, отель, экскурсии", limit: 8))

let note = "Купить к ужину #продукты: сыр, #вино 🍷 и хлеб. Не забыть #Продукты по списку! #ужин_пятница"
print("Теги:")
for tag in hashtags(in: note) {
    print("- \(tag)")
}
```

## @rules
- must: /index\s*\(\s*after\s*:/ :: Иди по тексту индексами строки: `text.index(after: index)`.
- must: /\.\.<\s*\w+\s*\]/ :: Вырежи тег диапазоном индексов: `text[start..<end]`.
- mustnot: /Array\s*\(\s*text\s*\)/ :: В этой задаче не превращай строку в массив: тренируемся работать с индексами `String.Index`.

## @hint1
`isTagCharacter` — одна строка: три проверки, соединённые через «или». Для букв и цифр у символа есть готовые свойства, а подчёркивание сравни с символом `"_"` напрямую.

В `hashtags` понадобятся два цикла `while`, один внутри другого. Внешний идёт по всему тексту: заведи переменную-индекс, начни со `startIndex` и двигайся, пока индекс меньше `endIndex`. Если символ на текущей позиции — не решётка, просто шагни вперёд.

Если решётка — начинается тег. Его первый символ стоит на следующей позиции. Заведи ещё один индекс — конец тега — и двигай его вперёд, пока не кончился текст и символ подходит для тега. Теперь между началом и концом лежит тег: вырежи его диапазоном `..<`, переведи в маленькие буквы. Если он не пустой и такого ещё нет в результате — добавь. Внешний индекс переставь на конец тега: там может сразу начаться следующий.

`preview` — сравни `count` с `limit`. Если обрезать нужно, возьми `prefix`, преврати его в `String` и допиши три точки.

## @hint4
Вот готовое решение:

{{solution}}

**Почему индексы, а не номера.** В тексте заметки бывают русские буквы (2 байта), эмодзи (4 байта и больше) и составные символы вроде «é» из двух кодов. Swift не может перепрыгнуть сразу к «пятому символу», не пройдя предыдущие. Поэтому он не даёт писать `text[5]`, а предлагает двигаться по позициям: `startIndex`, `index(after:)`, `endIndex`. Зато каждый шаг — ровно один видимый символ, и эмодзи никогда не разрежется пополам.

**Как работает поиск.** Внешний цикл ищет решётку. Внутренний от позиции после неё двигает `end`, пока символы подходят для тега. Условие `end < text.endIndex` стоит первым: если текст кончился, `text[end]` даже не вычисляется, и программа не падает. `text[start..<end]` — это `Substring`, окно в исходный текст без копирования. `lowercased()` сразу делает из него обычную `String`.

**Почему `index = end`.** После тега поиск продолжается с первого символа, который в тег не вошёл. Если это снова `#`, как в `#кофе☕#утро` или `#раз#два`, следующий тег найдётся на следующем шаге. Пустой тег (одинокая `#`) тоже не ломает цикл: `end` всегда хотя бы на шаг правее решётки, поэтому цикл движется вперёд.

**Почему `prefix` и `count` честные.** Оба работают с `Character` — символами, как их видит человек. Семья из эмодзи — это пять кодов Unicode, но один `Character`. Поэтому `preview` с лимитом 1 отдаёт её целиком.

**Типичные ошибки:**

- `text[end]` раньше проверки `end < text.endIndex` — тег в самом конце текста уронит программу;
- вырезать тег от `index`, а не от `start`, — в результат попадёт решётка;
- `index = text.index(after: end)` — символ сразу после тега пропускается, и в `#раз#два` найдётся только первый тег. А если тег стоит в самом конце текста, шаг за `endIndex` уронит программу;
- проверить повтор до `lowercased()` — `#Работа` и `#работа` попадут в результат дважды.
