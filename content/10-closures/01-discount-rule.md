## @description

### Контекст
Акции на «Ярмарке» меняются каждую неделю: то сезонная распродажа, то купон на фиксированную сумму. Сейчас при каждой смене акции разработчик правит код расчёта цены в нескольких местах — и иногда что-нибудь забывает.

Тимлид предлагает: «Давай хранить правило скидки как значение — в переменной. Захотели сменить акцию — положили в переменную другое правило. Остальной код при этом не трогаем».

### Новое в Swift
В модуле про функции ты уже видела, что функция — это тоже значение. Её можно положить в переменную или передать в другую функцию, а у её типа есть запись: например, `(Int) -> Int` — «принимает целое число, возвращает целое число».

Тогда, чтобы получить такое значение, ты объявляла функцию через `func` и придумывала ей имя. Но часто действие короткое и нужно в одном месте. Для таких случаев есть **замыкание** (по-английски closure) — функция без имени. Её записывают в фигурных скобках прямо там, где она нужна:

```swift
let addDelivery = { (total: Int) -> Int in
    return total + 250
}
```

Разберём по частям:

- `{ }` — всё замыкание целиком живёт в фигурных скобках;
- `(total: Int)` — параметры, как у обычной функции;
- `-> Int` — тип результата;
- `in` — слово-граница: до него заголовок, после него тело;
- `return total + 250` — тело, обычный код.

Сравни с функцией. Части те же, только имя исчезло, а заголовок переехал внутрь скобок:

```swift
func addDelivery(total: Int) -> Int {
    return total + 250
}
```

Теперь в константе `addDelivery` лежит значение типа `(Int) -> Int`. Вызывается оно как функция, но **без меток аргументов**:

```swift
print(addDelivery(1000))   // 1250
```

В теле замыкания может быть несколько строк, условия — всё, что бывает в функции:

```swift
let addGiftWrap = { (total: Int) -> Int in
    if total >= 5000 {
        return total
    }
    return total + 150
}
```

И главное. Раз замыкание — значение, его можно положить в **переменную**, а потом заменить другим замыканием того же типа:

```swift
var extraService = addDelivery
print(extraService(1000))   // 1250

extraService = addGiftWrap
print(extraService(1000))   // 1150
```

Строка `extraService(1000)` одна и та же, а результат разный — зависит от того, какое правило сейчас лежит в переменной.

> ⚠️ Не забывай слово `in`. Без него Swift не поймёт, где кончается заголовок и начинается тело.

### Задача
В редакторе есть цена товара `productPrice`. Не переименовывай её — проверка подставит другое значение.

1. Объяви константу `seasonSale` и положи в неё замыкание «Сезонная распродажа». Оно принимает цену (`Int`) и возвращает цену, сниженную на 10%. Считай в целых числах: `price * 90 / 100`.
2. Объяви константу `coupon300` — замыкание «Купон на 300 руб.». Оно принимает цену (`Int`) и возвращает цену минус 300. Если цена меньше 300, результат — `0`: цена не бывает отрицательной.
3. Объяви **переменную** `activeRule` и положи в неё `seasonSale`.
4. Выведи строку `Цена по акции: N руб.`, где `N` — результат вызова `activeRule(productPrice)`.
5. Акция сменилась: положи в `activeRule` правило `coupon300` и выведи такую же строку ещё раз.

Обычные функции (`func`) в этой задаче не нужны — оба правила записываются замыканиями.

### Пример
Для цены из редактора (2400 руб.):

```text
Цена по акции: 2160 руб.
Цена по акции: 2100 руб.
```

А для товара за 250 руб. получилось бы `225` и `0`.

## @solution
```swift
// Входные данные (их подменяет проверка — не переименовывай)
let productPrice = 2400

// 1. Правило «Сезонная распродажа»: цена снижается на 10%
// Объяви замыкание seasonSale
let seasonSale = { (price: Int) -> Int in
    return price * 90 / 100
}

// 2. Правило «Купон на 300 руб.»: минус 300, но не меньше нуля
// Объяви замыкание coupon300
let coupon300 = { (price: Int) -> Int in
    if price < 300 {
        return 0
    }
    return price - 300
}

// 3. Правило, которое действует сейчас
// Объяви переменную activeRule и положи в неё seasonSale
var activeRule = seasonSale

// 4. Выведи цену товара по действующему правилу
print("Цена по акции: \(activeRule(productPrice)) руб.")

// 5. Акция сменилась: положи в activeRule правило coupon300 и выведи цену ещё раз
activeRule = coupon300
print("Цена по акции: \(activeRule(productPrice)) руб.")
```

## @rules
- mustnot: /\bfunc\b/ :: В этой задаче правила записываются замыканиями — без слова `func`. Замыкание выглядит так: `{ (price: Int) -> Int in ... }`.
- must: /\bvar\s+activeRule\b/ :: Действующее правило меняется, поэтому `activeRule` нужно объявить через `var`.
- must: /\bactiveRule\s*\(\s*productPrice\s*\)/ :: Цену нужно получить вызовом `activeRule(productPrice)` — тогда при смене правила изменится и результат.

## @hint1
Задача состоит из двух частей: сначала описать два правила, потом ими воспользоваться.

Каждое правило — это замыкание, которое лежит в константе. Замыкание пишется в фигурных скобках. Внутри сначала идёт заголовок: в круглых скобках параметр с типом (цена, целое число), затем стрелка и тип результата (тоже целое число), затем слово `in`. После `in` — тело: что сделать с ценой и что вернуть через `return`.

У `seasonSale` тело — одна строка с формулой из условия. У `coupon300` тело чуть длиннее: сначала проверь через `if`, не меньше ли цена трёхсот. Если меньше — верни ноль. Иначе верни цену минус 300.

Вторая часть. `activeRule` — переменная, потому что правило в ней будет меняться. Сначала в неё кладётся `seasonSale` — просто по имени, без скобок: ты кладёшь само правило, а не результат его вызова. Потом выводишь строку, в которую интерполяцией вставлен вызов `activeRule(productPrice)`. Потом присваиваешь `activeRule` второе правило и повторяешь тот же `print`.

## @hint2
Замыкание в константе выглядит так. Обрати внимание, где стоят параметры и слово `in`:

```swift
let addDelivery = { (total: Int) -> Int in
    return total + 250
}

print(addDelivery(1000))   // 1250
```

Твои `seasonSale` и `coupon300` устроены так же: один параметр типа `Int` и результат типа `Int`. Меняется только тело.

Чтобы положить готовое замыкание в переменную, пиши его имя без круглых скобок:

```swift
var extraService = addDelivery
```

## @hint3
Первое правило готово. Допиши второе и работу с переменной:

let seasonSale = { (price: Int) -> Int in

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В `seasonSale` и `coupon300` лежат не числа, а действия: «возьми цену и верни новую». У обоих один и тот же тип — `(Int) -> Int`. Swift определяет его сам по заголовку замыкания: параметр `Int`, результат `Int`.

**Почему `activeRule` — переменная.** Строка `var activeRule = seasonSale` кладёт в переменную первое правило. Скобок после `seasonSale` нет: мы не вызываем замыкание, а передаём его целиком, как вещь. Позже `activeRule = coupon300` заменяет правило. Это возможно, потому что типы у правил совпадают.

**Почему два одинаковых `print` выводят разное.** `activeRule(productPrice)` вызывает то замыкание, которое лежит в переменной в этот момент. Сначала там распродажа: 2400 * 90 / 100 = 2160. Потом купон: 2400 - 300 = 2100. Код расчёта цены не изменился ни на символ — изменилось только значение в переменной. Именно этого хотел тимлид: новая акция — это новое замыкание, а не правка кода по всему приложению.

**Зачем проверка `if price < 300`.** Без неё для товара за 250 руб. получилось бы -50. Отрицательная цена в чеке — настоящая ошибка, из-за которой магазин остался бы должен покупателю.

**Типичные ошибки:**

- забыто слово `in` — Swift не видит, где заканчивается заголовок;
- `var activeRule = seasonSale()` — со скобками это попытка вызвать замыкание, а не сохранить его;
- `activeRule(price: productPrice)` — у замыканий нет меток аргументов, значение передаётся просто в скобках;
- `let activeRule` — константе нельзя присвоить второе правило.
