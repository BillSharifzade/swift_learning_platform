## @description

### Контекст
«Копилка» считает кэшбэк — часть суммы покупки, которая возвращается на счёт. Продакт-менеджер описала правила так: обычно возвращается 1% от покупки. В «категориях месяца» процент выше, у партнёров бывают свои акции. И есть потолок: за одну покупку возвращается не больше 1000 руб., если акция не обещает другого.

Тимлид добавляет: «В девяти вызовах из десяти это будет 1% и лимит 1000. Не заставляй каждый раз писать одно и то же — задай эти значения по умолчанию».

### Новое в Swift
Бывает, что у параметра почти всегда одно и то же значение, и лишь изредка нужно другое. Тогда ему дают **значение по умолчанию**: после типа параметра ставят знак `=` и само значение.

```swift
func monthlyPayment(for total: Int, months: Int = 12) -> Int {
    return total / months
}
```

Такой параметр при вызове можно не указывать. Тогда функция возьмёт значение по умолчанию. А если аргумент передан, используется он:

```swift
monthlyPayment(for: 60000)              // 5000  — months равен 12
monthlyPayment(for: 60000, months: 6)   // 10000 — months равен 6
```

Кстати, метка `for` — то же слово, которым начинается цикл. В роли метки Swift понимает его правильно, а вызов читается естественно: «платёж за 60000».

Параметров со значением по умолчанию может быть несколько. Каждый из них пропускается независимо от других:

```swift
func reminderText(for bill: String, daysBefore: Int = 3, time: String = "10:00") -> String {
    return "Напомним про \(bill) за \(daysBefore) дн. в \(time)"
}

reminderText(for: "интернет")                               // за 3 дн. в 10:00
reminderText(for: "интернет", daysBefore: 1)                // за 1 дн. в 10:00
reminderText(for: "интернет", time: "19:30")                // за 3 дн. в 19:30
reminderText(for: "интернет", daysBefore: 1, time: "19:30") // за 1 дн. в 19:30
```

В третьем вызове пропущен параметр из середины. Swift понимает это по метке: раз написано `time:`, значит, `daysBefore` остаётся со своим значением по умолчанию.

Что стоит запомнить:

- параметры без значения по умолчанию обязательны, их пропускать нельзя;
- параметры со значениями по умолчанию принято ставить в конец списка;
- порядок аргументов при вызове всегда такой же, как в объявлении.

> 💡 Значение по умолчанию — это подсказка для читающего код: «обычно здесь вот такое число». Объявление функции становится маленькой документацией.

### Задача
В редакторе есть суммы трёх покупок: `groceries`, `cafe` и `laptop`.

1. Объяви функцию `cashback`, которая возвращает `Int` — кэшбэк в рублях. Параметры:
   - сумма покупки: метка `for`, внутреннее имя `amount`, тип `Int`;
   - `percent` типа `Int`, значение по умолчанию `1`;
   - `limit` типа `Int`, значение по умолчанию `1000` — максимальный кэшбэк за одну покупку.
2. Кэшбэк считается так: `amount * percent / 100`. Сначала умножение, потом деление — деление целых чисел отбросит копейки. Если результат получился больше, чем `limit`, функция возвращает `limit`.
3. Выведи три строки, как в примере:
   - продукты — обычные условия;
   - кафе — категория месяца, 5%;
   - ноутбук — акция партнёра: 3% и лимит 5000.

### Пример
Вывод программы:

```text
Продукты: 25 руб.
Кафе: 90 руб.
Ноутбук: 3600 руб.
```

Проверка вызовет функцию и по-другому:

```swift
cashback(for: 120000)                           // 1000 — сработал лимит
cashback(for: 30000, limit: 100)                // 100  — свой лимит, процент обычный
cashback(for: 30000, percent: 5, limit: 2000)   // 1500
```

## @solution
```swift
// Покупки за сегодня (суммы в рублях)
let groceries = 2500
let cafe = 1800
let laptop = 120000

// 1. Объяви функцию cashback(for:percent:limit:) со значениями по умолчанию
func cashback(for amount: Int, percent: Int = 1, limit: Int = 1000) -> Int {
    let bonus = amount * percent / 100
    if bonus > limit {
        return limit
    }
    return bonus
}

// 2. Выведи кэшбэк за продукты, кафе и ноутбук
print("Продукты: \(cashback(for: groceries)) руб.")
print("Кафе: \(cashback(for: cafe, percent: 5)) руб.")
print("Ноутбук: \(cashback(for: laptop, percent: 3, limit: 5000)) руб.")
```

## @hint1
Сначала разберись с объявлением. У функции три параметра. Первый — сумма покупки с меткой `for` и внутренним именем `amount`, как в прошлой задаче. У второго и третьего по одному имени — `percent` и `limit`. Новое здесь одно: после типа каждого из этих двух параметров стоит знак равенства и значение, которое функция возьмёт, если аргумент не передали. Для процента это единица, для лимита — тысяча.

Тело функции от значений по умолчанию не зависит: внутри `percent` и `limit` — обычные константы, и неважно, пришли они из вызова или из объявления. Посчитай кэшбэк по формуле из задания и сохрани в константу. Потом сравни его с лимитом: если кэшбэк больше, верни лимит, иначе — сам кэшбэк.

Вызовы отличаются только количеством аргументов. Для продуктов передай одну сумму. Для кафе добавь процент. Для ноутбука — процент и лимит. Каждый вызов поставь внутрь интерполяции между названием покупки и словом `руб.`

## @hint2
Значение по умолчанию пишется после типа параметра, а при вызове такой параметр можно пропустить:

```swift
func monthlyPayment(for total: Int, months: Int = 12) -> Int {
    return total / months
}

print("Платёж: \(monthlyPayment(for: 60000)) руб.")
print("Платёж: \(monthlyPayment(for: 60000, months: 6)) руб.")
```

В твоей функции таких параметров два, они идут через запятую. А в теле, кроме формулы, есть сравнение с лимитом.

## @hint3
Допиши значения по умолчанию, проверку лимита и последний вызов:

```swift
func cashback(for amount: Int, percent: Int = ___, limit: Int = ___) -> Int {
    let bonus = amount * percent / 100
    if bonus > ___ {
        return limit
    }
    return bonus
}

print("Продукты: \(cashback(for: groceries)) руб.")
print("Кафе: \(cashback(for: cafe, percent: 5)) руб.")
print("Ноутбук: \(cashback(for: laptop, ___)) руб.")
```

В первых двух пропусках — обычный процент и обычный лимит из задания. В третьем — с чем сравнивается кэшбэк. В четвёртом — два аргумента с метками: процент 3 и лимит 5000.

## @hint4
Вот готовое решение:

{{solution}}

**Как это работает.** В объявлении у `percent` и `limit` после типа стоит `= значение`. При вызове `cashback(for: groceries)` передан только один аргумент, поэтому Swift сам подставляет `percent = 1` и `limit = 1000`. Получается `2500 * 1 / 100 = 25`. В вызове `cashback(for: cafe, percent: 5)` процент передан явно, а лимит остаётся по умолчанию: `1800 * 5 / 100 = 90`. В третьем вызове заданы все три значения: `120000 * 3 / 100 = 3600`, это меньше лимита 5000, значит, возвращается 3600.

Тело функции ничего не знает о том, откуда пришли значения. Для него `percent` и `limit` — обычные константы.

**Почему сначала умножение.** Деление целых чисел отбрасывает дробную часть. Если написать `amount / 100 * percent`, то для покупки на 199 руб. получится `199 / 100 = 1`, и потом `1 * 5 = 5`. А правильный ответ — `199 * 5 / 100 = 9`. Чем позже деление, тем меньше теряется.

**Почему значения по умолчанию, а не три разные функции.** Можно было написать `standardCashback`, `cashbackWithPercent` и `cashbackWithPercentAndLimit`. Но правило расчёта одно, и хранить его лучше в одном месте. Значения по умолчанию дают короткий вызов для обычного случая и полный — для особого. И прямо в объявлении видно, какие условия считаются обычными.

**Типичные ошибки:**

- значение по умолчанию написано перед типом: `percent = 1: Int` — правильный порядок: имя, двоеточие, тип, знак равенства, значение;
- при вызове забыта метка: `cashback(for: cafe, 5)` — метки пишутся всегда, по умолчанию бывает только значение;
- аргументы переставлены: `cashback(for: laptop, limit: 5000, percent: 3)` — порядок должен быть как в объявлении;
- условие `bonus >= limit` — результат получится тот же, но точнее читается `>`: лимит заменяет кэшбэк, только когда тот больше.
